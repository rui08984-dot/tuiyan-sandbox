# v1.3 需求变更：长视频定调（2026-09-02 用户拍板）

## 决策
1. **只做长视频**（B站），不做短视频内容——用户个人初衷。道听途说/稗官野史形态：单故事 15-20 分钟起步。
2. 抖音切片降级为「可选引流器」（30秒高能段+完整版引导），是否启用由用户后续决定；从核心工作流移除。
3. 文学性分层：片头/收尾可文学化，中段递进口语推进；文学性的正确形态=意象系统+细节精准（转写稿实证：道听途说「有点像哼哼声，还有点像哭，里面还夹杂着唱」的声音分层描写；「像是有鸟飞到玻璃上的那种撞击」的具象比喻）。

## skill 参数变更（v1.3 执行）
1. 默认时长：单故事 15-20 分钟（≈4500-8000 字，按 4 字/秒）；多故事拼盘与单长篇两种格式并存。
2. 微高潮制度：每 4-5 分钟一个 attention reset（小爆点/反转/钩子升级）——长篇不再只是「三次递进」，而是「递进×N 波浪」。
3. 催泪双泵升级为节奏骨架：吓→泪→吓的情绪波浪撑起 20 分钟（待 longform 蒸馏结果定具体手法）。
4. 配比表重算：按 20 分钟稿重排五段字数。
5. 质检新增：「自我查重」（对近期产出查相似度，吸收 YTGen 的 recent-story similarity 检查）、「陈词滥调结尾检测」（吸收 YTGen cliché ending check）。
6. 外部依据引用：obra/the-elements-of-style（简洁即文学性）、openprose（prose 风格系统）原则并入 oral-conversion.md。
