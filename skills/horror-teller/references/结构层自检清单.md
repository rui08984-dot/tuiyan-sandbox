# 结构层自检清单（v1 · 2026-09-03 实测阈值）

> **定位**：质检第 6 步的「结构硬门」。理论依据=P3b 报告（检测器测的困惑度/爆发性本质是结构信号；ASD-STE100 证明「系统门」胜「词表」）+ 用户假设「结构改清楚，AI 味自然淡」（样稿结构指纹偏离对标一倍远的实证见 examples/episode-001 结构实验报告）。
> **分层原因**：机器门脚本可算、不给 LLM 留手滑空间；语义门必须语义理解，混层会假精确。
> **工具**：`node scripts/structure_metrics.cjs <输出> <稿子>`（脚本在本技能 scripts/ 下，相对技能根目录执行；对文稿需先剥标注行，剥标注用 scripts/strip_annotations.cjs）。

## 一、机器门（脚本实测，任一越界=打回）

基线来源：5 份对标真人口播稿全文统计（稗官野史42min/道听途说106min/伪人/校寝/特辑，2026-09-03 实测，句层指纹高度一致）。

| # | 指标 | 口播稿阈值 | 对标基线 | 说明 |
|---|---|---|---|---|
| M1 | 句均长 | **26-34 字** | 34.5-36.3（含ASR语气词膨胀） | 书面讲稿合理带；低于 24=书面碎句腔 |
| M2 | 句长爆发性 std/mean | **0.45-0.70** | 0.47-0.57 | 低于 0.4=节奏均匀（AI 信号）；高于 0.8=短拳滥用 |
| M3 | 短句(≤8字)占比 | **≤8%**（峰值短拳 ≤3 处豁免） | 1-3% | 超标=书面短句美学，偏离口播 |
| M4 | 长句(≥30字)占比 | **≥35%**（向 50% 靠） | 54-58% | 口语流水句是主形态 |
| M5 | 句长 std | **15-22** | 16.5-20.3 | 绝对波动带 |
| M6 | 语速核算 | **5.0-6.7 字/秒（300-400字/分）** | 字数÷成片时长实测 | 字数档×片长自检：中片 2500-3800 字≈8-13min ✓ |
| M7 | 红线三判据 | 判1三要素/判2地名分级/判3灾难错位 | （SKILL.md 质量层） | 并入本门一并过 |
| M8 | 语感密度（口语皮） | 呢1.5-2.5/千字·啊1-2.5/千字·设问空拍≥2 | 对标ASR原值：呢3.4-8.4·啊0.6-3.6（含语气膨胀） | 工具 scripts/oral_texture.cjs 实测；低于带=书面腔变味（09-03 实证），高于带=撒奶油；啊带按第1期含回味段实测2.1重校（仍在对标散布内） |

注：ASR 文稿无段落结构（整节连排），段层阈值不设机器门；段落层走语义门 S1/S2。

## 二、语义门（LLM 自查，逐项给行号）

| # | 检查 | 通过标准 | 结构病信号 |
|---|---|---|---|
| S1 | 段尾形态轮换 | 连续同名收尾（名词句收/问句收/引语收）≤2 段 | 「六十秒。」「两层。」「同步的。」式连续名词短句收=钩子句式每段重复（原样稿实病） |
| S2 | 段落节拍 | 长节拍段与短拳段交错；禁全均质段 | 相邻段长近同构率 >60%=模板感 |
| S3 | 钩子句式去重 | 同一钩子模板全篇 ≤2 次 | 每段结尾都悬+设问=新模板化 |
| S4 | 转场多样性 | 节拍间过渡不用同一句式（「然后/接着/这时」轮换或零过渡直切） | 统一转场词=可预测 |
| S5 | 峰值位置审计 | 短拳只允许出现在：恐峰/泪峰/结尾戛止（≤3处）；铺垫段禁短拳串 | 铺垫段碎句=紧张感错配 |
| S6 | 节奏合同复核 | 微高潮间隔/段末必悬/无事件区≤3min（SKILL.md 节奏合同） | 结构合规但节拍失序 |
| S7 | 破绽与回收 | 铺垫段破绽已埋；结尾回收日常物+感官签名（十条硬规 11/12）；**伏笔图谱建档**（fuji 法：伏笔｜埋设+原文｜回收+原文｜功能，每期必建，断裂伏笔/凭空回收=打回；跨期伏笔登记到排期表对应期行） | 语义层，机器测不了；图谱实测抓过3个账目bug（09-03） |
| S8 | 语感指纹细节 | 停顿位规律5条（时间状语自成一顿/转折词领起新句/数字前减速/悬念短句收尾/设问空拍）；插入语口头禅≤5；转述体优先（我妈就说…）；体选型=咱呢是吧商议感 或 他说好，啊切镜感（视频蒸馏§4） | 语义层；骨架对皮不对=被朗读的短篇小说（变味实证） |

## 三、过门动作（按序）

1. 成稿（或改稿）→ 剥标注 → 跑 structure_metrics → 对 M1-M7 逐项判定；
2. 越界项回稿：短句并流水句（功能词连接，实词不动）、段尾轮换、铺垫段去碎句——**禁用同义词替换**（那是词层，P3b 已证低效且伤文）；
3. 语义门 S1-S7 逐项自查给行号；
4. 过门后再走 deslop-standard 审计与 aidetect（相对指标，剥标注，≥3000 字）——顺序不能反：**先结构后词层**，词层微调放在结构定形之后，否则结构重排会打散词层修改。

## 四、与相邻工具的分工

- 本清单=结构层门（主杠杆，用户假设+检测器原理支持）
- deslop-standard/human=词层与情绪层（次杠杆，最后做）
- aidetect=检测（地板效应实证：原版 2/10 但结构指纹偏离基线一倍——它测不到结构层，不能单独当验收）
- 朱雀=外部真判据（短文本噪声带 ±0.04，≥3000 字贴检）

## 五、实证记录

**2026-09-03 朱雀三点梯度对照（第 1 期）**：A 原版 11% → B 纯结构实验版 31% → C 结构+具体化正式版 约50%。B 与 A 长度几乎相同（2021/1981 字）、唯一变量=结构，真人率 ≈2.8 倍——**结构层主杠杆实证成立**，本清单的机器门 M1-M8 即该杠杆的操作化。证据与判读表见 examples/朱雀对照实验说明.md。

**2026-09-03 语感门依据（变味诊断）**：C 版结构指纹全绿但用户读感「变味」——oral_texture.cjs 实测语气词密度呢0.4/千字 vs 对标 3.4-8.4（差8-20倍）→ **骨架对、皮不对＝被朗读的短篇小说**。口播化回填后由 M8/S8 门禁。伏笔图谱法（fuji）同期实测抓出3个账目bug（时间排序/天数笔误/送达面），升格为 S7 标配。

## 六、待办

- M1-M6 阈值带基于 5 份样本，每新增一份对标文稿（每期节目发布后回收自己成片的 ASR）应重新校准——对标自己的过检稿比对外部理论更重要
- 段层指纹：自制成片发布后，用 Whisper/FunASR 反切自己的成片，可补段落呼吸指纹（ASR 对标稿无段落结构的空缺）
- 全片长文本贴检：成片后 ASR 回灌 ≥3000 字再测，逼近朱雀可靠阈值，降低短文本噪声
