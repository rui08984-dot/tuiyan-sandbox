# 局鉴

**把一局狼人杀拆成结构化声称，抓出互相矛盾的地方，每条结论都能回查到原始发言。**

它不替你下结论。

---

## 先说清楚它是什么，不是什么

网上叫「AI 狼人杀助手」的东西，大多在承诺一件做不到的事：**告诉你谁是狼**。

局鉴不承诺那个。它承诺三件都能验的事：

| 它做的 | 怎么验 |
|---|---|
| 把你听到的每一句话拆成结构化声称（谁、说了什么、关于谁） | 打开任意一局看那张表，每行都指着一条原始发言 |
| 找出**互相矛盾**的地方，并说清是哪两句打架 | 矛盾清单每条都带原文引用，缺一条都出不来 |
| 每条矛盾都说得出「也可能不是矛盾」的理由 | **说不出无辜解释的矛盾，不许入库、不许展示** |

第三条是硬约束，写在存储层里（`src/db/store.js` 的 RD1 校验），删不掉、绕不过。

### 为什么是「复盘器」不是「破案器」

这不是谦虚，是实测结论。局鉴的前身在同一台机器上跑过一次预注册的盲测（5 局真实对局、双层档案、防幻觉抽查），读数是：

- 局鉴的机制层站得住：矛盾清单引用**零虚构**，有据可查的硬矛盾抽查通过率 100%
- 局鉴的**价值层没站住**：「嫌疑排序比人工更准」未获证明，某一局里甚至输给人工

所以它被定位成**对局复盘 / 说书人复盘工具**：局后帮你把这一局理清楚——谁和谁对不上、每次判断翻转是因为哪句话。

**如果你要的是「现在告诉我谁是狼」，这个工具不适合你，那件事目前没人做得可靠。**

## 三分钟跑起来

```bash
git clone https://github.com/rui08984-dot/jujian.git
cd jujian
npm install
node scripts/doctor.cjs     # 体检：查 Node 版本、角色数据、依赖、端口
npm start                   # 起服务，默认 http://127.0.0.1:8788
```

或者从 npm 装到全局：`npm i -g jujian` —— 那之后 `jujian` / `jujian-mcp` / `jujian-bench` 三个命令直接可用。
（只跑 `npm install` 的话它们**不在 PATH 上**：用 `npx jujian …` 或在仓库里写 `node bin/jujian.cjs …`。）

端口被占就换一个：`PORT=8899 npm start`（Windows PowerShell 写 `$env:PORT=8899; npm start`）。

只需要 **Node ≥ 22.13**（或 ≥ 23.4）。**没有数据库要装，没有原生模块要编**（存储用 Node 自带的 `node:sqlite`）。

★版本门槛为什么不是 22.5：`node:sqlite` 虽然 22.5 就有，但那之后仍在 `--experimental-sqlite` 标志后面，
且**不是一条直线**（实测：22.13 解除、23.0–23.3 又回到标志后、23.4 再解除）。少写这一句，
用 22.5–22.12 或 23.0–23.3 的人会看到体检全绿、然后每个命令都报 `No such built-in module`。

想先看一眼它会做什么，不用起服务：

```bash
node scripts/smoke.cjs
```

它会走完一局：建局 → 录三句发言 → 入账 → 天结算出矛盾 → 撤回 → 导出 → 演示三条数据护栏 → 验证幂等 → 验证令牌门，全在内存库里跑完，零网络。
（它要 `fastify`，所以先跑过 `npm install`；真正零依赖的是命令行 / MCP / 盲测那三个入口。）

## 它支持哪些游戏

| 游戏 | 怎么算的 |
|---|---|
| **狼人杀** | 通用引擎：对跳、自相矛盾、声称 vs 行动、死者活跃 |
| **血染钟楼 BOTC** | 三本剧本（tb / bmr / snv）、130 个角色、恶魔/爪牙/醉酒/中毒四条专属谓词 |
| **阿瓦隆** | 适配器形态：任务成败、队伍审批、刺杀 |
| **剧本**（纯记录） | 不做矛盾推理，只记 |

**加一种新游戏 = 往 `src/kernel/adapters/` 丢一个文件。** 前后端一行都不用改——这是 `GET /api/adapters` 当场兑现的承诺，前端拿到的游戏列表会自动多一项。

## 天结算：一天结束时它给你什么

```
矛盾清单   每条：哪两句冲突 ｜ 欠定度(high/mid/low) ｜ 无辜解释(≥1 条) ｜ 原文引用
假设       当时你在怀疑谁、依据哪些发言
明日清单   明天该盯什么（不自动勾——只有你知道答案）
```

矛盾清单里的「无辜解释」值得单独说。例如它报「3号和8号同时声称预言家，互斥必有一假」，同时会说：

> 也可能是其中一人在跟风起跳；也可能是记错了自己的位置。

**没有这类解释的矛盾不允许出现。** 因为「这两句话冲突」如果说不出「也可能不冲突」，那它多半不是冲突，只是解析器嘴硬。

## 三条不许越过的边界

1. **默认不联网。** 不配 key 时所有分析走确定性模板，零出网，功能全可用。
2. **默认只听本机。** 要让同一 Wi-Fi 下的手机连，必须**显式**设 `JUJIAN_HOST=0.0.0.0` **并且** `JUJIAN_SHARED_TOKEN`——少一个就**拒绝启动**（不是警告）。库里是你这一局每个人的发言和身份声称。
3. **key 只从环境变量读，绝不写进任何文件。** 也不发去任何地方。

## 能力清单

21 个 HTTP 端点，全在 `docs/CAPABILITIES.md`（每条写了「它做什么／越界了怎么办」，并注明它**不做什么**）。摘要：

| 组 | 端点 |
|---|---|
| 建局与席 | 建局 · 列表 · 详情 · 状态回放（可按天截断）· 导出 · 改席位名 |
| 录入 | 宏录入三型（跳身份/查杀/金水）· 自由文本抽取 · 确认入账 |
| 改与撤 | 声称改/撤 · 行动改/撤 · BOTC 声称改/撤（撤回后一律 409，不许改写） |
| 复盘 | 天结算（异步）· 参谋卡按天回读 · 游戏类型登记 |

**写口幂等**：带同一个 `Idempotency-Key` 重发建局，只建一次。AI 客户端默认会重试，而账本不可改——不幂等就是重试一次多一局。

## 命令行

饭桌上你只想敲一行，不想开浏览器。
下面这些裸命令（`jujian` / `jujian-mcp` / `jujian-bench`）来自包的 `bin` 声明 ——
用 `npm install -g jujian` 全局装、或在本目录 `npm link` 之后才有；
不想装就等价地写 `node bin/jujian.cjs ...`。

```bash
jujian new "周五饭桌局" --players=12      # 建局
jujian 1 claim 3 预言家 --day=1           # 3 号跳预言家
jujian 1 check 3 1 --day=1               # 3 号查杀 1 号
jujian 1 good 7 5 --day=1                # 7 号给 5 号发金水
jujian 1 say 3 "我是预言家，昨晚验的4号"   # 自由文本抽取（走 AI）
jujian 1 advise --day=2                  # 天结算，直接打印矛盾清单
```

★`say` 产出的是**待确认卡**，它自己**不落库** —— 确认入账在网页或 `POST /api/games/:id/events/confirm`。
宏三型（`claim` / `check` / `good`）则是直接落库的：它们不经 AI，没有需要人核的东西。

`advise` 的实际输出长这样（下面这局的命令是：3 号、6 号各跳一次预言家）：

```
第 2 天 · 天结算
矛盾 1 条 ｜ 假设 2 条 ｜ 明日清单 2 项

  · [对跳] 唯一角色「预言家」被 3 号（claim#1）与 6 号（claim#3）同时声称/指认，互斥必有一假
    欠定度 high ｜ 无辜解释：
      - 女巫可能毒错人/救错人——毒与守是合法谎言（药剂类）
      - 信息差：夜晚视角不同或没听到关键发言（信息差类）

  明天该盯：
    1. 明天白天盯 1、2 号是否继续补身份，判断悍跳链
    2. 核对夜里刀口与用药时序，验证信息差是否成立
```

加 `--json` 全部命令都给机器读（`export` 默认就是 JSON，方便 `> game.json`）。
完整命令表：`jujian help`。

## 接进 AI 客户端（MCP）

```bash
jujian-mcp        # stdio，8 个工具
```

```jsonc
// 客户端配置示例
{ "mcpServers": { "jujian": { "command": "node",
  "args": ["/你的路径/jujian/bin/jujian-mcp.cjs"] } } }
```

Windows 上 JSON 里的路径用双反斜杠（或正斜杠），例如把 `/你的路径/` 换成
`你的盘符:\\你的路径\\`，其余照写。

### ★这个 server 不能替你往账本里写任何东西

8 个工具里 **5 个读、3 个只起草**：

| 读（真的查库） | 只起草（一个字节都不写） |
|---|---|
| `jujian_list_games` 列局 | `jujian_record_claim` 起草一条声称 |
| `jujian_game_state` 读整局状态 | `jujian_record_speech` 起草一次抽取 |
| `jujian_review_card` 读参谋卡 | `jujian_review_day` 起草一次天结算 |
| `jujian_contradictions` 只看矛盾清单 | |
| `jujian_game_types` 支持哪些游戏 | |

后三条返回的永远是**草案**，`gate` 恒为 `NOT_CONFIRMED`、`do_not_retry` 恒为 `true`，
并附一条人可以直接粘贴的命令。要真写入，由人自己跑。

**为什么不给它写权限**：局鉴的全部价值是「矛盾清单里每一条都能回查到原始发言、
每一条都说得出也可能不是矛盾的理由」。这个价值完全建立在「账本里那句是谁说的」可信之上。
一条没人核对过的声称混进去，矛盾检测就在编造上推理，而它的输出看起来和有据可查的一模一样。

### 兼容两套协议

新规范（2026-07-28）走 `server/discover`。**老客户端只发 `initialize` 也照样能连** ——
只支持新规范的话，它们会拿到 -32601，症状是「明明装上了却连不上」，那是最难排查的一类装不上。
新旧两条路径都有用例钉着。

## 网页

```bash
npm install && npm start      # 只有这一路需要装依赖
```

打开 http://127.0.0.1:8788 —— 四个屏：**局**（列表与建局）、**录入**（宏三型 ＋ 自由文本）、**复盘**（矛盾清单）、**关于**。

**没有构建步骤。** 那些文件是浏览器直接读的原生 ES 模块，CSS 也是原样的。
理由和存储层选 `node:sqlite` 是同一条：**局鉴的承诺是「下载即跑」**，
给界面加一条构建链（npm install ＋ 打包器 ＋ 产物目录），等于在最常用的一路上把这个承诺弄丢。

复盘台是产品的正脸，所以矛盾清单按四段渲染，一段都不能省：

```
[对跳] 唯一角色「预言家」被 3 号与 6 号同时声称，互斥必有一假   ← 哪两句打架
欠定 high ｜ 几乎无解释空间 ｜ AI 补全                        ← 证据有多硬
也可能不是矛盾 —— 女巫可能毒错人/救错人（药剂类）…            ← ★免责，不是装饰
[回查原文（2）]                                               ← 点开看原文
```

★第三段是产品的地基：**说不出「也可能不是矛盾」的理由，那条矛盾就不许出现在这儿。**

## 拿真实对局验它

`bench/archives/` 下有 **5 局真实对局的双层档案**：公开层（牌桌上所有人都知道的信息）
＋ 真值层（真实身份，盲测时不可见）。一条命令跑出读数：

```bash
jujian-bench
```

★5 份档案里**能进读数的是 4 局**：`replay-botc-rulebook` 那份只有玩家名字、没有座位号，
而真值评分依赖座位号 —— bench **不猜**名字到座位的映射，如实把它登记为「未覆盖、不计入分母」。
（宁可少一局，也不猜一局。）

```
【replay-werewolf-lyingman-s02e01】11 人 · 3 天
  事件 31 条，其中抽到声称的 10 条（覆盖 32%）｜ 声称 11 条（角色 4）
  真值：狼 [1,4,5,6] ｜ 主考点 6
  矛盾 2 条 ｜ 涉及真狼 2 ｜ 候选误报 0
  H2 引用真实性 ✔ 全部可回查 ｜ RD1 守卫 ✔ 如期拦下无解释的入库
  角色对跳：
    · witch ← 6 vs 10　[涉及真狼 true，命中 1/2]
```

它证明的东西：**在真实对局上，局鉴能找到真的矛盾**——lyingman 那局的 6 号与 10 号
双女巫对跳（E-7/E-8 明写），而 6 号正是该局四只狼之一。

### 这条 bench 刻意不测什么

| 不测 | 为什么 |
|---|---|
| 抽取质量 | 这里的抽取是**档案格式适配器**（规则），不是产品的 LLM 抽取。**覆盖 20%，读数就该被少信一点** |
| 嫌疑排序是否优于基线 | 预注册协议已判负（某局里结构化账本输给人工）。bench 不翻案也不重跑 |
| 矛盾「有效率」 | 那是**人工抽查**，机械读不出来。bench 把它标成「需人工」而不是编一个数 |

**不可复跑的评测不是评测，是许愿。** 所以这套 bench 零网络：抽取是规则，读数逐条可复核，
档案被动、真值改了对跳抓不到，都会在提交那一刻响。

## 它从哪来

局鉴是从**推演沙盘**里独立出来的一个模块。它继承了两样东西，都在盘上可查：

- **领域内核**（`src/kernel/`）：角色表、BOTC 矛盾比对器、阿瓦隆适配器、狼人杀检测器。这些文件是**平移**不是重写，所以行为零漂移。
- **一条机制上的教训**：矛盾清单必须带无辜解释（RD1），这是它全部产品价值的根。

它**没有**继承的：预测计分账本、玄学排盘、网页观测台。

平移过来的文件有一条**漂移守卫**（`test/kernel-drift.test.cjs`）逐个核对 sha256：任何一侧改动而另一侧没跟，立即响亮地失败。守卫只认两处「有据可查的接缝」，都写在用例里。

## 常见问题

**Q：它能提高我的判断力吗？**
A：它不提高你的判断力，它把你的判断**记下来并摆在一起对照**。矛盾是你自己的两句话打架时，它替你指出编号。判断力还是你的。

**Q：为什么查出来的东西这么少？**
A：因为你只录了三句话。一局十二人打三天，通常有两三百句发言——矛盾是从量里长出来的，不是从一次对话里问出来的。

**Q：它会把我这局传到网上吗？**
A：不会。库是本地的 `data/jujian.db`。唯一的出网是你自己配了 key 并发起分析时，那次分析所需的文本。局鉴没有任何上传口。

**Q：能不能用手机在饭桌上录？**
A：可以，但要显式开：

```bash
JUJIAN_HOST=0.0.0.0 JUJIAN_SHARED_TOKEN=你自己想的随机串 npm start
# 手机浏览器打开 http://<本机局域网IP>:8788/?jujian_token=<那串字符>
```

Windows PowerShell 的等价写法（POSIX 那套前缀赋值在 PowerShell 里不生效）：

```powershell
$env:JUJIAN_HOST='0.0.0.0'; $env:JUJIAN_SHARED_TOKEN='你自己想的随机串'; npm start
```

**开了令牌之后，一切请求都要带令牌**（读口和 `/api/health` 也要——health 会报出库路径，那属于信息）。
不开令牌就对外监听会被**拒绝启动**——这是故意的。

**Q：数据能带走吗？**
A：`GET /api/games/:id/export` 导出整局 JSON，带元信息和计数。库文件本身是单个 SQLite 文件
（默认 `data/jujian.db`），直接拷走即可。
