## 2. 已收口勿重做（含负结果与失败过的路）

### 2.1 定位：复盘器，不是破案器（**这是产品定位，不是待选项**）

依据是预注册盲测（5 局真实对局、双层档案、防幻觉抽查）：

- 机制层**成立**：矛盾清单引用零虚构，可复核硬矛盾抽查通过率 100%
- 价值层**未证**：「嫌疑排序比人工更准」未获证明，**某一局里结构化账本输给人工**

⇒ 定位收窄为复盘器。README 第 4 行、`/api/health` 的 `positioning` 字段、
MCP 的 `instructions` 三处都写了，并由测试 ⑦ 钉住三者一致。

★**不要**在任何地方加「嫌疑排序」「谁是狼」——那是被实测证伪过的承诺。
`test/web.test.cjs` ⑧ 会判红。

### 2.2 内核血统：平移，不是重写

`src/kernel/` 下 5 个文件是**从沙盘逐字节平移**的（sha256 相同），只有两处「有据接缝」：

| 文件 | 接缝 | 为什么 |
|---|---|---|
| `botc/roles.js` | 数据源路径 → 自带 `data/roles-zh.json` | 独立项目不能指回沙盘目录 |
| `botc/extractPrompt.js` | 惰性 `require('./claims')` → `require('./wordmap')` | ★原写法把内核拉向存储层 |

`test/kernel-drift.test.cjs` 逐个核对 sha256，接缝以外任何差异立即失败。
**沙盘那边改了内核文件而局鉴没跟 ⇒ 守卫会响，这是设计意图，不是误报。**

### 2.3 三条不许放松的边界（违反 = 弃棒）

1. **RD1**：`innocent_explanations` 必须非空 —— 说不���「也可能不是矛盾」的理由，那条矛盾不得入库、不得展示。（`src/db/store.js` 存储层校验，绕不过）
2. **MCP 不能写账本**：8 个工具里 3 条写意图工具恒返回草案（`gate:'NOT_CONFIRMED'`）。理由：一条没人核对过的声称混进去，矛盾检测就在编造上推理，**而输出看起来和有据可查的一模一样**。
3. **零依赖面**：CLI／MCP／盲测三个入口不许沾任何第三方包。`test/zero-dep.test.cjs` 守着，理由是「多一道 npm install 就多一批装不上的人」。

### 2.4 ★本轮抓到的 13 个真缺陷（都已修，全部有对应测试）

**后端 5 个**，其中最严重的一个是**数据丢失**：

- ★**同日重结算把当天存档清空**：先删后写两步之间无事务，写失败被 catch 吞掉只留一句 `save_error`
  ⇒ 已把事务边界收进 `store.replaceAdvisorCard`（删与写同一事务）
- **内核藏通往存储层的边**：`extractPrompt.js` 在**函数体内**惰性 require 落库模块
  ⇒ ★我第一遍体检 grep 的是文件头 require，**结论下得太早，检查就不够**
- **人数上限声明了没人用**：`util.js` 导出 `MAX_PLAYERS=24`，路由却硬编码 `>99`
- **同一天重结算不灌水**、**bench 漏了 `.join` 让 content[0].text 变成数组**

**前端 4 个**，其中三个属于「看起来跑起来了」：

- ★**路由把捕获组传错**：`found.run([path, params])` 让 `m[1]` 拿到 params 而非捕获组 ⇒ `Number(params)=NaN`
  ⇒ 所有带 id 的路由悄悄退化成列表页。**地址栏是 `/review/1`、页面是「选一局」，而正则单独验时全过**

- ★**`/../package.json` 返回 200** —— 「存在即发」意味着**谁往 `web/` 放个文件就自动对外可访问** ⇒ 改成扩展名白名单

- ★**干净克隆后 README 成 CRLF ⇒ 测试道红**。根因：库里存的是 LF，但作者本机 `core.autocrlf=false`，
  本地永远绿。**「在我这儿是对的」不等于「发出去是对的」** ⇒ `.gitattributes` 定死换行 ＋ 一条守卫盯住它本身

## 4. 铁律与纪律（违反 = 弃棒）

1. **闸门不许绕过。** `gates/gates.cjs` 四道：测试／冒烟／体检／盲测。红了就是红的。

## 6. 环境备忘（高频坑速查）

| 坑 | 症状 | 处置 |
|---|---|---|
| ★**`node:sqlite` 的免 flag 门槛不是一条直线** | 原写「≥22.5」是**错的**。实测免 `--experimental-sqlite` 的门槛：**22.12 ✗／22.13 ✓／23.0–23.3 ✗／23.4 ✓**。写错会让那一串版本的用户体检**全绿**、然后每个命令崩在 `No such built-in module: node:sqlite` | `engines.node = "^22.13.0 \|\| >=23.4.0"`；`doctor` 按实测区间判并给出「加 flag」的照抄命令；`test/package.test.cjs` ⑥ 钉住 |
| **`web/package.json` 是 ES 模块标记**，只在 Node 侧用 | 删了它，`test/render.test.cjs` 的动态 `import` 报 `Cannot use import statement outside a module` | ★**随包发**（2026-10-06 反转：原先「发行包排除它」，但发行树带着 `test/`，排除它 ⇒ **发行树自跑测试 3 条红**）。`.gitattributes` 同理（`readme.test.cjs` ⑭ 要读它） |
| ★**npm 包与发行树是两份不同的产物** | `npm pack` 走 `package.json` 的 `files`，`build-release.cjs` 走自己的清单 —— 两份都要各自维护，漏一个就是「本地全绿、装出来缺件」 | `test/package.test.cjs` **真跑 `npm pack`** 取清单来核（不核对自维护清单，那等于拿实现验实现） |
| **静态资源缓存顽固** | 改完 `app.js` 刷新没变化，且同一 URL 只改 hash 根本不重载文档 | 服务端已加 `Cache-Control: no-store`；改前端时用 `?v=N` 兜底 |
| **`npm install` 必须先有 `package.json`** | 本轮踩过：在 `jujian/package.json` 创建前跑 npm，npm **向上找到沙盘根**并改了它的依赖 | 局鉴已有 `package.json`；若拆仓操作先建文件 |
| **node:sqlite 的行是 null 原型对象** | 对它们 `String()` 抛 `Cannot convert object to primitive value` | 渲染前 `plain()` 转普通对象（`src/mcp/tools.cjs`、`bin/jujian.cjs` 都有） |
| **Fastify 5 的 `app.get(url)` 只收字符串** | 传正则抛 `URL must be a string. Received 'object'` | 用 `'/*'` 通配，`req.params['*']` 取路径 |
| **闸门里 `node --test` 默认并行** | 两条「只并行时红」的并发事故（见 §2.4） | 需要独占的测试各自用临时目录，不要藏/改共享状态 |
| **Bash 里的反引号与 `$`** | `node -e` 带模板字符串/反斜杠会被 shell 吃掉 | 含特殊字符的编辑一律用 Edit/Write 工具，**不要用 Bash 拼** |
