## §2 共享骨架（walk-forward 重放）

- **同一实现、四臂共用**：逐题按 `resolved_at` 升序遍历；**题 t 的读数只允许使用 `resolved_at < t` 的结局**（照 E2 PREREG §6 M5② 的原口径，**同一把尺、不另立**）。
- **同刻批量零信息流**：同一 `resolved_at` 的题**互不可见**（批内不得相互喂结局）。
- **只读**：骨架**零账本写、零 LLM 输出概率**（铁律④；四臂全为读侧确定性估计量）。
- **确定性**：同一输入两次重放须**逐字节同**（照 E2 重跑零选择性先例）。

## §5 撤票规则（两窗无增益）

- **窗定义（★本条为补白：蓝图原文只写「连续两窗无增益」，未逐字给定窗的切法）**：窗＝**按 `resolved_at` 的日历月**；「连续两窗」＝**相邻两个自然月各独立跑一次判据**；两月均**未过 C1** ⇒ 该候选**撤**，负结果入 `negative-results` 账本（四要素齐）。
- **薄样本保护**：某月格内 `n < 30` ⇒ 该月**并入下一窗**（**禁止拆细到无统计功效**）。
- 「无增益」＝**未过 C1**（含「CI 跨过 +0.005」与「显著更差」两种），**不含** C2 单条不降。

## §6 功效核算与 MDE 义务（★本条为补白：蓝图未给功效口径）

- **义务**：每臂每次跑批**必须报 MDE**（照 E2 C2 的 MDE 义务）。
- **口径**：非劣判据的 MDE ≈ `2.8 · σ̂_d / √n`（σ̂_d ＝**配对差的标准差**，**须在实现期以真实配对差估计**，禁沿用别处）。
- **敏感性（冻结时的指示性上界，仅表量级、不得当读数引用）**：

| σ̂_d | MDE @ openmeteo(528) | MDE @ dbnomics(79) |
|---|---|---|
| 0.01（两臂输出接近） | 0.0012 ✅ < 0.005 | 0.0032 ✅ < 0.005 |
| 0.05（两臂输出差异较大） | 0.0061 ⚠ > 0.005 | 0.0157 ⚠ > 0.005 |

- ⇒ **读法**：C1 可过与否**几乎完全由 σ̂_d 决定**（即两臂输出有多接近）；**σ̂_d 小时非劣可证，大时不可证**。**这不是缺陷，是判据的正确行为**——但**引用者必须同时报 σ̂_d 与 MDE**，否则「CI 上界 > 0.005」会被误读成「臂更差」。

## §7 披露义务（写死）

1. **薄格**（`n < 30`）一律**只作方向披露**，禁入判读。
2. **C2 的 resolution** 与 C1 **并列披露**；**禁以「CI 含 0／上界超阈」单独声称臂劣**（须连 σ̂_d、MDE 一起报）。
3. **未过非劣 ≠ 更差**：两者是不同的结论，报告须分开写。
4. **本队任何增益不得跨层池化**；格间比较一律用 Δ 或 resolution。
