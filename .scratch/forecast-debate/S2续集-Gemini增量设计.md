## ① ACR 抗投毒鲁棒性实验

**动机**：Gemini 原提案=replay 事件流注入 10-50% 结构化谎言→测矛盾检测+参谋卡劣化曲线；红队裁定为全蓝图最有价值一条（蓝图红队评估 §五.1【已验证】），直接喂命题 A「机械矛盾特征=外生校准信号」。红队同时裁定其原话「漂移率≤15%」未定义、按原样不可测（§四.4【已验证】）——本设计把它算子化为 TV 距离判据。

**注入协议（三类，PREREG-ACR 冻结后执行）**【推测=协议细节为本棒设计】：
语料=既有 sim corpus 31 局（M0 id=7 + M1 gid=8..37，events=310/claims=337，全 source=sim 带真值——p11 §7.1/§7.3【已验证】）。注入率 ρ∈{10%,30%,50%}=被注入事件数/该局公开事件流 E 行总数；每局每 ρ 独立注入一轮=31×3=93 污染运行+31 零污染基线运行。注入脚本只动 replay 内存/临时副本，库与原 replay 文件只读。
- A 类·改票型：把真实投票事件改写为与后续结算矛盾的票（如投狼票改投民票）——测跨事件一致性检测；
- B 类·插假声称：插入与已记录事件机械矛盾的声称（死亡角色再发言/身份声称与 truth 相悖）——测声称-事实核查；
- C 类·时序错位：事件重排（放逐结果前移到投票前/死亡时点错位）——测时序活性检查。

**测什么**：
- 机械矛盾检测召回/误报：contradictions.js（p1b/src/botc/ 五文件之一，11.1KB 实存——红队 §一【已验证】；只读调用）。召回=注入事件被标记比例，A/B/C 三类分报、禁合并平均（防平均数掩盖覆盖缺口）；误报=零污染运行被标记事件比例。
- 参谋卡预测分布劣化：每局跑参谋卡（advisePrompt.js 口径【已验证实存】），产出两族离散分布：P_win=「狼人胜/好人胜」二值分布；P_vote=首场放逐候选席位 simplex。判词温度预注册固定 0.2（判词重跑三温度 0.2/0.7/1.0 低温端【已验证，队长规划 §1.3】，取低温减采样噪声）。

**可证伪判据（预注册式，冻结前待用户确认）**【口径来源已验证；数字为本棒预注册提案】：
- 主判据：max(TV_win, TV_vote)≤0.15 @ ρ=30%，31 局取中位数（90 分位作伴生读数，>0.15 触发脆弱性告警）。TV(P,Q)=½Σ|P_i−Q_i|（离散分布全变差距离【教科书定义】）。此即 Gemini「漂移率≤15%」的算子化（§四.4 悬案闭环）；分族计算取 max，避免拼接权重拍脑袋。
- 噪声地板协议：零污染运行跑两遍得 TV_self——若 TV_self>0.05，采样噪声淹过效应，判据作废重设计，不得硬判。
- 副判据（声明性）：B 类召回≥70% 且零污染误报≤5%；不过线则结论降级为「检测器本身不可用，TV 读数无意义」。

**失败长相与砍件条款**：①TV 全线超标且副判据过线→命题 A 在投毒场景被反证：ACR 不进工程，产出=投毒脆弱性档案+「机械矛盾特征不可作外生校准信号」负结果报告；②A/C 类召回≈0 而 B 类过线→只出检测器覆盖缺口档案，补检测器=新 wrapper 另行立项（禁改文件不碰）；③TV_self 地板失效→实验设计缺陷，重设计不硬跑。

**执行前置与工时**：用户令=修复线收口后（不与重跑 R-A/R-B 抢资源——队长规划 §五.2 资源优先级【已验证】）；红队原裁定「G1 后可立项」（§五.1）——两者取严。工时：注入器+重放脚本 1-1.5 天、124 运行跑批 1 天、统计报告 0.5-1 天，合计 3-4 天。
**成本估算**【推测，单价以 TokenRhythm 账单为准】：判词类调用 M1 实测 15.5k tokens/局（p11 §7.3【已验证】）；124 运行×参谋卡 3 调用×约 3k tokens≈1.1M tokens≈¥1-5 量级。零落库。
**合规自证**：不碰出题机与五元组（只读 replay 消费侧——与红队否决④「改变数据生成过程」划清界限）；contradictions.js 禁改只读调用；实验件不进 CI/不进门禁（L0 只记不评）；结论只进研究档案不进 UI。

**竞品对照（related work 定位）**：竞品三篇——arXiv:2607.10645（MafiaScope）、arXiv:2607.10814（Auditing）、arXiv:2608.24691（belief miscalibration）【已验证=队长已核三篇存在】——只做信念探针/审计，均无抗投毒鲁棒性实验、也无显式概率结算统计管线；ACR 是本项目 related work 上的独有增量之一（投毒注入×机械矛盾检测召回/误报×TV 劣化曲线的组合，三篇均未覆盖）。【未验证】「竞品无此实验」的口径来自队长核对结论，本棒未逐篇读全文——对外引用前须按爬全文铁律回读三篇原文核对措辞，禁止直接转写进论文 related work。

## ③ VoI 形式化并入 J5 开口规则

**动机**：Gemini 原提案=把 VoI 形式化作 S2②（J5 selective 开口规则）的数学语言补强、conformal 集合宽度作 VoI 代理（红队 §五.3【已验证】）。J5 开口规则=S2 TOP2、「11 篇里最大缺口」（S2 §二 J5.1）：何时开口给判断、何时闭嘴只给账本。论文5 §6.3 实证：三准则同时=唯一反超 crowd 的条件（0.240 vs 0.247，>2SE，覆盖 22%——J 笔记表C【已核】）。

**数学骨架**【推测=映射为本棒设计；公式件全部已核原文】：
- VoI 语义：开口价值=损失(闭嘴)−损失(开口)，损失用 Brier（proper score，J 笔记 P1【已核】）。真 VoI 需真值不可在线算→用两代理做门控。
- 代理 1·conformal 集合宽度：F9 区间 C(x)=f̂(x)±u(x)q̂，q̂=F3 调整分位数 Quantile(s₁..sₙ; ⌈(n+1)(1−α)⌉/n)（K 笔记 F3/F9【已核】）；二值题集合={0}/{1}/{0,1}，C=全集⟺无信息（F22：p 值粒度 1/(n+1)；n=30 最小可用 α=1/31≈0.032，更小则 q̂=∞ 全集——K 笔记【已核】）。二值域「宽度」操作化=集是否退化为全集（退化=宽度∞）。
- 代理 2·3 路判词分歧度 D(x)：F9 的 u(x) 取「3 路判词方差」=diversity-scaled conformal，路间分歧大→区间自动宽（K 笔记 ⑦3【猜想可行，未验证】）。
- F47 合流（S2 K4.1 方向）：selective 过滤效率受 Thm3 保留率差≤C′·MSE^(β/(β+2)) 约束（K 笔记 F47【已核】）——3 路集成 MSE 越小，开口过滤的数学空间越大：开口规则给语义，F47 给边界。

**门控公式与参谋卡行为规格**【推测】：
open(x) = 1{C(x)≠{0,1}} ∧ 1{D(x)≤τ_D} ∧ 1{基率∈[0.3,0.7]}——三条件与 J5 三准则同构（conformal 证据充分/路间共识/基率帮不上的不确定区）。
VoI≤0（任一条件不过）→ 参谋卡只给账本块：基率+同型局历史+矛盾特征计数（命题 A 件）+固定文案「本局无增量证据，仅出示账本」；UI 禁预测字样不变（队长规划 §五.2 口径【已验证】）。open=1 → 输出判断，思路非答案。
τ_D 定法：离线校准使开口率落 20-40%（Halawi 表C 三条件覆盖 22% 先例【已核】），校准值落盘冻结，禁事后调。
伪代码（行为规格层，非实现）：
    D = var(paths_3)                        # 3 路判词方差
    C_full = both_pvalues_gt_alpha(x, cal_scores, alpha=0.1)   # F22：双 p 值均>α → 全集
    open = (not C_full) and (D <= tau_D) and (0.3 <= p_base <= 0.7)
    # open=False → 卡片只渲染账本块；open=True → 附判断（思路非答案）

**可证伪判据（预注册两级）**【数字为本棒提案】：
- PREREG-VoI-a（立即可跑，弱口径）：L0 存量 90 条 v2 判词（纯题面，R-A 口径【已验证，队长规划 §1.2】）上，开口子集 ΔBrier=(Brier_v2−Brier_base) < 全量 ΔBrier（方向性主判据）；差值≥0.06 记「超噪声带」（n=60 噪声条款 ±0.06 先例口径【已验证，队长规划 §二】）。如实声明：v2=信息真空域，此为弱口径（开口规则在此域=「LLM 何时比基率差得少」）；结算证据（v1）不进本验证——防读数泄漏（R-A/R-B 拆分同源纪律【已验证】）。

## ④ 里程碑代理树（L3 题源设计参考）

**实例树 B（票型统计线，与树 A 声称线互补）**：
- 根：「本局放逐次数≤2 内分胜负（速胜局）」｜锚=程序结算｜resolve=局终｜cutoff=开局。

## ⑤ 强类型 slot schema（M2 转录管线抽取约束）

**动机**：Gemini 原提案=给转录抽取加强类型 slot schema；红队裁定思想正确、落点=p1b 新 wrapper 或 M2 转录管线、p1a/botc 五文件禁改（§五.4【已验证】）。M2=真实局转录管线（ASR→结构化→replay+truth，零 db 写入；试点=PandaKill S1E6 在跑【已验证，队长规划 §五.3 台账 2dde55bf】）。
**Schema：五槽+校验（JSON Schema，版本化 slot-schema@1）**【推测=本棒设计】：每条抽取记录=五槽对象，整局=记录数组。
- actor（必填，string）：席位注册表引用（seat id 或别名映射）；注册表=该局席位清单，前置注入抽取 prompt（防注册表外幻觉）。
- action（必填，封闭枚举）：speak/claim/vote/abstain/night_kill/death/witch_save/witch_poison/seer_check/系统行——枚举封闭集以 M2 试点实际事件类型定版；改动=版本号递增+schema-hash 联动（照审计器 §4 条款③「指标定义改动=预注册修订」先例【已验证】）。
- target（可空，席位引用）：speak 类无 target；投票自指禁例 target=actor。
- time（必填）：对局相对时序 {day:int, phase:night|day|vote, seq:int}——不用 ASR 绝对时间戳（时轴不可靠【推测=工程判断，待 M2 试点实证】）。
- confidence（必填，number∈[0,1]）：ASR+抽取置信；<0.6 降级「低置信待复核」队列，不入正式流。

**校验规则（wrapper 内纯代码校验器）**：①actor∈注册表；②action∈枚举封闭集；③时序活性：死亡角色禁再产生 speak/vote——与 ACR C 类时序错位检查同源（两设计共享检测器规格）；④投票自指禁例；⑤必填槽缺失或低置信→整条入 reject 队列并记 reason（no_actor/ambiguous/low_conf——照审计器 §4 防 Goodhart 条款②的 reason 模式【已验证】），reason 分布进试点报告。
**可证伪判据（试点验收）**【数字为本棒预注册提案】：S1E6 试点上 schema 校验通过率≥90%（事件条数口径）；低置信条目 100% 带 confidence 标记且 100% 进复核队列；时序活性违例 0 条入正式流（拦截率 100%）。
**失败长相与砍件条款**：①通过率<70%→schema 过严或抽取 prompt 缺陷：先查枚举漏动词，schema 修订走版本号、已抽条目不回溯重抽（除非全量重跑，预注册写死）；②LLM 幻觉注册表外 actor→拒收入队，不放宽校验；③砍件：不做 ASR 词级时间对齐、不做多说话人分离模型（YAGNI，审计器 §6.2 精神）；schema 不入 db 层（wrapper 外零感知）。
**执行前置与工时**：交 M2 棒（2dde55bf）采纳；schema 定义+校验器 0.5-1 天（M2 棒内）；p1a/botc 五文件零触碰（新 wrapper 文件）。
**合规自证**：落点=新 wrapper（红队裁定原文口径【已验证】）；零 db 写入（M2 现行纪律【已验证】）；schema 版本化可审计；LLM 只出结构化逻辑（无研判数字）；与设计①共享时序活性检查规格=一次定义两处消费。
