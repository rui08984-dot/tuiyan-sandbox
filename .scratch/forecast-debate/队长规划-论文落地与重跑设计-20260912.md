## 一、亲读后对既有认知的修正清单（本人第一手）

### 1.1【要害·新发现】90 条已 resolve 题的「证据注入」=结局泄漏，重跑 H1 会被读数能力冒充信息价值
- 链条：sim-titles 的 evidence 是**结算事件**（endEv=「狼人阵营胜利」/nightDeath/voteEv=计票 JSON）；90 条全部已 resolve；批次 1 若按 A1 把 evidence_json 事件文本喂进 v1_evidence，判词直接读到答案 → v1@L6 Brier≈0。
- 后果：评审 per-path 判据「v1@L6 vs 旧值 0.3876 与基率下限 0.13」会被**读数泄漏**击穿——改善是真（管道通了）但与「信息价值」无关；这正是评审攻击 2 自己警告的「判据被零信息达成」的镜像（它抓了基率泄漏，没抓证据泄漏）。
- S1 §2 H2 其实已经默认了这个性质（「夜死亡证据直接给出答案」），但没把 L6 的同样性质挑明。

### 1.2 修法：重跑拆成两个实验（R-A/R-B），判据各自独立
- **R-A 证据读数+acquiescence 实验**（老 90 条，v1 喂结算证据）：
  - R-A1【读数门】：v1 全量 Brier ≤ 0.05（≈能读懂账本证据；>0.10=管道或抽取失败）。
  - R-A2【acquiescence 实锤】：L1 层 v1 仍高置信偏 Yes（Brier 不向 0 收敛）→ acquiescence 独立于信息真空成立；向 0 收敛 → 偏差可被证据矫正。
  - R-A3【v2 对照】：v2（纯题面）预期复刻 ~0.33 信息真空水平——「v1 与 v2 的差」度量的是**证据送达量**，不宣称信息价值。
- **R-B 信息价值实验**（新题，依赖模板库扩建）：只收「cutoff 早于结算」的题+**cutoff 时点前**的账本证据（发言/声称/白天的投票前事件），resolve 仍在未来——判据才允许用「vs 分题型基率下限」。R-B 与 B1 拍板「重跑后再排结构件」衔接：模板库扩建（≥10 非重言模板）升格为 R-B 的前置件。
- v3 基率注入补一个两处都没有的细节：**leave-one-out 基率**（除本题外的同型局基率）——全量基率含本题自身=自我泄漏；且 L1 层（重言）不注入基率（评审已证 0/30 白送）。

### 1.3 其余亲读要点（进批次 1/1.5 的规格）
- **freeze 措辞=背景化**（J3 FB + J6 Study2）：基率以「账本历史统计（截至判词时点）」作背景注入，**禁**「请据此更新你的判断」式更新指令（Schoenegger 实测更新指令反而劣化）——写死进 prompt 模板。
- **输出格式锁定**（J2 Lu Appendix C）：`Between X% and Y%, but Z% being the most likely. Probability: Z%`，锁 0.10-99.90；**区间两端入库**（verdicts 加区间列或入 verdict_text 结构化字段）——区间宽度=第二信号源（J6）。
- **impute 预注册**（J3 P4+J2 ⑧2）：判词路失败/拒答→dataset 型题 impute 0.5、有 crowd 型（账本基率）impute 基率；重跑 PREREG 必须写死，禁止临场选。
- **ECE/coverage 不进判据**（K F13/F22/F58/F61）：90 条=8 桶 ECE 只配作过程记录；判据全部用 Brier（proper score 小样本更稳）。
- **γ̂ 双轨记账**（K F55+收官账）：重跑写回用原始 implied_prob 的 median；γ̂=3/(1+2λ̂) 只记校准列不得定版（λ̂ 用重跑后相关矩阵重算）。
- **批次 1.5 TS 回测三纪律**（K F42/F43+F33+F59）：逐路独立 TS（logit→1-D NLL 优化）；分数先归一化（各路除以历史残差尺度，F33）；回测用 Platt/TS 不用 isotonic（200 条规模伤 accuracy，K ⑥b+AIA 表E isotonic 0.1097 劣证）。TS 结论只做预期管理不进 PREREG 判据（评审边界维持）。
- **A0 臂提醒**（J3 ⑦7）：FB 全基线 temp=0——本次重跑维持 0.2/0.7/1.0 三温度不变量隔离，temp=0 对照臂留 L1。
