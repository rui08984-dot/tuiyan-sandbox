## 已核证据（本轮实抓）

### E1【已核】AIA Forecaster（arXiv:2511.07678，2025-11）「AIA Forecaster: Technical Report」
- 系统=LLM-based，三要素：①agentic search over 高质量新闻源 ②supervisor agent 调和同事件多路预测 ③统计校准技术对抗 LLM 行为偏差。
- **ForecastBench 上达到人类 superforecasters 平价**，超越此前一切 LLM 基线；自述"first work that verifiably achieves expert-level forecasting at scale"。
- 液体预测市场基准：单独跑输市场共识；**AIA+共识集成跑赢共识单独**（加性信息实锤）。
- 对 T1（B-泼冷水 §1.1：连续≥2 评测周期 Brier 稳定优于专家中位数且跨≥3 不相关域）：**平价≠优于，T1 未触发，但逼近**。
- 关键：三要素全部落在本项目 LLM 四角色合法集合（聚合/多路/校准）内——SOTA 没有水晶球成分，全是管线工程。

### E2【已核】LLM vs Expert Forecasters（arXiv:2507.04562，2025-07，A 棒原登记未核，本轮回补）
- 464 道 Metaculus 题：前沿 LLM 名义超人类群众，**仍显著弱于专家组**。
- 时间线：2025-07 显著弱于 → 2025-11 平价。追赶斜率实锤，方向直指 T1。

4. key 不出服务端/微步回合制/池上限：运营安全纪律，与预测能力无关。
