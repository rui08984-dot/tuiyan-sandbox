## §1 勘误 HB-A：v1 §4 的**收缩量口径有缺陷**（出现负值，与「收缩」语义矛盾）

### 1.1 事实

v1 §4 写死的口径：

```
shrinkage = 1 − |theta_post − ybar_unit| / max(ε, |ybar_unit − ybar_global|)
```

首跑实测出现**负值**：

| 单元 | n | ybar_unit | theta_post | v1 口径的 shrinkage |
|---|---|---|---|---|
| long·中 | 42 | 0.429 | 0.415 | **−0.593** |
| long·最难 | 80 | 0.425 | 0.419 | **−0.188** |
| mid·最难 | 87 | 0.460 | 0.418 | **−0.054** |
| short·最难 | 87 | 0.460 | 0.418 | **−0.054** |
| short·近 | 4 | 0.500 | 0.505 | 0.933 |

### 1.1b 追加：**v1.1 初稿的修正公式同样有缺陷**（同日二次自查）

v1.1 初稿改为 `1 − |post−unit| / max(|post−global|, |unit−global|, ε)`，**实测仍出负值**：
`long·中` 的 `|post−unit| = 0.0137`，而 `max(|post−global|, |unit−global|) = max(0.0051, 0.0086) = 0.0086`
⇒ `1 − 1.59 = −0.59`。**根因**：`|p−u|` 不受 `max(|p−g|,|g−u|)` 约束（三角不等式只给上界 `|p−g|+|g−u|`）。
**⇒ 改用插值系数**（见 §1.4 修正版），天然有界。

### 1.2 根因

**分母设计错误**：当某单元的观测值**本来就接近全局**（`|ybar_unit − ybar_global|` 很小）时，
分母趋零 ⇒ 比值被放大 ⇒ `1 − 比值` 变负。

诊断实证（首跑）：`long·中` 的 `|post − unit| = 0.0137` 但 `|unit − global| = 0.0086`
⇒ `0.0137 / 0.0086 = 1.59` ⇒ `shrinkage = −0.59`。

**语义矛盾**：「收缩量」应为**该单元向全局借力的比例**，落在 `[0,1]`；
负值意味着「估计离单元观测值比离全局更远」——那是**反向**，不叫收缩。

### 1.3 定性

**v1 的口径缺陷**（非实现 bug）：我把「收缩」定义成了**相对单元-全局距离的比值**，
但正确语义应是**估计相对「单元观测值」与「全局值」两个锚点各靠多近**。

### 1.4 修复（v1.1 生效；**v1.2 起以此为准**）

```
lambda_raw = (ybar_unit − theta_post) / (ybar_unit − ybar_global)     # 当 |ybar_unit − ybar_global| > ε
shrinkage  = clip(lambda_raw, 0, 1)                                   # 落 [0,1]
```

**语义（插值系数）**：`theta_post = ybar_unit + lambda·(ybar_global − ybar_unit)`
⇒ `lambda` 就是「估计从**单元观测值**朝**全局值**走了多少比例」：
- `=1` ⇒ 估计完全落在全局（**完全收缩**）；`=0` ⇒ **无收缩**（估计仍贴着单元观测）；
- `>1` ⇒ **过冲**（估计越过全局）⇒ clip 到 1，并**如实披露 `lambda_raw`**；
- `<0` ⇒ 略向外（数值噪声）⇒ clip 到 0，同样披露 raw。

**为何不用 v1.1 初稿的公式**：初稿写 `1 − |post−unit| / max(|post−global|, |unit−global|, ε)`，
实测**仍出负值**（如 `long·中`：`|post−unit|=0.0137` 但 `max(|post−global|,|unit−global|)=0.0086`
——因 `|p−u|` 可**超过** `max(|p−g|,|g−u|)`，三角不等式不保证该界）⇒ 该式**非有界**，弃用。
- **单调性检验（v1.1 修正版；判据提在**正确层级**）**：
  · **★ 层级更正（同日二次自查）**：初稿把该判据提在**单元级**（`horizon档×难度档`）——**错**。
    **随机效应在 `city×month` 组级**（PREREG §3.1），收缩是**组估计**向全局借力；
    单元只是**观测的切片**，其 `ybar` 差异来自题目构成而非组样本量 ⇒ 在单元级检验「n小收缩强」**无依据**。
  · **正确判据（组级）**：`city×month` 组中，**组内题数越少的组，平均收缩量应越大**。
    实测：见 §2 的组级表（按组内 n 分档：n≤5 / 6–10 / >10 的平均 lambda）。
  · 若组级单调性不成立 ⇒ **如实披露**（不强行解释；池化本身仍有效，只是「借力强度」不呈单调）。

层级结构（随机效应 `city×month`／单元 `horizon档×难度档`）**未改**；适用层（**仅 L3**）**未改**；
采样超参（4 链／tune 1000／draw 2000／`target_accept=0.95`／seed `987654321`／cores 1）**未改**；
收敛判据（R̂<1.01 ∧ ESS≥400 ∧ div=0 ∧ BFMI≥0.3）**未改**；输出契约的另两件（收缩后估计／95% 等尾区间）**未改**。
