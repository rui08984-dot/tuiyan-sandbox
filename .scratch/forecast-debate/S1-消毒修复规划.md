## §2 特别处理①：信息真空改写 p12 归因 + 重跑实验设计

### 归因改写（p12-PROGRESS 微步 3 与 G 引用处同步）
原归因（p12 L41）：「判词=基率噪声版（acquiescence 方向错配）」——单因。改写为**双因素未分离**：
- 因素一（设计，A1 实锤）：三路全部信息真空运行，prompt 只含题面+day+game_type，evidence_json 从未进入——「v1_evidence=信息聚合路」在首跑中不成立；
- 因素二（行为，A 报告 L1_prob_dist 实锤）：acquiescence 方向错配——L1 层 87 条判词 70 条 implied_prob∈[0.6,1.0] 高置信指向「平安」而真值恒 false，反向信息（L1 Brier=0.5970）。
- 保留的原有诚实限定：L6 层 ECE=0.2114 且系统性欠自信（低置信高命中）提示判词并非纯噪声——这是「修复信息输入后可能改善」的正面信号，也是重跑的动机。

### 重跑设计（预注册式，防「重跑到好看为止」）
- **前置门**：A1+B1(a) 落地+测试全绿+A2 日志就绪后**一次性**重跑；禁多次重跑择优（F 防多重比较）；跑前本规划 §2 判据冻结。
- **步骤**：①judge-runner 抽 10 条烟测——verdict_text 必须引用事件内容（红队复测标准），人审通过；②verdicts 全量导出 JSON 归档（判词是 LLM 衍生数据可再生，predictions 账本一行不动——与 A3「账本完整」裁定同源）后清空 verdicts 表；③全量 90×3 重跑（live，成本≈首跑 270 调用/18 分钟量级）；④重算分层报表+λ̂/γ̂；⑤PROGRESS 写「重跑对比节」，新旧数据并存引用（旧=信息真空条件，新=证据+基率条件）。
- **预注册判据（跑前冻结）**：
  - H1（主）：证据+基率注入后 median Brier < 0.25 无信息基线 → 成立=推翻「负结果系模型能力不足」的单因解读，负结果改判为「信息真空主导」；仍 ≥0.25 → 负结果**不翻案反而加固**（限定升级为「信息修复后仍无效」）——两个方向都是可发表结论，无白跑路径。
  - H2：L1 重言层修复后判词应向 0 收敛（夜死亡证据直接给出答案）；仍高置信指平安 = acquiescence 实锤独立于信息真空（因素二单独成立，TS 再校准必要性坐实）。
  - H3：λ̂ 重算（三路信息输入变化后相关性结构可能移动）；γ̂ 仅记录，不构成极端化排期依据（B2 限定继续有效）。
- **工时**：跑半天+分析半天=1 天（另 live token 成本≈首跑量级）。**依赖**：第一批（A1/B1a/A2）全落地。**不重跑后果**：p12 归因停留在双因素未分离；G 排期（TS vs 两件套）无数据锚。
