## §3 模型（写死）

### 3.1 数据

- **来源**：`.scratch/backtest/d2-report.json` 的 `rows[]`（400 题；字段 `city / month / horizon_days / tier / p_base / y`）；
- **观测**：`y ∈ {0,1}`（该题真值），`n=1`（每题一个伯努利观测）⇒ **不用二项似然，用伯努利**；
- **层级键**（照 §11.5 ②）：**随机效应 = `city × month`**（题级分组）；**观测单元 = `horizon 档 × 难度档`**（=D2 的 `by_cell` 口径，3×3=9 格，实际非空 9 格内）。

### 3.2 先验族（写死；**冻结后禁改**）

用 **logit 空间的非中心化参数化**（non-centered；E-工具箱 §8.1 的标准做法，防漏斗）：

```
mu      ~ Normal(0, 1.5)            # 全局 logit 均值（弱信息）
tau     ~ HalfNormal(1.0)           # 组间标准差（弱信息）
eta_g   ~ Normal(0, 1)   (g = 1..G) # 组级非中心化偏移，G = city×month 组数
theta_g = sigmoid(mu + tau * eta_g) # 组级概率
y_i     ~ Bernoulli(theta_{g(i)})   # 题 i 属组 g(i)
```

**超参（写死）**：`mu: Normal(0, 1.5)`｜`tau: HalfNormal(1.0)`｜`eta: Normal(0,1)`。
**为何弱信息**：本题域基率已知落 (0.15,0.85)（Q0-3）⇒ logit 大致 ∈ (−1.73, +1.73)，
`Normal(0,1.5)` 在该区间内近乎平坦；`tau` 用 HalfNormal(1.0) 允许组间差异但不鼓励极端。

### 3.3 适用层（照 §11.5 ④，**写死**）

- **本批只做 L3**（D2 题 layer 恒 L3）；
- L1／L2／L5／L6 的池化**须另行评审**（本件不做、不声称）。

## §4 输出契约（写死）

**每个单元（horizon 档 × 难度档）必须给三件**（照 §11.5 ③）：

1. **收缩后单元估计** `theta_post_mean`（该单元所属组的后验均值）；
2. **收缩量** `shrinkage = 1 − Var_post / Var_prior_equiv`（或等价定义：`|theta_post − y_unit|` 相对 `|y_unit − global|` 的收缩比）——
   **本件写死用后者**：`shrinkage = 1 − |theta_post − ybar_unit| / max(ε, |ybar_unit − ybar_global|)`，`ε=1e-9`；
3. **后验（可信）区间** `hdi95 = [lo, hi]`（**94% HDI** 或 95% 等尾区间——本件写死 **95% 等尾** `[2.5%, 97.5%]`）。

**外加披露**：单元原始 `n`／`ybar_unit`（未收缩）／`ybar_global`。

**禁止**：n<30 单元**不得**同时给裸 Brier 当读数（那正是规格要取代的「数据不足」文案）。

## §5 收敛判据（写死；**不达标即不出结论**）

| 判据 | 阈值 | 依据 |
|---|---|---|
| **R̂（rank-normalized split-R̂）** | **< 1.01** | 规格 §11.5 ② 明文 |
| **ESS（bulk & tail）** | **≥ 400**（每参数） | 规格 §11.5 ②「ESS 下限」；400 为常规下限 |
| **divergences** | **= 0** | 冒烟测试出过 1 ⇒ 本件写死零容忍 |
| **BFMI** | **≥ 0.3**（每链） | E-工具箱 §8 收敛诊断配套 |

**任一不达标 ⇒ 本批 HB 输出整体作废**（不得「降阈值重跑」，照 D2 停止规则）。

## §6 报告范围与诚实边界（写死）

1. **HB 输出另立节**，**不得**混入 D2 首批 `by_cell` 读数（那节是**裸分层**，本件是**池化**，口径不同）；
2. **不得**把池化估计当「实测读数」引用（照 E-工具箱 §8.8：「收缩语义字面可解释」，是**谦逊的明文**，不是结论）；
3. **N_unit 不改**：D2 首批的「有结论单元」口径维持原样；
4. **域限制**：仅天气（openmeteo archive）｜**层限制**：仅 L3｜**难度**：仅 3/4 档（「极」档不可达，D2-D）；
5. **零账本写、零 LLM**（HB 是纯统计计算）。
