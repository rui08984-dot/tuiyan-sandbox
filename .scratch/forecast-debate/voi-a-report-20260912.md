## 四、失败长相逐条记录（设计稿 §③ 三条，全部如实计分）

**① 开口子集 ΔBrier ≥ 全量 → 触发。** 门控选出的点比全量更差（+0.2965 vs +0.1479，差 0.1486 超噪声带）。J5 开口规则在 v2 信息真空域被反证：**参谋卡恒全量输出，VoI 门不建**。

**② τ_D 校准塌向 0 → 触发（且重校准无意义）。** open 率上限 3.3%（C∧基率交集=3 条），塌窗根因在 C∧基率交集过小而非 τ_D——τ_D 拉到 +INF 也只有 3.3%。设计稿允许「重校准一次」，但重校准唯一自由度是 τ_D，对交集瓶颈零作用（数学上不可能落 20-40% 窗）——二次校准注定退化，按设计稿处置：**砍 VoI 门，只留 J5 语义三准则（文字版）**。

**③ 零额外 LLM 调用硬约束 → 满足。** 两代理（C 代理/D 方差）全部由既有判词输出+账本统计纯离线算出，LLM 调用=0。

**机制**：三点同构——v1（证据）与 v3（基率）一致判 true（0.96-0.98/0.71-0.73），v2（纯题面怀疑派）反向给 0.36-0.38，真值=true。「|p_v2−0.5|≥0.1」代理抓到的不是信息量而是 **v2 怀疑派 prompt 的结构性反向偏移**：在 v2 信息真空域，「判词有倾向」≈「倾向错误」（与 R-A3 v2=0.2866 劣于基率、TOST v2 方向「劣于基率」meanD=+0.0514 完全一致）。VoI 门在弱口径域选出的恰是 v2 最错的点——门的三个条件（证据充分/路间共识/基率不确定区）逐条满足时，v2 的「倾向」没有信息价值只有角度噪声。

## 六、释读边界（防过度宣称）

- **弱口径**：本验证只覆盖 v2（纯题面）域，不判 v1（证据域）/v3（基率域）的开口价值——v1 读数是结算证据读数实验（R-A 口径），不进本验证（防读数泄漏）。
- **n=3 开口子集**：主判据读数方向稳定（bootstrap CI 不跨 0），但样本极小，只作本域证伪记录，不外推其他域/其他 prompt 版本。
- **基率窗结构性出窗**：peace（重言层全 false）与 votes（true 占比 0.79）恒出窗是账本现状的机械结果——基率条件「帮不上的不确定区」在本账本仅存 win 型边界区，J5 三准则的适用面本就窄。
- **L1 层**：open=0（重言层基率=0 恒出窗），ΔBrier_all=+0.3525=v2 在重言层反向信息的再量化（p15 A5 锚 0.5970 同源现象，Brier_base=0 为常数 0 预测器在恒 false 层的完美读数）。
- τ_D 冻结值（0.061089）随本报告+raw JSON 落盘；塌窗状态下该值无工程用途，冻结仅为留痕防事后调。
