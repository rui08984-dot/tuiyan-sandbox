# 03 · 科学性棒（方法学审查）· 预测万物 v3.0

> 审查人：科学性棒｜2026-09-16｜对象：`输入-方案v3.0全文.md`
> 对照基准：J/K 精读+二期笔记七份（Confident/Substitutes/PSR/Pitfalls/KK516/ExtremVal/InfoDiv）。BBC 与 Kull beta calibration 未精读原文，涉及处标「不确定」。

## 一、v3.0 对现有系统的诊断判定

**「六层=手工固定先验」——部分成立，归类错位。** L2 基率+Wilson 确是手工不确定度表达（频率派，非贝叶斯先验），对 L2 成立；但 L1 是决定论程序复算（正确率 1.000），既非先验也非似然；L5/L6 属聚合与判据层。六层整体归为「先验」是削足适履。

**「AI=黑箱似然」——字面不成立，实质部分成立。** 铁律「LLM 出逻辑不出数字」下，AI 判词是聚合的多路信号源（J-预测系统精读：LLM 直读判词聚合实测 Brier 劣化 0.1168 vs 0.1140），不是可求值的似然函数。「黑箱似然」是重包装，非新诊断。

**「纠错=粗糙后验更新」——不成立。** L3 的 ACI（l3_aci.js）即 Gibbs & Candès 在线保形（K-公式精读 F24/F27），对任意数据生成过程有频率保证；L6 判词聚合对齐 KK516 可插拔聚合器纪律。「三者未统一到贝叶斯」事实成立，但换共轭贝叶斯会丢掉 ACI 的分布无关保证——v3.0 未计价此代价。

## 二、科学组件逐个评审

**① 可预测性=先验强度×似然可靠性：拒绝。** 乘法公式在论文笔记中无对应（不确定有支持）；共轭更新标准结构是后验精度=先验精度+数据信息（加法），乘法方向可疑；两因子无操作化定义与测量方案。

**② 问题DNA八维 vs 万物分类清单 v2：记账互补、路由重复且踩 null result。** Ω/T 与现有六层分类重叠，A/R/S 是增量。作分域记账标签可用（对齐 J 笔记 Lu 文落地点）；作「DNA→配方」路由器则撞上 KK516 核心 null：516 算法预注册研究中无任何特征能一致解释绩效变异，唯一有信号的是历史误差反馈（二期笔记-KK516）。无回测即上线 DNA 路由=重蹈覆辙。

**③ 共轭更新与 MCMC/变分：共轭采纳、MCMC/变分拒绝。** Beta/Dirichlet 解析更新零成本，n=93~400 稳定，可作 L2 基率先验升级（Wilson→Beta 后验）。但按 DNA 分组后单元更薄——PyMC HB 只池化 3 个 n=4 单元是教训；K 笔记 F13：校准稳定到 ε=0.05 需 n≈102，本量级不支撑高维推断，MCMC/变分是负担非收益。

**④ BBC vs beta calibration vs 已有 ACI：保留 ACI，拒绝替换。** 账本是时间序列、可交换性不严格，正落 ACI 适用域，是三者中唯一有在线保证者。等渗回归有反证：AIA 表 E isotonic 0.1097 劣于 Platt 0.1076（J-预测系统精读）。BBC/Kull 未精读原文（不确定），替换现役校准器无收益论证；三校准器并置属冗余，选择应按回测+多口径并列（二期笔记-PSR home-advantage）。

**⑤ 认知/偶然分解：部分可落地，限两形式。** BIN 三分解是非观测量（组件和与观测差 1-2pp，二期笔记-PSR）；按 DNA 分组后每组 n 常 <100，组级方差爆炸。可行：全池 BIN+判词路间分歧作认知不确定性代理（K 笔记回合1发散3）；v3.0 逐问题四分输出不可落地。

**⑥ 因果图/反事实算子：拒绝。** 七份笔记+J/K 精读无一篇支撑因果发现/SCM/反事实模拟（论文家底为零）。Confident 的 oracle-vs-public bound 提醒：机制不可读时连「任务不可解」都无法判定，应先做可解性上界；保留「关键假设+证伪条件」输出即可（Confident 格式可抄）。

## 三、与论文精读结论的一致性核对

**「AI 作似然估计器、不直接出概率」：方向一致、表述过强、实为同构。** Confident 证实 LLM 自报置信严重误校准（1/62 高置信命中、Brier 比 7.1），支持「不能直接信 LLM 概率」；但 PSR 显示 LLM 概率可塑形且 Brier 型变体有最高 information 分量（二期笔记-PSR），AIA 表 E 显示 Platt 把 0.1140 提到 0.1076——准确表述是「须先校准再进聚合」。且 v3.0 实际操作（AI 信号+校准+聚合）与现有多路判词同构，非范式升级。

**「算子组合提升精度」：增益条件 v3.0 未满足。** 组合增益为正的条件：①信息低重叠——重叠高则平均即可，低才需强极端化；三路判词同底座同 prompt 族 λ≈1，「logit 平均几乎不需极端化」（二期笔记-InfoDiv）；②先验可估——prior-free 时平均准最优、极端化无依据，已知先验+substitutes 下常数极端化才 minimax 最优（二期笔记-Substitutes）；③最优聚合方差不减、中心趋势量欠自信（二期笔记-ExtremVal）。v3.0 十三算子多数消费同一题面同一检索，重叠度大概率高，又无 λ̂ 实测机制，「提升还是拖累」只有口号没有判据——当前配置下组合增益大概率为零或负。

**「公开排行榜」：有预注册意识，缺四防坑（二期笔记-Pitfalls）。** ①Piggybacking：可读市场/人群价则「胜过专家」是循环论证，须隔离（J 笔记 AIA 价格黑名单可抄）；②winner's curse：第一名大概率被高估，报告须带折扣与 CI；③Brier 跨基率不可比 E[BS]=b(1−b)：须组内基率分层，否则榜单选出「区分常见题」而非「稀有事技能」；④排名竞赛破坏真值披露（InfoDiv）。另防校准崇拜：完美校准零分辨率无用（conclave 例），指标须 Brier+log+resolution 并列。

## 四、总判定与最小修正案

**总判定：科学层「需大改」——叙事框架可用，五个组件应拒绝或降级，主干与现有六层同构而非升级。**

| 组件 | 判定 | 一句话理由 |
|---|---|---|
| 贝叶斯记账语言（给六层标注先验/似然/后验） | 采纳 | 行动清单第一条，零成本，不动现役机制 |
| 预注册+公开验证骨架 | 采纳 | 与 PREREG/Brier 计分兼容，补 Pitfalls 四防坑 |
| DNA 作分域记账标签 | 采纳 | 便宜，对齐 Lu 文分域记账落地点 |
| Beta-Binomial 共轭基率先验 | 采纳 | 解析零成本、量级稳定，分布输出优于点区间 |
| 可预测性乘法公式 | 拒绝 | 无文献依据、数学方向可疑、因子无操作化定义 |
| DNA→算子路由（13 算子配方） | 需大改 | 踩 KK516 null result；须 λ̂ 实测+按域回放 |
| MCMC/变分推理 | 拒绝 | 样本厚度不支撑（PyMC HB：3 个 n=4 单元），共轭已够 |
| BBC/等渗替换 ACI | 拒绝 | ACI 有分布无关保证；等渗有 AIA 反证；BBC 未精读不评（不确定） |
| 逐组认知/偶然分解 | 需大改 | 限全池 BIN+路间分歧代理两形式，组级不可估 |
| 因果图/反事实算子 | 拒绝 | 论文家底零支撑+零储备，先做可解性上界 |

**最小修正案**：v3.0 对本项目真实增量只有三件——贝叶斯记账语言、DNA 分域标签、共轭基率先验；其余「路由/因果/MCMC/换校准器」在通过「λ̂ 实测+按域回放+预注册」三关前，一律不得进入现役管线。
