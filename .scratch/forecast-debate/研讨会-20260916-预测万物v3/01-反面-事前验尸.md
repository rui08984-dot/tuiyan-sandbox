# 01 反面棒 · 事前验尸（Pre-Mortem）

评审对象：`输入-方案v3.0全文.md` ｜ 出棒日：2026-09-16

## 〇、强制反问：这个计划最需要为真、实际却为假的是什么

v3.0 成立依赖一句话：「瓶颈在框架不统一，统一后精度有增量」。实证史恰好相反：命题A消融负结果止发、检索证据 0/52、D2 回测 model≡base、L2 基率 ΔCI 含 0——四次证明换框架/加信号≈零增量；且 28 格仅 7 格 n≥30，真瓶颈是数据量。v3.0 还需「迁移近零成本」「一人+AI 可养 8 产品与专家网络」同时为真——亦为假。

## 一、失败场景（2027-06 回望）

2026-10 起按 v3.0 推倒统一；12 月新旧管道不可比，Brier 序列断裂，373 测试重写后仅形式通过。2027-03 平行对比：v3.0 对冻结版无增量，成第四次负结果；算子归因因 n 不足成空报告，DNA 缓存污染未察觉。8 产品无一上线，观测台停更。2027-06 回到 1972 条旧账本，唯一产出是 v3.0 文档。

## 二、头部失败路径（按可能性×影响排序）

### P1 统一改造零增量（可能性：高｜影响：致命）
结果：2027-03 消融显示贝叶斯主干+算子路由对冻结六层的 Brier ΔCI 含 0，v3.0 成为第四次「新框架无增量」实证。
必要条件：①「重表达=增精度」未验证即动工；②1300 已解题的 DNA 标签由未验证的 LLM 生成；③按 DNA 细分后每格 n 更小，检验力更低。
预防要求：动工前先做纸面预检——对已解 1300 题回溯打 DNA、按 v3.0 配方「若当时如此路由」重算 Brier，对比冻结管道；ΔCI 含 0 则 v3.0 封存为文档，不写一行实现代码（账本字段能否支撑重算：不确定，需先核验）。
Gate：PREREG 新增「V3-H0」假设文件冻结后才准施工；裁决走既有账本+Brier，负结果照例止发。

### P2 迁移毁掉已验证核心（可能性：中高｜影响：致命）
结果：2026-11 为「统一」重构管道，旧 verdicts 与新输出不可比，4766 条 verdicts 可比性报废；PREREG 冻结被当障碍绕过；8787 服务被波及停机。
必要条件：①大爆炸式替换而非并行；②把「账本不可变」误作可重算重释；③无新旧双跑期。
预防要求：禁大爆炸。v3.0 只作影子管道并行，写独立命名空间账本；旧账本只追加、不迁移、不重释；373 测试全程保持绿；8787 零接触。
Gate：新增「G3-切换」门：双跑≥200 题同题双计分且增量过验后才准切换；切换=版本递进，旧版本永久冻结。

### P3 一人+AI 撑不起 8 产品与专家网络（可能性：高｜影响：高）
结果：2027 上半年产能摊到编译器/市场/API/竞技场等 8 形态，无一可用；「专家似然算子」因无专家可约从未实现；垂直域细胞 n 仍 <30。
必要条件：①产品面×8 乘在数据瓶颈未解之上；②竞技场/排行榜需持续运营与对手供给，AI 代理无此能力。
预防要求：v3.0 删除 8 形态清单，保留≤1（竞技场最小版后置）；任何产品代码放行条件=所选垂直域全部细胞 n≥30 且首份校准报告已发布。
Gate：以分域 n≥30 读数作硬门，未过门冻结产品线；垂直域选择先 PREREG。

### P4 DNA 标签与缓存沦为不可证伪装饰+污染源（可能性：中高｜影响：高）
结果：2027-04「算子级归因报告」因 8 维组合下无格有 n 而成主观叙述；DNA 缓存把单次结果的「最佳配方」扩散进后续预测，Brier 缓慢劣化无人察觉。
必要条件：①标注器精度从未对标验证；②缓存写入无证据门槛；③n 不足时照常输出归因。
预防要求：标注器先过一致性验证集（双标+一致率阈值）方准入账；缓存仅从「PREREG+已解+n≥k」条目写入，禁单结果写缓存；n 不足时归因输出「不足以归因」。
Gate：铁律「无真值锚不入账本」延伸为「无验证标签不入 DNA 缓存」，以版本递进写入规范。

### P5 「AI=似然估计器」与铁律正面相撞（冲突确定存在｜失败可能性：高｜影响：中高）
结果：v3.0 第 3 层要求 AI 输出似然函数（概率形态），与「LLM 仅四角色且不出概率」冲突；执行中要么静默破戒（纪律死亡），要么该层从未实现（框架变空壳）。
必要条件：①规范层未裁决冲突即施工；②铁律被悄悄重新解释。
预防要求：二选一并落字：走版本递进修订铁律且附验证 gate（AI 似然须先在回测 ΔCI>0 才入生产道）；或改写第 3 层，AI 仍限四角色。
Gate：任何铁律修订必须走 PREREG 版本递进，禁止静默重释。

## 三、计划变更清单（v3.0 应增/改/删）

1. 删：「推倒统一」→ 改「影子并行+版本递进」，旧管道为基线永不拆除。
2. 增：V3-H0 预注册——纸面重算 1300 已解题，ΔCI 含 0 即止发（第四次负结果流程）。
3. 改：第 3 层「AI=似然估计器」→ 显式裁决其与「LLM 不出概率」铁律的关系：版本递进或改写。
4. 删：8 个产品形态 → 保留≤1，以「分域 n≥30」为放行门。
5. 增：DNA 标注器验证集与一致率门槛；无验证标签不入缓存。
6. 改：四层缓存写入规则 → 仅 PREREG+已解+n≥k 条目可写，禁单结果写缓存。
7. 删：「专家似然算子」「专家网络/接入更多数据源」——与一人团队现实冲突，标为不可行动。
8. 增：G3 迁移门（双跑≥200 题双计分）+ 373 测试常绿 + 8787 零接触，列为不可协商前置。
