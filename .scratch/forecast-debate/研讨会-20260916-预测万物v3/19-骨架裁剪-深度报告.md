## §1 裁剪的量纲：为什么「砍」可以有数学依据

用户要「数学或者其他的依据」。裁剪不是审美，是计算。本棒用三个可算的量纲，全部有实抓锚点。

### 1.1 主量纲：MDL 两部码留位判据（18 号 §7 交付，本棒首次消费）

18 号移植件⑥交付的框架（Rissanen 1978，DOI 10.1016/0005-1098(78)90005-5）：一个部件该不该留在系统里，看剪除后系统总码长是否不增——

```
ΔL = [Σ log p̄_含(y) − Σ log p̄_不含(y)] + (ln n)/2 · k ≤ 0  ⇒  剪
```

第一项是被剪对象的边际码长节省（可为负＝它在实际贡献预测信息），第二项是它占用参数与维护预算的复杂度罚。本棒把骨架层面的每个器官（DNA 维、算子、缓存、产品）都当作「候选剪除对象」来过这个判据，并给出一个可操作的近似：**第一项 ≈「有多少在役或持票判据在消费它的输出」×「它对那些判据的边际贡献是否已被实证」，第二项 ≈「打标/维护/检验它的持续成本」＋「它占用的判据名额（多重比较）」。** 第一项为零（无消费者或贡献为零）的器官，ΔL=(ln n)/2·k>0，纯税——这是本棒全部「砍」的数学形态。与 BIC 的桥：Lanterman（2001，DOI 10.1111/j.1751-5823.2001.tb00456.x）实证 Schwarz 的 Laplace 近似给出同样的「每自由参数 (ln n)/2」罚——18 号把 BIC 桥和 MDL 桥都验好了，本棒只管往回填内容。

### 1.2 家族量纲：多重比较税（Benjamini & Hochberg 1995）

八维 DNA 若每维各跑一次 E1 式 ΔCI 检验（α=0.05），即使七维全是纯噪声，至少一维「显著」的概率按独立近似为 1−0.95⁸≈**34%**——三分之一的概率骨架里会住进一个假 DNA 维，此后它享受判据待遇、进入披露、进入对外宣称，直到某个季度被自然暴露。Benjamini & Hochberg（1995，DOI 10.1111/j.2517-6161.1995.tb02031.x，CrossRef 实抓 **93,944 引**）的 FDR 框架给出的直接推论是：**控制错误率的最便宜方式不是设计更复杂的校正，是减少检验个数**——m 越小税越轻，m=1 时无需任何校正。Barron, Birgé & Massart（1999，DOI 10.1007/s004400050210，实抓 668 引）的惩罚风险界从另一头给出同一结论：模型选择的惩罚项随候选模型族的规模增长——**候选族每大一圈，每个幸存者背的罚就重一分**。这就是「为什么其余七维不许借 S 维的基建续命」（§2.9）的数学依据。

### 1.3 贝叶斯量纲：奥卡姆因子（MacKay / Myung–Pitt）

贝叶斯模型比较里有一个不用算 MCMC 就能用的洞见：模型证据 p(D|M) = ∫p(D|θ,M)p(θ|M)dθ 中，参数空间越大，先验质量被摊得越薄——**哪怕复杂模型拟合得一样好，它的证据也被「奥卡姆因子」系统性压低**（MacKay，Caltech 实抓，明文「the Bayesian Occam's razor is explained」；Myung & Pitt 1997，DOI 10.3758/bf03210778，把同一因子用于认知模型选择）。翻译到骨架：v3.0 骨架里每个没有判据约束的自由方向（未实证的维度档位、未测的流形关系、未消费的缓存键体系）都在稀释整个系统「预测被验证」的先验概率——98 个描述单元里 40+ 个自由方向，等于对外宣称里 40+ 个可被攻击的面。**瘦身不是删功能，是把先验质量集中到有定理和判据靠山的方向。**

### 1.4 本棒的四问判据（把三个量纲合成 30 秒能过完的检查单）

每个候选器官过四问：**①方差问**——它在账本里有没有取值变化（常量=熵 0=第一项必为零）？**②票问**——有没有在役或持票判据消费它的输出（没票=没人付钱给它）？**③可靠性问**——打它这个标的错误率实测过吗（未实测的语义打标默认按 09 争议 1 的 ≥85% 门槛存疑）？**④共线问**——它与既有机械字段是不是确定性函数关系（共线=k 个参数买 0 bit，MDL 罚全额缴）？四问全过=留；③④未过但①②有真实内容=缩（降为披露不入判据）；①或②为零=砍（重开条件写死）。

### 2.2 Ω——留，但定性为「机械别名」，禁止为它建打标器

Ω（二元/分类/连续/分布）根本不需要一个语义维：resolve_spec 在入库时就机械决定了结果形态（L2/L3 数值超阈=连续指示、L6 对局=二元、L5=机械读数），b(1−b) AND 门、E1 的 layer×domain 分层、U8 的 Brier 口径选择消费的全是 resolve.kind 本身。**裁决：留，但骨架图上标注为 resolve.kind 的别名（zero-cost alias），禁止建 LLM 打标器、禁止建新列。** MDL 代价 k=0。**砍错的代价（反向陈述）**：反过来「不收编而独立打标」的代价更重——语义标签与机械字段偶发不一致时会制造「第二真相源」（按 3% 打标错误率 × 1972 题 ≈ 60 处假分歧），归因时不知该信哪个，比没有这个维更糟。

### 2.3 T——留，机械别名，唯一被第 1 期在建产品直接消费的维

T（即时/短期/中期/长期）由 created_at / resolved_at / matures_at 三列机械派生；U7 预测日历（due.json byDay/byMonth/bySrc 已实证在跑）与 18 号生存分析票消费的都是机械时距而非语义分档。**裁决：留（别名）。** 附一条剃刀条款：T 的分档阈值若要进任何判据，必须 PREREG 冻结——「中期/长期」的边界本身就是一个可被事后挖掘的自由度（forking paths）。两头税都趋零（留它零成本、砍它也省不了什么），是八维里唯一无争议留存。

### 2.4 I——缩：语义标签整列砍掉，概念挂靠到机械 n 披露

I 的真实内容（信息充足/稀疏/无）在引擎层**已经被机械测量**：l2_baseline.js MIN_N=30、l5_certified.js unsupported、L2 insufficient_data 出口——这些门消费的正是格内 n 与源可用性，且已经在役。若让 LLM 按题面打「充足/稀疏」标签，它测的是「题面看起来信息多不多」的语义印象：一道冷门城市天气题题面具体、格内 n 却 <30——语义版是计量版的系统性噪声化。**裁决：缩——降为披露不入判据；披露列直接用每格机械 n（进 U8），「I 维标签」这个动作砍掉。砍错的代价**：若未来出现「n 足但信息真稀疏」（数据源系统性迟报、批量复制值）的情形，重开条件=n 披露列与引擎实际 resolution 出现系统性背离且 CI 不含 0——届时 I 作为残差维才有真实信息量，现在它是零 bit 的重复记账。

### 2.5 M——留，layer 列的重编码，比 09 号原判还省

09 表#7 原判「A/R/S≈现有 L 层重编码」——本棒补一刀：**M 也在这个映射里，而且映射得比 A/R 严格**：L1 决定论复算=机制明确（正确率 1.000）、L2 统计基率=部分、L6 判词=黑箱、L5 认证源=外包。KK516 三轴切分（10 号）消费的正是这个编码。**裁决：留（机械别名，即 layer 重编码）。** 诚实边界：M 与 layer 不完全一一对应（存在「L6 题但机制其实明确」的错配），这个错配正是 E2 C1 一致率检验（10 号 B 路由「审计化」）的审计对象——审计消费的是 layer 与 resolve_kind 的既有组合，依然零新打标。

### 2.6 A——缩：域查表披露，正式标签动作砍掉

在本账本里 A（无/弱/强）是 domain 的近似确定性函数：werewolf/botc=有博弈，openmeteo/noaa/dbnomics=无。模板共线性自查（90.9%）使 A 的语义打标结果 ≈ domain 前缀查表；且 12 号已有明文「纯域级与格完全共线使条件化退化」——**一个在每格内近似常数的变量，在 E1 式条件化检验里系数不可识别**。娱乐局语境下「强/弱」边界也不可靠（演技、挂机混杂，18 号 §8 否决 Level-k 时已举证）。**裁决：缩——domain→A 查表进披露件（零打标），正式标签动作砍掉；唯一判据消费走 15 号 G2 的对局分歧分布代理线（0.5–1d，探索性）。砍错的代价**：若未来接入市场/选举域（对抗强度在域内有真实方差），重开条件=新域入库且走 I5 通道独立立票（票价 2 人日）——届时 A 从查表升级为实测标签，期权无损。

### 2.7 R——砍（八维里唯一的三选一之「砍」，也是数学上最干净的一刀）

R（预测影响结果吗）在账本里是**常量**：1972 行全部是读侧重放/赛后记录——L1 复算、L2/L3 机械引擎、L6 判词对已归档对局、L5 认证源，没有任何一题的预测行为能反馈进结果生成过程（天气不因被预测而改变；对局在预测写入前已结束）。常量的香农熵 H(R)=0：它在任何条件化检验里分母为零，E1 式 ΔCI **数学上不可定义**；判据消费者为零；MDL 第一项恒为零、第二项全额——若按 17 号角色①给 R 建 LLM 打标，1972 次调用全额成本买到 0 bit，还占 dna_tags 一列、占 I5 通道一个票位（将来若真去测它，n 全在单一取值上，永远含 0）。**裁决：砍。重开条件写死**：第 4 期对外线（API/排行榜）上线**且**存在「预测可被决策者消费并移动结果」的域（市场/选举类）入库时，R 只对该域重立独立 PREREG 票。**砍错的代价（反向陈述）**：留 R 的唯一辩护是「对外后它会变活」——但对外线放行门本身就是 R 复活的前置条件，届时重标边际成本 1 人日/域，远低于现在每题打标＋每票占位＋披露维护的持续税；**砍它不损失任何期权，只省税**。

### 2.8 S——留，唯一判据级维，外加一条「物理隔离」条款

S 的实质已由 12 号全件冻结（同源源序列两半期对比、Newcombe 差值 CI、分母裁决、集中度门、弃权条款逐字），本棒零增改。剃刀只加一条**防续命条款**：E1 含 0 ⇒ 删列且 DNA 线终止时，**其余七维不得借道 S 的基建（打标脚本、分层框架、回放管线）以「换个维度再试」复活**——15 号 I5 已写「E1 含 0 则逐维开票机自动作废」，本棒把它升格为骨架图上的物理隔离：任何维的重开必须自带独立 PREREG 与独立打标方案。依据即 §1.2：八维各测一次的家族错误率 34%，裁到一维回到 5%——**控制错误率最便宜的校正是不测那七个**。

### 2.9 O——缩：源类型与发布滞后披露，语义标签砍掉

O（直接/间接/延迟）的大半已被机械编码：L5=直接（认证源）、L2/L3=间接（代理序列）、L1=复算；「延迟」在源发布时点里有机械形态（18 号 nowcasting 件消费的正是发布错位——发布空窗层分层判据）。语义打标「直接/间接」会与 layer 列制造第二真相源（同 Ω 的病）。**裁决：缩——U8 每格披露数据源类型与发布滞后天数（纯机械派生），O 维标签动作砍掉；合法残渣全部由 nowcasting 票的机械空窗定义承接。砍错的代价**：若将来要做「延迟披露导致校准错觉」分析，重开=该分析立票时从源元数据机械派生 O′ 列——依然不需要语义打标器。

### 2.10 八维净效果：三笔账

**①打标账**：需要 LLM 打标器的维从 8 → **0**（S 是机械规则打标；Ω/T/M 是查表别名；I/A/O 是机械派生披露；R 砍）。17 号角色①「DNA 八维语义提取器」在剃刀下**降级重定义**：从「八维枚举标签 JSON 输出器」降为「S 维规则打标器＋layer×resolve_kind 错配审计器」——它的 schema 砍掉七列，成本从 1972 题×8 维降到 S 维规则零调用＋审计读侧。**②错误率账**：家族错误率 34%→5%（§1.2）。**③产能账**：八维全打标 ≈1.6 万次 LLM 调用＋每维 I5 票 2 人日（15 号原价）——裁后这笔预算整块转给天气主攻（全案唯一 Δ=0.1587 的增长引擎）。

### 3.2 16 号化劣七件的复剪：六件维持，一件降级（全报告唯一与刚出件相左的裁定）

16 号的炼金术质量很高——七件里六件自我设限判据齐全、定理锚扎实，剃刀放行：件① KL 披露列（含 0 即永久纯披露，写死）、件② Granger 滞后票、件③ R3h Hedge 规格（η=1 冻结，防立票时临场拍板）、件⑤ kNN 票（Stone 1977 一致性）、件⑥ 分支合成器票（Dawid 1982 校准传播）、件⑦ Bates–Granger 预检（E2 立票前置，1.5 人日）。

**唯件④（3×3 解耦实验升格为 λ̂ 测量）剃刀降级。** 理由三：①**消费者缺席**——λ̂ 的两个消费端（Satopää 式极端化决策、第二底座立项）自己都是持票件，没有一张在役判据今天就要 λ̂ 读数；②**成本端真实**——9 臂×30–50 锚题 ≈270–450 次 LLM 调用＋PREREG＋分析，M 级；③**有零成本替代**——存量 verdicts 4766 行里 3 个变体-温度对（v1/0.2、v2/0.7、v3/1.0，变体↔温度混淆）已经给出了 λ̂ 的**下界读数**：混淆对之间的读数差异是「提示词效应＋温度效应」的混合上界——**连混合上界都 ≈1（读数几乎重合），解耦后的纯角色效应更不可能 <0.8**；反之若混淆对之间都有 λ̂<0.8 的区分度，9 臂解耦才值得立项去分离成分。**降级方案：先导版＝读侧脚本在存量 3 对上算 λ̂ 下界（0.5 人日，零调用），9 臂解耦降为先导读数的条件票**（守门判据：先导 λ̂<0.8 才立项）。省下 270–450 次调用与 1–1.5 人日。**砍错的代价**：若先导读数被混淆严重压扁（实际角色效应大但被温度效应抵消得看不出），9 臂晚开一季——代价是一季延迟，不是永久损失；而反过来不做先导直接跑 9 臂，是在为一个没有消费者的测量全额付费。

**顺带一个结构性收编**：件② Granger、件⑤ kNN、18 号 MOS、18 号 nowcasting——四张票全部等同一个前置（A8/A7 把格养厚）。剃刀把它们**并成一队**：一张「厚格基建」总票，四个候选按同一 walk-forward 重放骨架、同一 ΔBrier 配对 CI 口径、同一 ρ̂ 预检（16 号 7B）排队——18 号 §10.1 已把 MOS+nowcast 合并排期，本棒把 Granger 与 kNN 收进同一队列。四张独立 PREREG 的重复 overhead（各自脚手架、各自功效核算）并成一次基建四次消费。

### 3.3 缓存：六件 → 1 建＋1 票＋1 零动作＋3 砍/封存

v3.0 的缓存体系是「四层贯穿」＋语义缓存＋Prompt 缓存。17 号已用账本实证否决了语义缓存、纠错 0.1x 计费，本棒把剃刀推到底：

| 缓存件 | 裁决 | 依据与重开条件 |
|---|---|---|
| 结果缓存预检（题面+证据块哈希） | **建（唯一现在建，S 级）** | 17 号 §5.2：重跑批次占历史调用 30–50%，键设计已给；判据=历史重跑全命中 |
| 配方文本库＋误差反馈回写（原先验/似然缓存） | **持票（E2 通过后）** | 15 号 C3 降格到底：只存配方文本，校准数字跨域禁令写死；KK516 唯一阳性通道 |
| Prompt 前缀缓存 | **零动作** | 现状架构已天然满足（稳定 system 前缀+动态 user 尾部）；只留「改 SYSTEM_HEAD 须 run_id 递进」纪律条款；收益上限 <10%（17 号实算） |
| 语义缓存 | **砍** | 17 号三重否决（同模板不同局=不同事件→泄漏；题面短基建>收益；同义改写极少）。重开=题面结构化改造使同义改写成为真实高频场景且泄漏审计可过 |

**砍错的代价**：语义缓存若强行保留，最坏情形不是浪费钱，是**把 A 局的判词喂给 B 局**——信息泄漏会污染 verdicts 账本的全部下游判据，且以「省钱」的名义静默发生；这类错误的修复成本（重放重算全部受污判据）远超缓存的全部历史收益。DNA 缓存同理但更隐蔽：它在 E1 未决时缓存「按自报 DNA 分组的准确率」——若 E1 含 0（标签无信息），这些分组读数就是噪声分组，披露出去是给对手递刀。

### 3.4 纠错四层与成本治理三层（骨架完整性要求的顺带过刀）

**纠错四层**（后验更新/先验修正/似然修正/DNA 修正）：后验更新=回填已在役（15 号 C4「重造即浪费」）；先验修正=Wilson→Beta 回放票（09 表#6）；似然修正与误差反馈回写并轨（KK516 唯一阳性通道，挂 A3 票）；**DNA 修正——砍**（它修正的对象 §2 已裁：别名维无需修正、R 维已死、S 维自有弃权条款；重开=E1 通过）。净：4→2 在役＋1 票＋1 砍。

**成本治理三层**（路由决策/缓存加速/上下文优化）：Layer1 路由已收编为审计器＋姿态门（10 号 B 主 C 辅，非新机制）；Layer2 即 §3.3；**Layer3 上下文优化三件套（Top-K 截断/长文档摘要压缩/Prompt 模板动态裁剪）——砍**：没有任何票测它，且 17 号实测「成本大头是思考型输出 token（reasoning_effort=low：思考 token −55%、延迟 −77%）」——输入侧裁剪动的是小头。**替代动作**：成本台账 1 人日（15 号 G3 第一步）＋reasoning_effort=low 固化为跑批默认（17 号唯一大杠杆）。**砍错的代价**：若台账显示输入 token 占比 >40%，重开=按台账按需优化——那时优化有判据，现在优化靠想象。

### 4.4 最狠三刀的排序与一句话辩护

1. **砍 R 维**——数学上最干净（H(R)=0，ΔCI 不可定义），愿景上最无痛（没有任何产品叙事真的需要它）。砍错的代价已反向陈述：期权无损、纯省税。

3. **16 号件④降级为先导版**——组织上最需要勇气（剃刀对准 24 小时前刚出炉的同僚方案），数学上最不痛（混淆上界 ≥ 纯效应，先导读数的否定性结论可以安全前置）。砍错的代价：一季延迟，非永久损失。
