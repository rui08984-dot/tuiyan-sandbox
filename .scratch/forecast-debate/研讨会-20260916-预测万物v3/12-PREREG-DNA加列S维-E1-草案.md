## §1 S 维操作化（可执行规则版，零 LLM）

**S 维定义**：一条题所涉系列的「基率生成过程在事件时间轴上是否平稳」。它不是新量纲、不是新评分，是一个二值（+不可判）标签，唯一用途是进 E1 检验「控制既有分层后有无 Brier 信息」。

**标签赋值单位决策表**（题级 / 纯域级 / 系列×期级三选一）：

| 方案 | 内容 | 否决/采纳理由 |
|---|---|---|
| A 题级 | 每题用自己的注记窗口做两半期检验 | **否决**。核验④：注记 window 全 null，题级窗口不可内部分割；即便重建，同系列相邻题窗口重叠度 >95%，序列自相关使题级比例差 CI 反保守（11 §7「行级聚簇虚高 3.3 倍」的题级镜像）；审计 1300 次不可行；标签随窗口微移抖动，测量误差吞掉功效。 |
| B 纯域级 | 一域一签（最新窗口算一次） | **否决**。与 domain 完全共线 → 「控制 layer×domain 后」的条件化在代数上退化（格内零标签变异），检验跌落为格间两臂比较，有效单元仅 6 格（L1 剔除后）；此时任何题级 bootstrap 都是把 6 个独立单元冒充几百个——11 §7 聚簇教训原样复发。 |
| C 系列×期级 | **采纳**。标签赋值与审计在 resolve.kind 系列×事件期级；计分单位仍是题 | 格内变异来自两处：同格多系列各有一签（openmeteo 格含 daily_max/air/pm2.5 等异质系列，核验⑤）；同系列跨期标签随窗口漂移可变（daily_max 跨 2024→2026 有真实时间纵深）。审计单位约 40–90 个，零 LLM 可全量人工复核。这是使裁决判据（控制 layer×domain 后条件化）**在代数上可执行的最粗标签粒度**——比它粗即退化，比它细（题级）即反保守。 |

**规则（冻结文本，逐字可执行）**：对每条 L2/L3 题，取其 baseRate 注记**同源的源数据系列**，以该题 cutoff（或 resolve.date）为窗尾、取窗尾前 N 期结局序列（N=注记 n，核验④实存 300–332 量级），按事件时序切前后两半：前半 k1/n1、后半 k2/n2，比例差 d=p2−p1 的 95% CI 用 **Newcombe hybrid-score 区间**。CI 不含 0 → **漂移**；含 0 → **平稳**；min(n1,n2)<10 或 n<20 → **不可判**。
**窗口来源主次**：主=源数据侧快照重建（一次性拉取约 15–25 个系列的历史，零 LLM，快照与 k1/n1/k2/n2 落旁路表保复现）；回退=同系列账本已解结局序列（仅当源不可得且 n≥20）。选源重建为主的理由：①窗口厚度决定功效——账本结局序列只有 openmeteo_daily_max 一个系列够厚（核验⑤），主判据人口将塌缩到 n≈100、MDE 恶化到 ≈0.11–0.15，实验近乎注定含 0；②S 维的语义对象就是注记窗口本身（引擎基率的窗口），源重建与引擎口径同窗，避免「标签窗口≠引擎窗口」的错位批评；③不受账本单批时间散布限制（air_daily_mean 64 题同日批也能各得标签）。**泄漏安全**：窗尾=cutoff，窗内不含 cutoff 后信息，walk-forward 结构天然成立（照 11 §8 M5 纪律）。

**无窗口数据回退先验档（逐一列，冻结）**：
| 档 | 适用 | 先验 | 理由 |
|---|---|---|---|
| 认证源=恒平稳 | L5 全部（cwl_ssq、dlt） | 平稳 | 组合数认证分布按定义不随时间变；stage4 l5_source_resolution 84 行 note_consistent 佐证注记即认证值 |

| L2/L3 不可判 | 窗厚不达门槛的期 | **该期不进主判据人口，披露占比** | 不默认平稳：默认平稳会单向稀释臂差（造臂偏差）；只许「移出」或「归平稳」两种处置，禁第三种，冻结规则不留研究者自由度 |
| 新题 cold-start | 无历史窗口的新系列 | 不可判（照 O6 降档语义） | 防先验档随时间膨胀 |

## §3 判据与弃权

**H0（照裁决原文）**：控制 layer×domain 后，S 维格间 Brier 无差。
**主统计量**：Δ = Σ_格 w_格 × (B̄_漂移,格 − B̄_平稳,格)，只对含混合标签的格求和；w_格 = 格计分 n 占比（n 加权；等权变体作敏感性，只描述）。
**主判据（唯一 primary）**：分层配对 bootstrap——重采样在 格×臂 层内逐题进行（保持格构成），Δ 的 95% 百分位 CI，**照 stage4-run.cjs `bootDeltaCI` 既有实现**（B=1000、seed=987654321、LCG、百分位法，核验⑦），照项目口径判「CI 含 0 / 不含 0」。
**检验族声明（照 11 §8 M2）**：primary 仅此一个；等权变体、题级标签变体、含 L5/L6 池化变体、per-layer/per-domain 分解**全部只描述不检验**（禁 28 格逐格检验）——多重比较即此为零。
**标签质量前置门（照争议 1 改判条款）**：系列×期标签全量双编码（规则版 vs 人工复核，约 40–90 个全审非抽样），一致率点估计 **≥85%** 方可进读数（照 E2 C1 阈值；Wilson CI 一并披露）；一致率 <85% → **连加列制也停**（裁决原文）。事视角污染不可控同此处置。
**先验方向预注册（防事后解释，照 11 §7 先例）**：漂移臂 Brier 预期更高（机制=基率引擎 p 对漂移滞后）。只改解读纪律，不改判据。
**弃权条款（逐字写死）**：
> 若主判据 ΔCI **含 0**，S 维**永久降为文档标签，姿态门与路由主张一并放弃，DNA 线终止**；**不许换维度续命**——不得以 A/R 或其余七维的任何重述、重切分、重口径、改名重启 DNA 线；主判据人口有效题 **n<150** 或**无任何格内两臂变异** → 处置**同含 0**（同样构成「无真实差异证据」）；唯一重启通道 = 全新 PREREG + 新证据种类（新信号源）+ 用户拍板。**禁止以「功效不足」为由复议**——那是换维度续命的变体；MDE 如实并列报告，使「无差异证据」不冒充「无差异证明」（照 11 §8 M1/M4）。
**E1/E2 分工边界**：E1 只答「S 标签有无 layer×domain 条件下的信息」；E2 只答「分配规则」（10 §5）。E2 的 R1 臂若引用 S 标签，前置 = E1 通过（09 第 1 季度第 12 项：路由三关首列通过才排期）。时序分歧留痕：10 §5 主张「E2 先于 E1 式打标工程」，09 收敛裁决第 12 项明文「首列通过才排期」——**以 09 为准**。

## §4 schema 变更

**裁决：旁路表，不加列。**
对照：加列方案（predictions 增 dna_s/dna_s_basis）须 ALTER TABLE + 对存量 1300 行 UPDATE 回填——即使列是新增，UPDATE 历史行触碰账本审计语义；09 第 1 周第 3 项「additive 只 INSERT」的形态只对新增行成立，回填存量天然违反。核验：predictions 现有 23 列、1972 行历史。
**旁路表方案（冻结结构）**：
```
dna_s_labels (
  prediction_id INTEGER PRIMARY KEY,   -- FK → predictions.id，一题一签
  series_key    TEXT,                  -- resolve.kind 级系列
  period_key    TEXT,                  -- 事件期（事件月）
  dna_s         TEXT,                  -- 平稳|漂移|不可判|先验:恒平稳
  basis_json    TEXT,                  -- {窗口来源,k1,n1,k2,n2,diff,ci_lb,ci_ub,快照指纹}
  rule_sha      TEXT, rule_version TEXT, created_at TEXT
)
```
理由：①**账本不可变**——predictions 是真值账本，S 标签是读侧派生物、可随时重算，派生数据不入账本（与「无真值锚不入账」同一逻辑）；②规则迭代零迁移——v2 直接 DROP/重建旁路表，加列方案留残迹；③项目先例：intake_questions 旁路表已存在（sqlite_master 实查）、l5_sources.js 读侧重建同为旁路形态；④加列唯一优势（免 join 读）用 `CREATE VIEW v_dna_s` 解决。INSERT-only。

**回填脚本接口**：`node p1b/scripts/dna-s-backfill.cjs --db <路径> [--confirm]`
- 无 `--confirm` = **dry-run 默认**：只打印将写入行数 + 前 5 行样本，零写入（照 brn-backfill dry/confirm 先例）；
- `--db` 必填并校验文件存在；写入口径仅限 dna_s_labels 表 INSERT，predictions/verdicts 零触碰；
- **金样验收**：回填前后 g2-report JSON diff 零读数变化 + 373/318 测试常绿；验收不过即回滚（DROP 旁路表）；
- 完成落 receipt（照 batch3-receipt 形态），含行数、指纹、脚本 sha。

## §6 反方自检

**①最脆弱：标签与系列/域的混淆（共线性残余）。** 可计算窗口的题集中于 openmeteo 家族（核验⑤推算），若漂移标签进一步集中于单格，条件化退化为「单格内部比较」，跨格推广为零，臂差可能只是系列构成差。缓解：臂×格列联表**强制预披露**；集中度门——单格占漂移标签 ≥80% → 触发「无充分跨格变异」处置（=同含 0）；结论只主张「标签有 layer×domain 条件下的信息」，**禁主张「平稳性因果」**。残余风险如实声明：期内标签与题目季节特征可能相关，本实验无法剥离。
**②低功效 × 弃权条款的组合。** MDE 0.06–0.11 下，真实小效应必然含 0 → 列死。这是裁决设计（「输得起才配赢」）不是缺陷；冻结文本并列 MDE（§2/§3），并明文禁止以功效不足复议。谁会反对？主张「先跑再看、不显著另说」者——本条回答：那正是第一轮被否决的 14 天包干自由度。
