## 0. 立场：**条件放行**——放行的是一把「零成本尺子」，不是「整合」这条线

先把话说尽，再说条件：

1. **作为「整合」**（接成生产引擎／自成新层／进 PREREG 判据／上对外产品面）：**现在不该做。** 三条理由：①它对第 4 期的门**零贡献**——那道门是数据事件，不是工程事件；②它在本项目的**产品面价值 ≈ 0**（不出文本、不给解释、中文是官方承认弱项，而产品面还被铁律②压着）；③「加一个模型」在本项目的历史战绩是 **0/N**（15 条负结果，§3）。
2. **作为「一次读数」**（把「要不要」从类比换成本项目的数）：**可以做，且必须切到不能再小。** 这一刀的成本 ≈ 半页纸 ＋ 一条只读命令；收益是它可能第一次给出「账本上还有没有第 2 个独立信号位」的量化答案（§2 末）。
3. **任何立场都必须过 §4 的 pre-mortem 闸**：本件为「若放行」写死了 5 条头部风险的预防 gate 与一份禁止项清单；**绑不上 gate 的风险一律不列**（照 pre-mortem 技能停止条件）。
4. 评分：**3/10**（拆解见 §7）。读法：**够做一次读数，不够立一个案。**

## 5. 若放行：最小第一步（且为什么不能再小）

**第 0 刀（必做；零模型、零新代码、零拍板、零外网）**：出**半页《新信号源·需求与功效前置》**，用现成读数回答三问：

1. **测量侧能测到什么**：ρ̂／RES 双门（读侧；`e2-combo-precheck.cjs` 头注口径「只读、零 LLM、零网络、零账本写」，`02` §C.5）；
2. **判据侧能读到什么**：用项目自己的 MDE 公式复算。本次我**已经把最难的一块算出来了**（§8-④ 亲测输出）：
   ```
   sd_hat = 0.122382   （由角色③实测 MDE=0.044270 @ n=60 反推：sd = MDE·√n / 2.802）
   n_needed_0.005 = 4704   （与项目自己报的「判非劣需 n≈4704」逐位吻合）
   mde_at_n385  = 0.01748
   mde_at_n1005 = 0.01082
   ```
   ⇒ 量级说明：**在 n≈385–1005 上，MDE 是边际 0.005 的约 2–3.5 倍**（σ̂_d 借用角色③ 的实测离散度做量级示意，**不是本臂预测**）；
3. **需求侧**：产品面要不要「第 2 个独立引擎」（§1.3 判「不需要」）。
   产物建议落 `.scratch/jev-integration/21-功效前置.md`（**本件不代写**）。

**为什么不能再小**：再小就没有读数，只剩类比；而「用类比代替读数」是本项目最忌的一件事——不做这一刀就说「不整合」，立场恰恰建在类比上。

**第 1 刀（条件触发；仍零写入）**：仅当第 0 刀显示「有非冗余空间」**且**不占开门窗口时——用**本地可跑件**（V4 级候选：`Mapika/decider` 2B／`jaredpalmer/kev` 0.8B 路径／`convaiinnovations/laya` 421M 编码器／`heman10x/rlcd-modernbert-151m` CPU 零安装，`11` §7、`12` §1、`14` §2.5）在**已有题库子集**上离线出 p，跑 `e2-combo-precheck` 的 ρ̂／RES 两表；**本刀不碰 Jev 托管 API**（避免出网／state 外传／别名漂移）；开跑前必须已过 **G0**。

**禁止项清单（写死）**：不接生产引擎；不自成新层（L7＝schema 迁移）；不新增 `prompt_variant`；不碰 PREREG／账本；不上产品面／UI；不引红灯站；不用「预测」话术；不为它修 WSL／装 vLLM（`14` §10 已判「不该为 0.785 GiB 的模型去动系统」）。

## 6. 什么会让我改主意

**上调（可能支持立案）**：
- 出现对某个 V4 本地件的**第三方独立复现**（不是自测）＋**中文题面实测**；
- 第 0／1 刀显示：ρ̂ 对 L1／L6 的 CI 下界 ＜ 0.95 **且** MDE ≤ 0.01 量级可读（即「非冗余 ＋ 可读」同时成立）；
- **需求侧变化**：第 4 期产品面或账本明确需要「第 2 个独立引擎列」（这是唯一能改变 §1.3 判定的东西）；
- 出现 Jev **权重／可信自托管**，推翻 `10` §3 的六路否证。

**下调／收口**：
- G0 拍板裁「受 ④ 管、不得接入」⇒ 直接收口；
- 第 0 刀显示 MDE ≫ 可读量级且无低成本通道 ⇒ 照 §4.4-3 收口；
- 任何一条走成「**要动冻结层才能继续**」⇒ 停，回到用户。
