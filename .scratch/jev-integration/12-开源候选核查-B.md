### 2.2 Von —— 模型是真的，但**引用错配**，够不到 V4

**先核站点本身（§5 红灯站 `myaiexp.com`）**：直连与 WebFetch 均被墙（`HTTP 429` + "Vercel Security Checkpoint"），改用浏览器式抓取后读到站点本体：

> `<title>AI 星图 - 发现好用的 AI 工具、模型与技能</title>`；JSON-LD `{"@type":"Organization","name":"AI 星图","url":"https://www.myaiexp.com","sameAs":["https://twitter.com/hunterzhang86","https://github.com/hunterzhang86/fflow-next-nav"]}`；条目原文：「**Von** … Von 是 Apache-2.0 的 395M System One 决策模型，在 Apple MPS 上约 18 毫秒本地给出带校准的答案，是 TypeSafe Jev 的开源替代。」链接指向 `https://github.com/wfzyx/von`。

**站点可信度判定：不可作为一手来源，属"转载目录站"**。理由是它自己的页面特征：(1) 它是**收录目录**（导航为「分类/洞察/榜单/替代/最新/提交」），不是实测方；(2) 每条都挂 `Month Visit / DR / AS` 指标，且**大量条目的数值是同一套样板**（多条并列 `Month Visit1000 DR: 80 AS: 80`），另有个别离谱值（Cloudflare Wallets `Month Visit500000000`）⇒ 该站流量指标疑为生成式模板填充；(3) 它对本条**没有给出任何自测数据**，只是复述项目自述。⇒ 它对 Von 的"Apache-2.0"只是转述，**不能当证据**。

**再核模型本体（都是我亲测）**：
- HF：`https://huggingface.co/api/models/wfzyx/von-1.0?blobs=true` → 200。`likes=25 downloads=1223 created=2026-09-19T15:19:01Z lastModified=2026-09-21T02:03:24Z usedStorage=6328920643`；`safetensors={"parameters":{"F32":395834371},"total":395834371}` ⇒ **395M 属实**；`tags=["safetensors","modernbert","arxiv:2503.23303",...]` ⇒ ModernBERT 属实。真权重：`model.safetensors` 1,583,355,740 B（1.475 GiB）、`option_marker.pt` 1,581,307,210 B、`run.log` 117,650 B、`calibration.json`、`marker_calibration.json`。

## 4. 8 GiB 本机落地判断（含权重算术）
