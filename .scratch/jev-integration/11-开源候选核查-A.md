### 4.6 「有 logits 直读」与「模型自报概率」是两条不同的技术路线，本批里混着
这是对 Q4（尤其铁律 ④）最要紧的一条横向发现：

- **真·读 logits**：`SemIf`（README: `native option logits`）、`kev`（`reads the prompt once and then scores one answer token per question`）、`nimble`（`The scorer reads the model's logits for these codes`）、`decider`（`returns, from one forward pass, a probability distribution`）、`simple-jev`（`reads the model's next-token logits for each question`，且我实测到 `"output_tokens":1` 佐证）。
- **模型自报 / 口头报概率**：`LocalJev` —— README 原文明写 `The probabilities are generated/self-reported by the model rather than read directly from its logits.`

**这两类在你的铁律语境下不是同一个东西，方案里绝不能并列。**
