## 4. Q2 · Jev 的事实初稿（★已核 / ○仅搜索摘要 混排，须你复核）

**★已核（主代理亲自 WebFetch 到原文）**：
- 来源：`https://www.marktechpost.com/2026/09/19/typesafe-ai-releases-jev/`（MarkTechPost，署名 Asif Razzaq，2026-09-19）。
- 发布方 **TypeSafe AI**，产品名 **Jev**，自称 **「System One Model」**（名字借 Daniel Kahneman 的快/慢思考之分）。
- 定性：「transformer-based, but it is not a large language model. It does not generate text.」——你送 **state + typed questions**，它回 **typed decisions with probabilities** 供代码分支。
- 接口：单端点 `POST https://api.typesafe.ai/v1/systemone`；请求体含 state、model、questions 映射。
- **三种题型原语**：`Choice`（从列表选 1，返回 choice + probabilities + confidence，**最多 255 个选项**）／`Score`（按有序档位打分）／`Noul`（「这句话是真的吗」，返回 0–1 概率）。
- 并行与隔离：多个问题对同一 state 并行、互不干扰；官方称「加问题几乎不增加响应时间」。
- **confidence**：Choice/Score 每答带 0–1 的 confidence，**由概率分布形状导出**（不是独立预测）。文档例子：billing 胜率 0.84 而 confidence 仅 0.…（原文此处被截断）。
- SDK：`pip install typesafe-sdk`（Python ≥3.10）、JS SDK `@typesafe-ai/sdk`，另有 cURL 与 Claude Code skill。
- 可用性：**托管 API，early access 候补名单**；另有 Vercel AI Gateway 入口写「Hosted typesafe-ai/jev, no waitlist needed」。
- **本文明确说：TypeSafe 未发布权重、未公布参数量、无自托管选项。**

**○仅搜索摘要（未核原文，请务必核实或标注不可核）**：
- 创始人 **Diogo Almeida**（前 OpenAI，参与 ChatGPT 的指令跟随研究）；发布日 **2026-09-15**（来源：dev.to 文章摘要）。
- 定价 **$0.042 / 决策**（来源：kie.ai 博客标题「The $0.042 Decision Model」）。
- 延迟 **70–500 ms 端到端**；宣称比生成式 **193.6× 更快、444.6× 更便宜**（来源：APIMaster / openchamber.dev 摘要）。
- 训练方法含 **RLCD** 与 **parallel sampling**；官方论点＝RLHF 为人类偏好调优带来「overconfidence and mode dropping」。
- 相关站点（**★证据卫生红灯，见 §5**）：`jev-agent.com`、`jevapi.org`、`jevbest.com`、`jevusers.com`、`hermes-ai.net/jev`、`openchamber.dev/blog/jev-typesafe-ai/`、`apimaster.ai`、`myaiexp.com`、`openjev.sh`、`jevbot.app`、`foq.fr`。

**★主代理实测：`https://kie.ai/blog/what-is-jev` 用 WebFetch 取回时返回的是「服务区域通知」而非文章正文**（内容为「非中国大陆市场…China IP access stops on 2026年12月31日」）。所以「$0.042」这个数字**目前只有标题级证据**，须另找源头或标为不可核。

## 7. 可用的核查手段（主代理实测有效，直接用）

**网络直连可用，无需代理；失败时再加代理。**

```bash
# GitHub 仓库是否存在＋元数据（HTTP 200＝存在；返回 JSON 含 stars/license/pushed_at/description）
curl -s -m 12 https://api.github.com/repos/<owner>/<repo>

# 仓库文件树（看有没有真正的权重/训练代码，还是只有 README）
curl -s -m 12 https://api.github.com/repos/<owner>/<repo>/contents

# HuggingFace 模型是否存在＋标称元数据

# 失败就加代理重试（本机代理 127.0.0.1:2080）
HTTPS_PROXY=http://127.0.0.1:2080 curl -s -m 12 <同上>
```

**主代理已实测**：`curl -s -m 12 https://api.github.com/repos/TheoLeeCJ/SemIf` 直连与代理**均返回 200**。

**其它**：
- 本机 Python 命令是 **`py`**（不是 `python`）：`py -c "print(1)"`。
- 算显存/参数量的账可以用 `py`，但**只许算，不许装**（见 §8）。
- 写文件**必须用 Write/Edit 工具**，不要用 shell heredoc / `node -e`（本仓库踩过坑：Git Bash 会吞反引号与转义、`\u0000` 会写成二进制）。

**判据分级（每条候选都按这个打分）**：
