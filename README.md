# 推演沙盘 · 本地判断账本

> 记录你的判断，然后证明它没有说谎。

**把判断力做成契约，让任何 agent 都无法替你下结论。**

## 这是什么

一个跑在你本机的账本：你写下问题和自己的判断，它按时去取真值，用 Brier 分告诉你有多准。
它只交证据和分数，**不交结论**：题分三类——机器能自己查的、人才能答的、永远结不了的。
第三类**不给按钮**：给一个按了没用的按钮是欺负人。

## ★30 秒上手

> ★**今天唯一走得通的路是源码运行。** 绿色包已能产出（`node tools/pack.mjs`），
> 但产物目录**不在仓库里**（`.gitignore` 挡了 `*.zip` 与 `/out/`），
> 且**仓库地址尚未建立**（`git remote` 为空）⇒ **下载链接今天必然点不动**。
> 我们不在这里放一个点不动的下载按钮——那比不放更糟。发行包一旦挂上 Releases，
> 这一节会改成「下载 → 解压 → 双击」三步。

1. **拿到源码**（需 Node ≥ 20）：
   ```bash
   git clone <仓库地址>      # ★地址待定：仓库尚未建立
   cd music-player
   npm install
   npm start
   ```
2. 浏览器打开 <http://127.0.0.1:8787/>。**首次启动不需要任何 key**（强制 mock）。
3. 数据落在 `%LOCALAPPDATA%\P1bSandbox\`，**不在程序目录里**——所以删目录不会删掉你的账本。

**已有绿色包在手**（比如别人发给你的）：解压到**任意路径，含空格与中文都能跑**，
双击 `start.bat`，浏览器自己打开工作台。

四道闸门（后端 / 构建 / 前端 / 类型）统一跑法：`npm run gates`。

## ★8 条红线（对外版，可直接复制）

全文与出处见 [`docs/RIGHTS.md`](docs/RIGHTS.md)，本页只给能复制的那版。

1. 所有生成的中英文文本**在生成时**就写入 AI 标识；不做事后补写。
2. 工具描述与返回文本里**不出现**荐下注类语义。
3. **默认不联网**；取数类工具必须显式确认，不由调用方（或模型）自决。
4. 服务端**强制**出网白名单；不提供、不实现任何绕过反爬的路径。
5. 外部价格/赔率字段**原样返回**并附来源与时间戳，标为「市场共识数据」；不加工、不推断、不建议。
6. **默认本地部署，不提供境外托管** —— 你的账本默认不离开你的机器。
7. 账本**不写入**姓名、邮箱、工号等可识别信息。
8. **默认不记录调用方身份**，只保留不含身份的聚合统计。

**我们不做什么**：不碰博彩/投注；不代替你下结论；不接管你的钱。

## 开发

四道闸门（后端 / 构建 / 前端 / 类型）统一跑法是 `npm run gates`，**不短路**——任一道红就整体非 0。
只列不跑：`node p1b/gates/gates.cjs --list`。全库泄漏体检：`node p1b/cli/index.cjs 体检 泄漏`。账本一页纸：`node p1b/cli/index.cjs 体检 看板`。
两条 3 分钟演示路径（**展示纪律，不展示功能**）见 [`docs/演示路径.md`](docs/演示路径.md)。
