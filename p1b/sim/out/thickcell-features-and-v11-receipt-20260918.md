## §2 勘误一（判据缺口）：v1 的 kNN 行**漏带 11 号件 O1b 的三条判据**

v1 §4 只写「近邻结局频率作基率，**经 O1b 收缩式与格基率融合**」，**没带** 11 号件（`11-拒绝项救援-深度报告.md` §3）已裁定的收紧：

1. **借力只许「同变量异获取模式」子形态；跨物理过程 kind 禁**——`domain.js` 前缀族是「**同一数据供应商**」不是「**同一数据生成过程**」；openmeteo 前缀内横跨大气污染／气温／风速／日照／降水／海温，**物理异质** ⇒ **前缀族内朴素比率池化：死刑**（参照类理论第一要求＝**同质参照类**，Flyvbjerg DOI `10.1177/875697280603700302`）。
2. **收缩式（非池化比率）**，`θ̂_cell = w·θ̂_cell + (1−w)·θ̂_family`，`w = n/(n+κ)`，**κ 须预注册冻结**。
3. **金样回放零读数变化 ＋ 薄格（n<10）走 `insufficient_data` 出口**；**死亡条件**＝金样回放读数变化即撤。

**⇒ 连带影响（如实）**：v1 §1 的池 607 是**骨架**口径；**kNN 臂的实际可用样本 = 「同变量异获取模式」对内的题**，**远小于 607**；「格 n<30 不启用」因此**更严**（须按对内的 n 判）。

## §3 勘误二（实现前置缺口）：MOS／Granger 的源数据不在账本

**Granger 滞后（2A）**：蓝图 §2.3 假定「天气/经济两个厚域，连续日值序列」——**该假定在实盘不成立**（序列未入库）。实现前提＝二选一：① 臂改为**联网重取数**（新增取数依赖，须补记）② 臂**封存**＋负结果归档（「账本不存序列 ⇒ 该线在现数据结构下不可估」）。**本件不代选**（属实现路径决策）。

### ★§4.5 过程自查（**踩了已登记的坑，已修**）

冻结 v1.1 时首跑 **MATCH=false**：冻结工具的 `recorded` 取的是「**文件里第一个**被反引号包的 64 位 hex」，而 v1.1 正文**引了 v1 的完整 64 位 sha** ⇒ recorded 取成了 **v1 的 sha** ⇒ 自检永远不过。
- **这正是 §83 已登记的坑**（「正文引 v1 完整 sha 致冻结工具 recorded 取错 ⇒ **引用一律截断**」）——本轮**又踩一次**，说明该纪律的**作用域被低估**：不只是「正文」，**登记块内同样不能出现完整 64 位 hex**（正则的 `\s\`hex\`` 分支覆盖面很宽）。
- **修法**：登记块内的原件 sha 改为 `e12c9db6…` ＋「完整 64 位见 v1 件内登记块」；正文引用同截断。
- **已加回归锁**：`thickcell-replay.test.cjs` **⑧**——断言「**第一个**反引号 64 位 hex 必须＝本件自己登记的 sha」且「写在 `sha256：` 槽位」。
