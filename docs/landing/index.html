记录你的判断，然后证明它没有说谎。

大部分「帮你猜」的 App 让你感觉准一点。这个做的是相反的事：它不猜， 只记下你怎么想的，然后证明你事后没改口。 · GitHub 仓库 · README 全文

它刻意不做的事（比「它能做什么」更重要）

  • 不替你猜 —— 那是专家的事。它替你猜就等于替你说谎。
  • 不给建议 —— 「建议你关注汇率」是理财顾问的事，而且会误导人。
  • 不碰你的私钥 —— 默认只在你自己的机器上跑。
  • 不承诺准确率 —— 下面那份成绩单很难看，但它是真的。

★ 你填的概率就是你的判断，一字不差。你写 60% 就是 60%，它不会偷偷改成 55%。

它解决什么问题

你一定有过这种时刻：3 月觉得某只股票会涨，8 月回头看跌了，于是你悄悄把 3 月那条改成了「我觉得会跌」。

没有人会阻止你。Fitbit、Evernote、甚至手机自带的备忘录，都能改——因为拦你等于得罪用户。

这本账不改。 不是靠自律，是账本只写不改，每条记录都带指纹。

所以它能回答一个别人回答不了的问题：你自己知道你在哪儿系统性看错吗？

不是「你这次错了」——那是运气。是「凡是遇到这类事，你就偏乐观」。

五分钟看明白

1. 写一道有答案的事      「明天下不下雨」
2. 写上你有多确信        60%
3. 到期了它自己去查真值   下雨了 / 没下
4. 跟你那个 60% 算个分
5. 攒够一批后告诉你      「天气类你准，汇率类你系统性说大了 19%」

第 5 步是全部价值所在。前四步任何一个 App 都能做。

六层分类是整个项目的骨架

不是六个算法模型，是六种「这事到底能不能算」的判法。

层大白话例子你的分数
L1 决定论有确定答案，纯算明年日食几号几分几秒0.0000（满分）
L2 常态有历史规律，取平均某人平均投多少球0.2403
L3 短窗有机制但混沌汇率、短期行情0.2386
L4 自反你的判断会改变结果「我觉得这股票要跌」不用（会自我实现）
L5 纯随机数学上不可能赢抛硬币、抽奖0.1578
L6 对抗有人在跟你对着干博弈、谈判0.1755

为什么必须分层：L1 能拿满分，L5 数学上就赢不了。把它们混在一起算一个总平均， 等于拿天气预报去跟抛硬币比。分了层你才知道「你在哪一层准、在哪一层根本不该指望准」。

三种用法

① 当 app 用最简单。clone ＋ npm install ＋ npm start，不需要任何 API key。
② 装进 AI 工具最推荐。MCP 协议，21 个工具，装上就能说人话调用。
③ 当库用最轻。require 一下就能算分，不用起服务。

② MCP：在你的 AI 客户端里加一段

{
  "mcpServers": {
    "p1b": { "command": "node", "args": ["/绝对路径/p1b-sandbox/p1b/mcp/index.cjs"] }
  }
}

装上之后你可以直接对它说：

你这么说它会
「帮我记一道：明天会不会下雨」归类 → 查拒收门 → 落进不可改的账本
「我在哪类事上偏得厉害」按题型分开算，指出系统性偏差
「这题算不算随机」六层判定 ＋ 为什么这么判
「这批数据被改过吗」冻结哈希 ＋ 锚点闸 ＋ 契约一致性

0 个能真写账本 21 个 MCP 工具里真正能写账本的是 0 个——写操作全部在确认闸后。AI 问你，它会问回来；它不自己动手。

★8 条红线

  1. 生成的文本在生成时即写入元数据隐式标识，不做事后补写
  2. 工具描述与返回文本中，不出现「建议下注／信号／必胜／稳赚」等语义
  3. 默认不联网。取数必须显式确认
  4. 服务端强制出网白名单，不提供任何绕过反爬的路径
  5. 外部价格／赔率原样返回并附来源与时间戳，不加工、不推断、不建议
  6. 默认本地部署，不提供境外托管。你的账本默认不离开你的机器
  7. 账本不写入姓名、邮箱、工号等可识别信息
  8. 默认不记录调用方身份，只保留不含身份的聚合统计

常见问题

问答
它能提高我的判断力吗？能，但有前提。它给的是「你在哪类事上看多了」——别的工具都不给。但你得自己手写几十条判断，现在真人写的还是 0 条。
为什么分数这么难看？因为好看是假的。它宁可难看也不好看。
数据会传到网上吗？不会。默认本地跑，不联网上报（只有你自己开 token 才会）。
要填 API key 吗？不要也能用，只读功能全部可用。填了 key 才能让 AI 帮你分析。
