# 私人 AI 音乐电台：账号调研与 30 天执行方案

> 调研日期：2026-09-02 ｜ 产能设定：本地引擎（ACE-Step 1.5 / HOT-Step）日产 1–2 首 ｜ 目标平台：B站（主站）+ 抖音（切片分发）

## 〇、一句话结论

**思路成立，而且你的供给结构（自产、日更、版权干净）恰好打在搬运型电台号的死穴上。** 但要赢的不是「AI 能做歌」——AI 音乐的「量」早已不稀缺，稀缺的是筛选、场景与人设。把账号当「电台主理人」经营，AI 只是你身后的制作部；发布时如实标注 AI 生成（这是 2025-09 起的强制规定），内容重心放在氛围与选歌眼光上。

## 一、可行性判断

### 有利的四点

1. **供给充足且独家**：日更 1 首 ≈ 每月 30 条稿件，远超一般音乐 UP 的更新强度；电台类账号的核心就是「陪伴感 + 固定栏目」，更新稳定性本身就是权重。B站站内已有同类形态被验证：「罗德音乐电台」连载到第 101 期、「AI音乐小电台」「温柔女声音乐电台」等栏目均以固定栏目形式运作。
2. **版权干净**：B站/抖音大量音乐电台号靠搬运网易云等平台歌曲，最大风险是版权投诉下架；你用本地引擎 + 自写词是「第一手原创」，天然免于此劫。引擎侧也无合规负担：ACE-Step 仓库 LICENSE 实读为 **MIT**（商用、改编、分发无障碍；发布前顺手自查模型权重附带说明即可）。
3. **零边际成本**：本地生成 + 本地渲染，试错自由——可以大胆做风格实验、A/B 封面、快闪栏目。
4. **无诉讼连带风险**：RIAA 及丹麦 Koda 起诉的是 Suno/Udio 的**训练数据**侵权，属于平台方行为，不波及用户发布自生成的音乐。

### 要警惕的四点

1. **AI 音乐「量」已不稀缺**：Suno 类工具让全网日产百万首，观众不会因为「这是 AI 做的」而停留。账号本质是**策展型电台**——你的筛选眼光、主题编排、氛围一致性才是护城河。
2. **观众对 AI 音乐存在抵触情绪**：策略 = 不隐瞒、不回避、不主打。合规要求标注 AI，但人设重心放在「审美筛选」与「陪伴感」上，人设是主理人不是技术展示。
3. **强制标注新规**：《人工智能生成合成内容标识办法》2025-09-01 施行；抖音官方口径明确「未按新规标注，轻则限流降权，重则账号处罚、内容下架」。
4. **无人直播红线**：B站/抖音对「无人直播」（24h 循环歌单直播间）均有限制，lofi girl 式直播间初期不要碰，老老实实做稿件。

### 关于启动时间

你提到「6月底」与当前时间（9 月初）对不上，不影响方案：下文全部按周推进，无论何时启动直接套用。

## 二、账号定位（四选一，可组合）

| 方案 | 内容形态 | 优势 | 建议角色 |
|---|---|---|---|
| A 深夜私人电台 | 人格化栏目「XX电台 第N夜」，lofi/氛围/爵士/钢琴，睡前陪伴 | 粘性高、栏目感强、日更压力小 | **主轴 ★★★★★** |
| B 风格档案馆 | 「每周一个流派」系列：AI 复刻 City Pop/后摇/Chillhop…，配 300 字风格小科普 | 差异化最强、知识区+音乐区双流量、搜索友好 | 每周日特辑 ★★★★ |
| C 场景歌单 | 雨夜/通勤/自习/加班专供，封面即场景 | 抖音最吃场景词，封面转化高 | 融进 A 的标题与封面 ★★★★ |
| D 点歌台 | 评论区投票决定下一期风格/主题 | 互动率最高，养评论区 | 第 4 周起启用 ★★★ |

**推荐组合**：A 为主轴 + C 融进标题封面，每周日固定一期 B 特辑，第 4 周启动 D。

- 标题模板：`【XX电台 EP.07】雨夜爵士 · 适合 23 点以后`
- 栏目名建议 2–3 字 + 电台感（如「回声站」「慢速频道」「月亮仓库」），**先定名再开号**，改名伤权重。

## 三、内容形态：不同类型音乐的画法

| 音乐类型 | 视频画法 | 要点 |
|---|---|---|
| 人声歌 | 歌词逐行滚动（卡拉OK式或整行淡入） | ACE-Step 生成自带结构化歌词 → LRC → 字幕；封面情绪 > 信息量 |
| 纯音乐/BGM | 氛围场景图/微动态（雨窗、篝火、城市延时） | 抖音切 30–45s 高潮段引流完整版 |
| 电子/实验 | 频谱可视化（ffmpeg showspectrum 等） | 最省人力，赛博感契合 AI 属性 |
| 长歌 4–5min | B站完整版 + 进合集 | B站对长视频友好 |
| 每周合集 | 当周 7 首打包「周更歌单」长视频 | 拉合集播放量，适合挂充电 |

**系列归档**：B站合集按 mood/genre 双维建（如「午夜电台」「雨天特辑」）——合集 = 完播加权 + 追更入口，务必用。

## 四、生产流水线（贴合现有工具链）

    生成 → 精修 → 体检 → 歌词 → 视频 → 封面 → 发布

1. **生成**：ace-music 技能（turbo 海选 → SFT 精修两段式）；精品成曲走 hot-step 的 song-sop 七步。
2. **响度体检**：music-polish（Matchering + ffmpeg），对齐流媒体标准 ≈ **-14 LUFS**，别发「毛坯」响度的歌。
3. **歌词对齐**：ACE-Step 的 lyrics 直接转 LRC（本地脚本或 LRC Maker 在线工具）。
4. **视频合成**：三条路线按投入排序——
   - **路线① 全自动脚本（推荐起步）**：ffmpeg + ASS 歌词字幕 + 封面图，一个脚本吃 wav+lrc+jpg 吐 mp4，日更零手工；横屏 1920×1080 起步。
   - **路线② Remotion 程序化模板**：React 写微动效（歌词浮动、频谱、进度条），质量上一档，适合做「账号视觉签名」。
   - **路线③ 剪映模板**：兜底方案，人工灵活但费时。
   - 现成参考：GitHub 上多个 lyric-video 生成器（Manzana-Apple-Music-Lyrics、MVSlideGenerator 等）可借鉴结构。
5. **封面**：AI 生图固定模板（统一色调 + 期数角标 + 台标 + 主题词）；你有 Blender 3D 场景技能，渲染氛围场景做封面是独一档的差异化。
6. **发布**：B站为主站（投稿选**原创音乐**、进合集、简介带完整歌词+标签）；抖音每天 1 条竖版切片互相引流。

**建议目录结构**（E:\music player 即工位）：

    E:\music player\
      songs\<date>-<title>\   wav / lrc / 封面 / 元数据.json
      covers\  templates\    封面模板 / ASS 字幕 / ffmpeg·Remotion 模板
      out\                   成品 mp4（按平台分子目录）
      publish-log.md         发布台账：日期/平台/风格/数据回填

## 五、平台规则与红线（有据可查）

1. **强制 AI 标识**：《人工智能生成合成内容标识办法》（网信办等四部门）2025-09-01 施行；腾讯、抖音、快手、B站、微博等 8 平台均已上线 AI 标识功能。**发布时主动勾选「AI 生成」。**
2. **抖音处罚口径**：官方口径「未按新规标注，轻则限流降权，重则账号处罚、内容下架」——不要赌。
3. **B站投稿分类**：选「原创音乐」，绝不选翻唱/搬运；简介写清「AI 生成音乐，词曲为个人原创」，既合规又免纠纷。
4. **生成内容自查**：引擎偶尔「撞旋律」，发布前完整听一遍副歌；**不要**克隆他人声线翻唱（声音权风险），不要用他人歌词。
5. **Suno/Udio 诉讼与你无关**：RIAA 与丹麦 Koda 起诉的是平台训练数据侵权，不涉用户；但也别拿「AI 音乐」当争议噱头碰瓷。
6. **无人直播**：24h 循环歌单直播间在两平台都有无人直播限制；若后续要做，用推流 + 真人值守 + 弹幕互动，初期跳过。

## 六、增长打法（30 天冷启动）

1. **垂直标签**：B站投稿标签固定 3–5 个（#音乐电台 #助眠 #学习背景音 #AI音乐 #原创音乐），让算法稳定给你打「电台」标签。
2. **固定更新时间**：晚 21–23 点发布（电台场景）；B站日更正片，抖音每天 1 切片 + 隔天 1 条场景歌单。
3. **标题公式**：栏目名 + 期数 + 主题词 + 场景词（见 §二）。
4. **封面公式**：同一构图模板换主题元素，系列感 > 单张惊艳；固定期数角标。
5. **前 3 秒**：直接进主题（歌名 + 今天氛围一句话），**别加片头动画**——完播率杀手。
6. **结尾钩子**：预告下期主题 + 引导订阅合集；评论区固定置顶「下一夜想听什么风格？」。
7. **数据指标**：B站看完播率、合集播放占比、追更数；抖音看 3s 完播、复播、主页访问。哪个 mood/genre 数据好，第二个月就固定成子栏目。
8. **应对「AI 抵触」**：文案讲歌背后的场景与心情，不是「AI 多厉害」；B站观众吃「审美 + 陪伴」，抖音观众吃「场景 + 氛围」。

## 七、变现路径（按成熟度排序）

1. B站创作激励（粉丝/播放达标后）→ 充电 / 合集付费。
2. 抖音创作分成（中长视频）+ 星图商单。
3. **定制 BGM 服务（最快回血）**：本地引擎零边际成本，给自媒体/播客/短视频主定制；账号即作品集，简介挂联系方式。
4. 流媒体上架（第二阶段）：网易云/QQ 音乐人平台——政策在动态变化，上架前先读最新音乐人协议并如实标注 AI 生成，不急。
5. 长线：主题月历（季节/节日特辑）→ 品牌联名歌单。
