## ① 一句话定调

**账号 = 电台主理人，AI = 你身后的制作部。**
赢的关键不是"AI 能做歌"（量已烂大街），是**筛选眼光 + 氛围一致性 + 日更稳定**。
发布必须勾选「AI 生成」（2025-09-01 强制新规，不勾=限流/下架）。

## ③ 账号定位（方案四选一的推荐组合）

- **主轴 = 深夜私人电台**：「XX电台 第 N 夜」，lofi/氛围/爵士/蓝调/City Pop 睡前陪伴
- 融合：标题封面带场景词（雨夜/通勤/加班）+ 每周日一期"风格档案馆"特辑 + 第 4 周开点歌互动
- 标题公式：`【XX电台 EP.07】雨夜爵士 · 适合 23 点以后`
- **先定栏目名**（2-3 字+电台感：回声站/慢速频道/月亮仓库 这类）

## ④ 生产流水线 ↔ 技能映射（你要看的部分）

```
做歌 ──────── hot-step（song-sop 七步，现行流程不变）＋ ace-music（海选）
体检 ──────── music-polish（-14 LUFS 达标才发布）＋ 四层评价（DSP/Audiobox/质检/耳朵）
歌词 ──────── MM3 自带 LRC ✅ 零额外工作
视频 ──────── 【待建】ffmpeg+ASS+封面 一键脚本（W1 首要任务）
封面 ──────── 【待建】固定模板（统一色调+期数角标+台标）；Blender 渲染氛围图是独一档
发布 ──────── 人工（B站选"原创音乐"+勾 AI 生成+进合集；抖音每天 1 竖版切片）
```

## ⑤ 红线（只有 5 条，全在原档 §五）

1. 发布**必勾**「AI 生成」（B站/抖音同规）
2. B站分类选**原创音乐**，简介写"AI 生成音乐，词曲为个人原创"
3. 发布前完整听一遍副歌防"撞旋律"
4. 不克隆他人声线、不用他人歌词
5. 无人直播初期不碰

## ⑥ 30 天节奏（浓缩版）

- **W1**：定栏目名 → 视频合成脚本跑通 1 条全流程 → 储备 ≥10 首精修歌（正在跑的队列就是在做这个）
- **W2**：双平台开号 → B站建合集 → 开始日更（B站正片+抖音切片）
- **W3**：数据复盘定子栏目 → 周日"风格档案馆"第一期
- **W4**：评论区点歌互动 → 月度复盘

## ⑦ 我的补充建议（AI 视角，原档没有的）

1. **首批库存直接用今晚的队列**：02 蓝调/03 电台北/04 日语 CityPop/05 福音/01 雷鬼 五首完全命中"深夜电台"氛围；07 热血番和 06 Trap 不适合电台人设，留作"风格档案馆"特辑素材（正好体现"筛选眼光"）。
2. **视频合成脚本是唯一卡点**：给我 wav+lrc+封面图三件套，ffmpeg 一键出 mp4 的脚本我可以直接写（ASS 字幕逐行滚动+固定模板），W1 的验收就是这个。
3. **定制 BGM 变现最快**（原档 §七.3）：账号开起来后，"接单-生成-交付"全程本地自动化，这块你现在的工具链已经 90% 就绪。
4. **人设文案公式**：每期简介 = 场景一句话 + 歌背后的心情（不提 AI 多厉害）——这条写进发布模板。
