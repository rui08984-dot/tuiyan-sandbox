## 0. 先说三个改变结论的发现（本机实测，与文档冲突处以实测为准）

### 0.1 ★ GitHub Actions **不可行** —— 没有 git 远端

```bash
git remote -v   # 输出为空
```

Agent 化评估报告 §9 把「CI 绿灯（1 人日）」列为**硬顺序第 1 步**，
§12 第 5 条写「建 GitHub Actions + 前端 npm test script（1 人日）」。
**在本机这两条都执行不了** —— 没有远端就没有 GitHub Actions。

⇒ **`ci` 模块改为本地形态**：`pre-commit` hook ＋ 一条统一跑四道闸门的 `npm test`。
四道闸门本身昨天已全绿，缺的只是「自动跑」这一层。

### 0.2 ★ 评估报告 §11 的 0.2349 算错了 population

本机 `node:sqlite {readOnly:true}` 逐行重算（n=1700，口径
`resolved_at IS NOT NULL AND assigned_prob IS NOT NULL AND outcome IN ('true','false')`）：

| 量 | 本机实测 | 对外口径原文 | 评估报告 §11 |
|---|---|---|---|
| 观测 Brier | **0.225920** | 0.2259 ✅ | 0.2348653 ❌ |
| 95% CI | **[0.219415, 0.232425]** | [0.2194, 0.2324] ✅ | — |
| 理论 E[p(1−p)] | **0.226656** | 未核实 | 0.2299864 |

⇒ **「对外口径」的数字是对的，评估报告的 0.2349 有误。**
⇒ 但**结论反而更硬**：理论随机基线 **0.226656 落在 CI 内**
⇒ **账本与「拿 p 当权重掷一次骰子」统计上不可区分。**

### 0.3 ★ 最后一处表述风险已在本轮堵掉

`docs/specs/对外口径-20260928.md` 原写「这是本项目唯一一条经得起追问的整体质量读数……显著优于永远报 50%」。
**已撤**，并补上实测的 E[p(1−p)] 与「落在 CI 内」这一行。
理由：0.5 是阈值型气候题上**最愚蠢的基线**；对方一句「把你们自己的 p 代进去算 E[p(1−p)]」就把它问塌。
对外只保留一句：「口径完整可复算；同一批数据上我们**没有**显示出超越基率的预测能力——这一点我们公开。」
