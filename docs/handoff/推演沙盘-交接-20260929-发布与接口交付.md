## 4. 环境备忘

- **`python` 是商店占位符** ⇒ 全路径 `C:/Users/crx/AppData/Local/Programs/Python/Python313/python.exe`
- **★批处理改行尾前必须按文件类型过滤** —— 2026-09-30 我用 `git status --porcelain` 取列表（★**含未跟踪文件**），
  对 30 个文件做了 CRLF→LF，**把 28 张 PNG ＋ 1 个 db 永久损毁**（PNG 签名里就有 `0D0A`）。
  登记在 `p1b/.tmp/受损登记/README.md`
- **`git ls-files` 必须加 `-c core.quotepath=false`**，否则中文名文件被静默跳过
- **做变异测试用 `cp` 备份，★不要 `git checkout -- <file>`**（会连未提交改动一起退掉）
- **注释里不许写看起来像真端点的串** —— 发行闸 C3 照红（我连犯三次）
- **curl 传中文 JSON 会坏** ⇒ payload 写 UTF-8 文件后 `--data-binary @file`
- **GitHub 收 Release 附件用 `--data-binary` ＋ `?name=`**；multipart 那条路在这个 API 上报 Invalid name
- 令牌在 **Windows 凭据管理器**（`git credential fill` 读得到），无 `gh` CLI
- 8787 服务零接触
