# 两条 3 分钟演示路径

> **这两条都不是功能演示。** 路径 A 展示「它会拒绝」，路径 B 展示「我亲手删掉自己的漂亮数字」。
> A 用绿色包（陌生人形态）即可；**B 需要源码 checkout**（纪律是可展示的，但要看代码与留痕件）。

## 路径 A · 给第一次见的人 —— 核心是展示「拒绝」

```
0:00 首页指那个大数：「这是系统里全部还没落定的题，**不是我记的**——
      这产品的规矩是先把归属分清」
0:25「三类：机器能自己查的、人才能答的、永远结不了的。
      **第三类不给按钮——给假按钮是欺负人**」
1:00 记一道题，重点讲第二栏「答案去哪里查」
1:40「它给了我同类题历史频率 12%，样本 34 条。
      **它没替我说『我觉得会跌』——那是我填的 40%**」
2:40「只有 1 道题，所以什么都不显示。
      **它不会拿 1 道题给我画个『你偏乐观』的结论——这才是我信它的原因**」
3:00「这页是死假设，每条挂 PREREG 的 sha16。**这是整个项目最贵的东西**」
```

★每一句都能在代码里落到一处，不是话术：三桶见 `p1b/web/src/pages/ResolvePage.tsx`（含「③ 永远结不了」）；
「答案去哪里查」是记一笔页必填栏（`p1b/web/src/lib/noteProb.ts` 缺它就拒发）；
「不许拿历史频率当用户的数」是 `p1b/web/src/lib/noteProb.test.mjs` 的一条断言；
「样本不足就不出结论」是构建产物里必须保留的文案（`p1b/web/dist.test.mjs`）。

## 路径 B · 给要给他人看的人 —— 核心是纪律的可展示性

```
0:00 全库泄漏体检「一条命令扫全库，★leak 逐条单列」
0:40 Q0 拒收门「**候选 0 条时它 exit 3，不是 exit 0。
      空集不许被读成通过。这是整个项目最重要的一行设计。**」
1:20 演示 exit 3 → isError:false ＋ verdict.gate='FAIL'
2:00 任意一题的六段一生，指 truth_basis.excluded
3:00 对外口径「**这页是我自己的话术管制：
      三个数字我亲手删了，因为它们会被第一问击穿**」
```

★最后一句指的是 [`docs/specs/对外口径-20260928.md`](specs/对外口径-20260928.md)：
哪些数字对外能说、哪些不能说、为什么，逐条写了理由。
`isError:false` 那条不是约定，是实现——见 `p1b/mcp/exitMap.cjs`（退出码 3 映射表）。

## 跑给别人看之前：三条命令自己先跑一遍

三条都是只读（CLI 档位 R），在仓库根目录执行：

| 命令 | 预期退出码 |
| --- | --- |
| `node p1b/cli/index.cjs 体检 泄漏` | 0 |
| `node p1b/cli/index.cjs 门禁 锚点 p1b/sim/out/candidate-trace-b4-20260918.json` | 0 |
| `node p1b/cli/index.cjs 门禁 锚点 docs/demo/candidates-empty.json` | 3 |

★**最后一条故意给 3。** 它读的是一个空候选集件（`docs/demo/candidates-empty.json`），
门禁的判据是「候选 0 条 ⇒ exit 3，防空集被读成通过」（`p1b/scripts/anchor-gate.cjs`）。
★同一份退出码经 MCP 适配层映射成 `isError:false` ＋ `verdict.gate='FAIL'`：
**一道设计好的闸在正常工作，不是工具报错** —— 这正是不能把它抹平成 0 的原因。

★上面三条命令与它们的预期退出码，由 `p1b/test/readme.test.cjs` 逐条**真跑**并断言；
改坏了这里，闸门会红。
