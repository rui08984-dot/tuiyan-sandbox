## §1 三类分支形态的构造性分析（纯逻辑，附实测锚）

### 1.1 D 型（互斥划分型）——**Δ≡0 构造性恒等**（★本设计题的核心）

设父题事件 E，分支 B₁..B_k 为**互斥且完备**划分（B_i∩B_j=∅、∪B_i=Ω）。合成读数按全概率定律：

```
P_synth(E) = Σ_i P(B_i)·P(E|B_i)
```

若分支生成器**不产生新信息**——即子题读数恰为「父题分布被分区读出」（如 1X2 的 home/draw/away 三支：子题读数就是父题同一分布的三片）——则：

- 对父题「主队获胜」而言，B_home 下 P(E|B_home)=1、B_draw/away 下=0 ⇒ P_synth = P(B_home)；
- 而 P(B_home) 的读数来源与父题直接判词**是同一分布**（同一次 LLM 判词/同一市场价/同一引擎读数按 pick 切片）⇒ **P_synth ≡ P_direct，逐题恒等，ΔBrier ≡ 0**。

**这不是「效果差」，是「没有信息通路」**——与 E2 C2「Δ≡0 无信息量」（9 臂批实测：一致率 0%、12/13 格成员输出逐位相同）同一教训：**判据在此形态上测不到任何东西**。

**实测锚（本次读盘）**：账本 20 道 `oddsapi_h2h` 题全部为 `pick=home` 单边二值题；其 `marketPrice` 三路口径 p_home+p_draw+p_away 归一化最大偏差 **2.22e-16**（即同一分布的完备划分）。⇒ 若把 1X2 三支当分支、以市场价为子题读数，合成读数与父题读数**逐位相同**（构造性，非经验）。

**推论（写死进 PREREG）**：**D 型父题不进「合成 vs 直接」判读单元**；其分支只可用于**披露**（分支结构质量、过锚率）与 **6C 结构分量**（该分量在 D 型上仍非平凡：它测的是「同一分布被切成几片后的分歧」——但那不是新信息，须如实标注为**形态标签**而非不确定性读数）。

### 1.2 U 型（替代路径型）——noisy-OR，非平凡对打成立

设父题事件 E =「任一路径 i 通向 E」（路径间非互斥），按 6B：

```
P_synth(E) = 1 − Π_i (1 − P(E|B_i))
```

与 D 型的关键差别：**各路径的读数来自不同子命题的独立判词**（不同题面、不同证据块），不是同一分布的切片 ⇒ 合成读数含**路径间互补信息**，与父题直接读数**可不同** ⇒ 对打**非平凡**。

**判据在此形态上测的是**：「把父题拆成若干路径子题后，机械合成的读数是否不劣于直接判词」——这正是 Dawid 1982 校准传播定理的适用形态。

**实测锚（本次读盘）**：账本里**「路径型」子命题现为 0**（`statement LIKE '%屠%' OR '%神%死%' OR '%民%死%'` ⇒ 0 条）；狼人局 30 场全部满足「夜杀恒为平民（30/30）∧ 狼胜⟺放逐平民（30/30）」——**狼胜条件恰是单路径**（放逐平民 ⇒ 狼胜），路径型分支在现语料上**需先出题**（属角色③本体工作量，不是判读面选择问题）。

### 1.3 N 型（合取组合型）——**非平凡，且盘上已存在实测样本**

若父题 = 子题合取（E = A∧B），分支读数取自两个**独立子题**的判词，则 P_synth 可非平凡（例：P(A∧B) 的机械合成 vs 父题直接判词）。

**实测锚（本次读盘，关键）**：sim 域已存在**完整父子族**——

| 族 | 父题 | 子题 | 题数 | 判词行（批 `ca1b5cdbddfc`） |
|---|---|---|---|---|
| T9 | 「被放逐者是狼人**且**最高票唯一」 | T9a「被放逐者是狼人」＋T9b「最高票唯一」 | 30/30/30 | 90/90/90（3 变体齐、零空值） |
| T10 | 「第一条公开发言者未被放逐**且**投票无弃票」 | T6「第一条发言者未被放逐」＋T4「投票无弃票」 | 30/30/30 | 90/90/90（同上） |

- **真值一致性实测**：T9 ≡ T9a∧T9b **30/30**（父题真值就是子题合取，程序结算同源）。
- **读数分布（`ca1b5cdbddfc` 批，L6 结构聚合口径，3 变体均值）**：T9 p̄=0.409/ȳ=0.300；T9a p̄=0.464/ȳ=0.300；T9b p̄=0.595/ȳ=0.967；T10 p̄=0.590/ȳ=0.533；T6 p̄=0.673/ȳ=0.633；T4 p̄=0.733/ȳ=0.900。
- **非平凡性证据**：子题读数与父题读数**不相等**（如 T9a=0.464、T9b=0.595，而父题=0.409 ⇒ 合成与直接必有差异）⇒ N 型**天然避开 D 型的构造性恒等**。

**但 N 型有一条必须写死的诚实边界**：父子题真值同源（都是程序结算），父题直接判词的证据块与子题判词的证据块**部分重叠**（同局、同 cutoff）⇒ 对打测的是「**结构分解是否带来读数改善**」，不是「新数据是否带来改善」。PREREG 须如实登记该边界（见 §4 规则三）。

## §2 判读面选择的三条候选与淘汰理由

| 候选 | 形态 | 数据可行性（实测） | 裁定 |
|---|---|---|---|
| **A. 1X2（oddsapi_h2h）** | D 型 | 20 题、零判词、全 home 单边 | ❌ **构造性恒等**（§1.1）——不进判读 |
| **B. 狼人路径型（新出题）** | U 型 | 路径子命题 0 条（须角色③先出题） | ⏸ **留待实现期**（角色③本体产能，非判读面问题）；noisy-OR 规则本次冻结 |
| **C. sim 域合取族（T9/T10）** | N 型 | **已存在**：6 题面×30 场=180 题、判词 3 变体齐、真值程序结算 | ✅ **本次判读面** |

**选 C 的附加理由**：①零新出题成本（父子题都在盘上、都已结算）；②判词批与真值批**同域同 cutoff**（R-B 口径），无泄漏；③30 场×2 族=**60 个判读单元**（父题），满足配对对打的样本要求（同厚格 C1 惯例 n≥30/单元）；④与蓝图「校准传播实证」要求的「按层聚桶可靠性图」兼容（L6 域 60 题可聚桶）。

**★必须先核池的教训（kNN 对 1）**：选 C 前已核「它在**池**里还剩几条」——T9/T10 家族 6 个题面各 30 条全在池（无真值口径缺陷排除），判词 3 变体零空值（§1.3 表）⇒ 前提落实。

## §3 合成器口径（本次冻结的机械规则）

- **合成函数**：N 型＝**合取合成**（乘积，因 E=A∧B 且 A、B 读数独立题）：`P_synth = P(A)·P(B)`；D 型＝全概率（**但 D 型不进判读**，函数仍实现以备用/披露）；U 型＝noisy-OR（**规则冻结、暂不判读**）。
- **读数来源**：**只读现役 L6 结构聚合**（`l6_structural.js`：每变体取最新非空 implied_prob 再求均值）——**不新跑 LLM、零账本写**。
- **判据口径**（照蓝图原文＋厚格惯例）：
  - 主判据＝ΔBrier（合成 − 直接）配对 bootstrap 95%CI；**非劣上界 ≤ +0.005**（与厚格 C1/阶段 5 同线）；
  - 同报 **σ̂_d 与 MDE ≈ 2.8·σ̂_d/√n**（照厚格 §6 义务）；
  - 校准传播＝可靠性图（10 桶）**不劣于各分支**（比较 REL 分量）；劣化 ⇒ **降为只披露不采用**（蓝图原文）。
- **Bootstrap 惯例**：B=1000、seed=987654321（照 `thickcell-replay.cjs`／`e2-combo-precheck.cjs` 现役值）。

## §4 结论（三条，原样进 PREREG）

1. **D 型（互斥划分）不进判读**——Σ 子题 p ≡ 父题分布 ⇒ Δ≡0 构造性恒等，判据测不到信息（§1.1 附 2.22e-16 实测锚）。
2. **N 型（合取族）＝本次判读面**——sim 域 T9/T10 两族、60 判读单元，父子题均在池、判词齐、真值程序结算（§1.3）。
3. **U 型（noisy-OR）规则冻结、判读留待实现期**——路径型子命题现为 0 条，属角色③出题产能问题；本件只冻结其合成规则（§3），不设判读单元。
