## §3 ★新发现 12 条的分两类

### A 类：题面**缺 cutoff 声明**（id 1459-1464，6 条）

```
题面：【backfill】美国 CDC FluView 202630 周（MMWR）ILI 就诊量 >= 42083 人次
      ↑ 无 cutoff 说明
meta.cutoff = 2026-09-05（落库时点）
窗口起点    = 2026-07-26（202630 周首日）
⇒ cutoff 晚于窗口起点 41 天
```

**语义**：CDC FluView 周数据约**次周五**发布 ⇒ 202630 周（07-26~08-01）数据约 **08-07 发布**
⇒ cutoff（09-05）时**该数据已发布 29 天** ⇒ **判词能看到答案** ⇒ **真泄漏**

### B 类：★**题面与 meta 不一致**（id 1929+，6 条）

```
题面：【backfill】… 202630 周 …（cutoff=该周结束后次日（严格早于真值公布日 滞后约 2 周）；…）
      ↑ 题面声称 cutoff = 周结束后次日（≈08-02）—— 这是**正确的口径**
meta.cutoff = 2026-09-12（落库时点）—— ★与题面声称不符
```

⇒ **题面写对了，`meta.cutoff` 写的是落库时点**（**字段填写错**，非题面设计错）。
