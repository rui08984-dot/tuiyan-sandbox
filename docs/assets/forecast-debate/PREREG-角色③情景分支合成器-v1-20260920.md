## §2 判读面（设计题三条结论，本件承载）

1. **D 型（互斥划分型）不进判读**——Σ 子题 p ≡ 父题分布（同一分布的完备划分）⇒ P_synth ≡ P_direct、Δ≡0 构造性恒等（实测锚：20 题 1X2 市场价三路归一化最大偏差 2.22e-16）。D 型分支只用于**披露**（分支结构/过锚率）与 **6C 结构分量**（须标注为形态标签，不是新信息）。
2. **N 型（合取族）＝本次判读面**——sim 域 T9/T10 两族：6 个题面 × 30 场 ＝ 180 题（父题 60 个判读单元），父子题均在池、判词 3 变体齐、真值程序结算（T9≡T9a∧T9b 实测 30/30）。
3. **U 型（noisy-OR）规则冻结、判读留待实现期**——路径型子命题现为 0 条（角色③出题产能问题）；本次只实现合成函数，不设判读单元。

**N 型的诚实边界（写死）**：父子题真值同源（程序结算）、判词证据块部分重叠（同局同 cutoff）⇒ 对打测的是「**结构分解是否带来读数改善**」，**不是**「新数据是否带来改善」；该边界进收据与披露。

## §3 合成器口径（机械规则，纯函数零 LLM）

- **合成函数**（唯一实现，`p1b/scripts/role3-combiner.cjs`）：
  - **conjunction（N 型，本判读）**：`P_synth(E=A∧B) = P(A)·P(B)`（子题为独立题，读数独立取）。
  - **partition（D 型，披露用）**：`P_synth = Σ_i P(B_i)·P(E|B_i)`；判读单元不取此模式。
  - **noisy_or（U 型，冻结待用）**：`P_synth = 1 − Π_i (1 − P(E|B_i))`。
- **读数来源**：**只读现役 L6 结构聚合**（`l6_structural.js` 固定规则：每变体取最新非空 `implied_prob` 再对可用变体求均值；实验批前缀排除照登记表）——**不新跑 LLM、零账本写**。
- **判词批口径**：**固定 run_id**（本件冻结为 `ca1b5cdbddfc`＝R-B 基线批；理由：与真值批同域同 cutoff、且为消融基线批）。若批行缺失 ⇒ 该单元记 `missing` 并**计入分母披露**（禁静默丢弃）。
- **6C 全方差输出**：`Var(E) = E[Var(E|B)] + Var(E[E|B])`（N 型下按合取分解；结构分量＝分支间条件读数均值的方差），**只披露不判生死**（喂 O6 用）。

## §4 判据实现（数字写死，照厚格/阶段 5 同线）

- **ΔBrier 定义**：Δ = Brier(合成) − Brier(直接)，**按题配对**；Δ<0 ⇒ 合成更好。
- **主判据 C1（非劣）**：配对 bootstrap（B=1000、seed=987654321，对**题**重采样保留配对）Δ 的 95%CI **上界 ≤ +0.005**。
- **C2（方向）**：Δ 的 CI 上界 < 0 ⇒ 合成显著更好（**只披露，不设承诺**）。
- **C3（校准传播）**：合成读数 vs 直接读数的 10 桶可靠性图；比较 **REL 分量**（`rel = Σ(n/N)(f−o)²`，与 `e2-combo-precheck.cjs::murphyRes` 同口径）；**合成 REL ≤ 直接 REL ⇒ 不劣化**；劣化 ⇒ 按蓝图降级为只披露不采用。
- **功效义务**：**σ̂_d 与 MDE ≈ 2.8·σ̂_d/√n 必须与 Δ/CI 同报**（照厚格 §6 义务）。
- **单元与分母**：判读单元＝父题（60）；子题读数缺失 ⇒ 单元 `missing` 计入分母披露；`n_eff`＝有完整读数的单元数。
- **金样（identity）**：合成函数对「P(A)=P_direct、P(B)=1」退化输入须恒等（Δ≡0、σ̂_d=0、CI=[0,0]）——证「无差异时不出假差异」。
