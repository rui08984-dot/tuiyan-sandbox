# H·发散-收敛架构（H2 棒产出 · 预测卡 L0 线）

> 任务：把用户直觉「低温调最低当计算机器算数 + 高温调最高出结果 + 结合搞预测」转写为**可预注册、可证伪、不破铁律**的架构设计。
> 队长边界裁定三条（不可翻案）全文内嵌：**R-a** temperature=0≠算术正确，合法形态=LLM 生成确定性代码由执行器跑数、LLM 出逻辑不出数字、账本统计层零 LLM；**R-b** 高温输出=发散候选假设集非预测信号，须经低温评估通道（可判定性+证据锚定+概率量化）+resolve 记账，发散→收敛两阶段落 C 四角色「多路推理」内；**R-c** 玄学=对照臂非预测臂，作第 4 路进消融落库，角色=安慰剂/仪式噪声基线，永不进参谋卡、不上 UI 判断文案、恒挂娱乐参考。
> 上游锚定（只读）：D-裁决.md §4/§5、C-创新.md L0-L5 阶梯/方案3、B-泼冷水.md P6/F4/三道门、docs/sandbox/p2-yijing/oracle-experiment-result.md（45.1% vs 67.6%）、全文精读/J-预测系统精读.md（AIA supervisor/Platt/simplex）。
> 证据三态：【已核】=锚文件已核原文；【转述】=转引未亲核；【待验证】=存疑；【未验证猜想】=J ⑧节原始标注沿用。
> 写入规程：骨架先行、逐节 ≤3KB 填充+读回验证（前任 H 棒两回合落盘阶段环境中断零产出退役，本规程防崩）。

## 一、双通道+收敛层架构规格
**管线总览**：账本(SQLite 事件流) →〔低温〕特征压缩 →〔高温〕候选发散 →〔低温〕收敛评估 → 中位聚合 → verdicts 落卡 → resolve 记账 → ECE 仪表盘。

**低温通道（T≈0，职责=压缩与计算，禁出断语数字）**
- 全机械零 LLM 计算清单：①日死亡率/威胁暴露计数/矛盾信号数/资源状态等账本统计（SQL 直查，D §6.3「账本正确性依赖」）；②resolve 记账与 outcome 写入（true/false/ambiguous，歧义不硬判）；③Brier/ECE/Murphy 分解（方案5 仪表盘，D §5.2 纯统计零 LLM）；④多路中位聚合与 bootstrap CI。【已核】
- LLM 唯一参与形态=生成确定性聚合代码（SQL/JS）→ 执行器跑数（R-a；pitfall「LLM 出逻辑不出数字」）。论文级实证【已核，J ⑦a/表D】：LLM 直读判词出聚合数（Halawi 式）Brier 0.1168 反劣于机械均值 0.1140，top@3 仅 7.8%——「先机械平均再校准」是 AIA 全文最可抄结论。
- 产出=特征包（威胁暴露/矛盾对/欠定度/资源状态/历史基率），全部附 SQL 或事件 id，可审计。

**高温通道（T 0.7–1.0，职责=发散候选假设，非预测信号）**
- 输入=低温特征包+账本事件节选；输出=候选假设集（如「3 号与 4 号存在未申报联盟」），每条必须：带 top-3 账本事件 id（C 方案1「每条概率必须附 top-3 证据事件 id（可审计），禁止引用账本外直觉」【已核】）+ 一句可判定化改写建议；**不带概率数值**——出概率即越权进预测臂（R-b）。
- 3 prompt 变体×温度 0.7/1.0，与第十棒 3 路判词件同源复用，不新增 provider。

**收敛层（低温逐条评估→中位聚合）**
- 三道评估关（顺序执行，任一关不过即丢弃该候选）：①可判定性——能否改写为原子命题（C P1 三元组「带时间戳概率+判定标准+结局」）；②证据锚定——引用事件 id 逐条回查账本真实存在，锚定失败=丢弃；③概率量化——通过者由机械特征模型输出 P，LLM 全程不出数字。
- 聚合=机械中位（非 LLM 读判词）；多变体分歧度（极差/方差）随卡落库，供 supervisor 式「找分歧补证据」扩展（J ⑦b：仅 high 置信才改判，失败回退均值【已核】）。

**玄学第 4 路旁挂**：高温 LLM 从卦象生成断语→implied_prob，仅进 §三消融落库；不进收敛层、不进参谋卡、不上 UI（R-c，自查见 §五）。

## 二、LLM 算术可靠性消融设计（合成账本，可立即测）
**目的**：把 R-a（temperature=0≠算术正确）从裁决变成实测数据。项目内两次失败（梅花查狼 45.1% vs 基线 67.6%、H1 概率层）均死于「LLM 直接输出数字/断语」环节【已核，B §3.1】；机理【已核，pitfall 记忆】：算术错误在权重（前向传播）不在采样噪声，0 温只是**稳定地错同一个数**——低温兜不出正确算术，须实测给全队看。

**合成账本生成器（纯机械，可立即测）**：脚本生成 50 合成局×10 天×6 席位，事件流由带真值参数的生成器产出（日死亡率/威胁暴露/资源流转金标准已知），复用现有账本 schema，零新基建。

**任务集（≥100 题，三档预注册）**：
- A 简单计数：某席位威胁暴露次数（答案 0–15，SQL 一层）；
- B 条件聚合：「3 号在与 4 号同夜事件后的次日存活天数」（跨表 join）；
- C 复合统计：多条件聚合+比率，近似真实特征形态（如「狼阵营人均夜间事件密度 vs 全局基率」）。

**两臂**：臂1=LLM 直接回答（T0.2 与 T0.7 各跑一遍，测「稳定地错」形态）；臂2=LLM 生成 JS/SQL → 执行器跑数 → 返回数字。

**判据（预注册）**：
1. 臂2 三档正确率 ≥95% → 代码生成路径转正；
2. 臂1 任一档 <90% → R-a 从铁律升格为管线硬约束（接口层禁止 LLM 输出被解析为数值的字段）；
3. 臂1 ≥98% 且与臂2 差距 <1pp → 记录负结果（简单计数低温直读够用），但 C 档仍强制臂2——**错误率随聚合复杂度上升的曲线本身就是本消融的产出**。

**成本与 gate**：一天跑完，对齐 D §5.2「立即」档；判据 1 不达则 §一 低温通道的代码生成路径不开（gate 前置，防「流畅的错误数字」进生产管线）。

## 三、预注册消融矩阵（对齐 W2 verdicts 表）
**W2 verdicts 表字段对齐（任务书口径）**：pid / prompt_variant / temperature / verdict_text / implied_prob。六臂判词全量逐行落库（C 方案3「15 份判词全量落库，不只存聚合值」【已核】）。

| 臂 | 配置 | 角色 |
|---|---|---|
| A1 单路低温 | T0.2，机械特征直读（LLM 仅写 statement，P 由机械模型给） | 主对照 |
| A2 单路高温 | T1.0，直接出 implied_prob | 预期劣化，实测证「高温≠信号」（R-b） |
| B 发散-收敛 | 高温 3 变体发散候选→收敛层评估→机械量化→中位聚合 | 本架构主检验对象 |
| C 3 路温度变体 | T0.2/0.7/1.0 同 prompt 变体 | 第十棒 W2 原案 |
| D 基率-only | 纯历史基率零 LLM | 永久消融臂：防「判词=基率噪声版」（J ⑧5【未验证猜想】；Karger SOTA 0.109 不如直抄市场价 0.096【已核，J 表C】） |
| E 玄学对照臂 | 高温 LLM 卦象→断语→implied_prob | 安慰剂/仪式噪声基线，恒挂娱乐参考（R-c） |

**判据（预注册冻结后才看数据）**：n≥200 已 resolve 点；主判据 ΔBrier≥0.02（bootstrap 95%CI 不含 0，对齐 C 方案3/D §1【已核】）；判词间一致率 >80% 判伪独立（相关矩阵随手产出，C 方案3）；**任一科学路（A/B/C）赢不过 E 玄学臂 → 多样性增益=伪增益，砍回单路**（任务书原文）。

**F 清单挂账内嵌**（F-算法陷阱清单.md §8【已核】）：选样按 created_at 顺序取前 200，禁「好判手选」（挂账 #2 防事后选样泄漏）；多臂全检附 Šidák 校正或明示「探索性，不进结论」（挂账 #3 防多重比较）。

**E 臂附带检验（J ⑧1【未验证猜想】）**：simplex 回归 o~凸组合(A1,E)，系数=信息量代理，预期 E 系数≈0（先例：跑输共识的信息源仍可有正多样化增益，MarketLiquid 集成 0.106<市场 0.111【已核，J 表H】）；若 E 系数>0 → 仅作「低相关多样化源」观察项上报，**不进研判、不上 UI——铁律不因数据翻身**（J ⑧1 原文：翻身也守 UI 娱乐参考）。

## 四、失败长相+砍件条款
**低温通道 pre-mortem：代码生成静默 bug**——LLM 生成的 SQL/JS 逻辑错但可执行，产出「流畅的错误数字」；0 温下每次错得一样（稳定地错），无异常信号可警觉。防线：§二 合成账本金标准测试为代码生成路径的**常开 gate**；生成代码强制带自检断言（行数/非空/取值域）；执行结果与手写机械 SQL 双跑抽检。**砍件**：§二 判据 1 不达（任一档 <95%）→ 砍代码生成路径，账本统计回退纯手写 SQL——统计层零 LLM 本来就是铁律默认态，回退=回归默认，无沉没成本包袱。

**高温通道 pre-mortem：候选同质化+空泛化**——3 变体产出高度雷同（一致率 >80% 伪独立，F 陷阱三【已核】）或大量「有人很可疑」类不可判定断言，可判定通过率趋零，发散原料=0，收敛层无米下锅。防线：可判定性通过率/候选去重率/锚定失败率三指标入监测面板。**砍件**：可判定通过率 <50% 持续 20 局 → 发散通道降级为「复盘联想工具」，只进复盘层、与预测管线脱钩（降级非删除：发散文本仍可作娱乐参考存在）。

**收敛层 pre-mortem：0.5 卡死+过滤过度**——中位聚合在分歧大时卡 0.5 毫无分辨率（C 方案3 pre-mortem 原文【已核】）；评估关若把极端但有据的假设全滤掉，只剩基率 → Brier 好看而 resolution=0（B P6 校准≠分辨【已核】）。防线：resolution 分量与 Brier 强制并列展示（D §2 R2【已核】）；0.5 卡死率、高低置信桶实测频率差（L3 判据 ≥15pp，C §二【已核】）入监测。

**总砍件条款（预注册）**：B 臂 vs A1 臂 ΔBrier 增益 <0.01 → 多样性幻觉，砍发散-收敛层回单路（对齐 C 方案3「增量 <0.01 → 砍回 1 路」【已核】；本处省 3× 发散成本）；A2 臂劣化属预期不算失败，其数据点本身就是 R-b 的实证材料。**一切砍件结论=可发表结果而非失败**（D §1 方案3 同款措辞【已核】）。E 玄学臂不适用砍件——对照组不是功能件，砍掉它消融就失去安慰剂基线。

## 五、铁律对齐自查

|---|---|---|
| LLM 四角色（聚合/基率/多路/校准） | 低温=信息聚合（账本压缩+代码生成算数）；高温=多路推理（发散候选，R-b 明文归入此角色）；聚合=机械中位非 LLM 读判词（J 表D 实证 LLM 直聚合反劣化【已核】）；校准=ECE 仪表盘（方案5 纯统计零 LLM） | ✓ 无第五角色；玄学臂是安慰剂基线（被测对象）非新角色 |
| LLM 出逻辑不出数字 | 全管线数字仅两源：机械特征模型输出 P（收敛层量化关）、执行器跑代码结果（低温算数）；LLM 文本仅 statement/候选假设/代码（R-a） | ✓ §二 消融为此提供实测 gate |
| L0 门禁 | 一切评分在 n≥30 局∧200 条已 resolve 后，此前只落库不评（D §4【已核】）；等级不可跳，L1 前无「预测力」话术 | ✓ 消融判据自带 n≥200 前置 |
| ECE 小样本纪律 | 分层 n<30 显示「数据不足」而非曲线（D §1 方案5【已核】） | ✓ |

| 玄学娱乐参考 | E 臂恒挂「娱乐参考·非游戏研判」；永不进参谋卡/收敛层/UI 判断文案；数据层结合（落库消融）、研判层隔离（R-c）；45.1% vs 67.6%（oracle-experiment-result.md【已核】）是其对照臂资格的数据背书 | ✓ |
