> 产出：创新棒 C（认知探索小队），2026-09-09。方法：first-principles 与 brainstorming skill 已加载执行。
> 纪律：与 B 泼冷水棒独立作业（未读其产出，辩论留给裁判棒）；全部方案锚定真实家底，负结果家底（梅花查狼 45.1% vs 基线 67.6%、H1 概率层砍件）视同正向资产；LLM 角色只许四类：**信息聚合 / 基率检索 / 多路推理 / 校准辅助**。

## 一、first-principles：把「预测未来」剥成可工程命题

### 声称的约束（分类后处置）

| 声称约束 | 分类 | 处置 |
|---|---|---|
| 「预测=会算命，LLM 要么神要么骗」 | 类比 | 丢弃。预测的本体是可打分的数字，不是全知 |
| 「校准必须依赖外部基准/人类超预测员」 | 惯例 | 丢弃。deepwolf 的 calibrate 自对局对照真值即可出校准曲线（调研 §B2.3 第三范式） |
| 「概率更新要贝叶斯增量微调才高级」 | 惯例 | 丢弃。Metaculus 系主流是「到点全量重算+聚合」，工程便宜且天然防锚定（调研 §B2.2） |
| 「小样本下谈校准是玄学」 | 数学事实 | 保留。二项比例 n=30 时 95%CI 半宽约 0.18（p=0.5），能力宣称必须绑定样本量门槛 |

### 基本事实（primitives，均可独立支撑）

- **P1 预测的物理本体 = 三元组**：{带时间戳的概率值, 明确判定标准, 后续真实结局}。缺任何一项，「预测」退化为抒情——Metaculus 的题型系统 + resolution criteria 就是在工程化这个三元组（调研 §B2.1：每个预测必须是可判定真伪的原子命题）。
- **P2 质量可分解可测量**：Brier = 校准(reliability) − 分辨率(resolution) + 不确定度（Murphy 分解）。校准=「说 70% 的事七成发生」；分辨率=「发生的事给分高于不发生的」。两者可分别计算、分别改进、也分别作假——校准完美而分辨率零 = 全报基率，毫无信息量。
- **P3 「有预测力」是相对量**：必须回答「比谁好」。三类基线缺一不可——无信息基线（基率/0.5）、朴素持续模型（明天=今天）、现役对照（其他 LLM/人类玩家）。梅花查狼 45.1% vs 基线 67.6% 正是这个测法的负结果实例：**它证明了本项目的对照组方法论早在负结果里验证过一次**。
- **P4 LLM 的合法贡献只有四种实现**：①信息聚合（账本证据→特征→概率）②基率检索（类案先验）③多路独立推理（平均掉单路偏差）④校准辅助（历史 Brier 反馈修正过度自信）。任何宣称超出四种即水晶球，铁律直接禁。
- **P5 本项目独有资产是「可机检的过去」**：对局账本是结构化事件流，机械矛盾检测是实证存活路线（H1 概率层被砍反证机械路线正确）。预测管线不需要预言未来，只需要把「过去的账」映射成「未来的分」——这是与一切玄学路线的分水岭。

### 重建（rebuild）

预测能力 = 记账 → 校准 → 胜基线 → 有分辨率 → 多路增量 → 改善用户，六级阶梯，见第二节。

### 残余约束（binding_residuals）

短时窗事件基率常极端（Brier 被基率项主导）；LLM 多路判词同底座相关性高（「独立」多为回声）；真人实验受样本量上限约束。

### 最便宜证伪测试（kill_test）

每条方案的第一个实验都预装「若 Brier 增量 <0.02 即降级/砍件」条款——与 H1 砍法同构，砍自己不心疼才算可证伪。

## 二、演化阶梯：从「记 Brier 分」到「有预测力」

| 级 | 名称 | 做什么 | 可证伪通过判据（数字+样本量+对照） | 失败长相（pre-mortem 一行） |
|---|---|---|---|---|
| L0 | 记账 | 预测卡最小版：验证点+置信度+判定标准+到期事件落库，resolve 自动记账（照 fatebook/brierly） | n≥30 局 ∧ ≥200 条预测，100% 可 resolve；判定标准歧义争议率 <5% | 验证点写得主观（「危险」「可疑」）→ resolve 争议爆表，垃圾进垃圾出 |
| L1 | 校准 | reliability 曲线 + ECE（按验证点类型分层） | n≥200 时 ECE<0.10；不达 → UI 只许说「参考」，不许说「预测」 | 样本不足时校准曲线是噪声，画出虚假信心 |
| L2 | 胜基线 | 与无信息基线、朴素持续模型配对比 | n≥200，ΔBrier≥0.03 且跨两类局型方向一致 | 过拟合局型：换剧本塌回基线 |
| L3 | 分辨率 | 证明预测真的区分结局 | resolution>0 且高/低置信桶实测频率差 ≥15 个百分点 | 「全员 0.5 假校准」：Brier 不难看但零信息 |
| L4 | 多路增量 | 多路判词聚合 vs 最佳单路 | n≥200，聚合 Brier 比最佳单路低 ≥0.02（bootstrap 95%CI 不含 0） | 判词同源 → 15 路=1 路回声，成本×15 增益 0 |
| L5 | 人回路收益 | 预测反馈改善用户判断（Good Judgment 路线） | 随机对照：反馈组 vs 仅结果组，每组≥15 用户×10 局，ΔBrier≥0.05 | 用户防御性报 0.5，分数好看能力没涨 |

**与已排期对齐**：预测卡「n≥30 局∧200 条前只记不评」正是 L0 的门禁条款本身；L1 起才允许「评」。等级不可跳：没过 L1 的一切「预测力」话术违反「辅助研判非预言」铁律。

## 三、科研创新方案（5 条，各带锚定/LLM 角色/可证伪判据/数据需求/pre-mortem）

### 方案 1 对局内短时窗事件预测：「下一天谁最可能死」作为 Brier 练习场

- **锚定**：L1 账本（结构化事件流）×预测卡最小版——每天结账时自动从账本生成短时窗题（「X 明天死亡/存活」），自动落注、次日 resolve。这是调研五环管线（§0.1）在对局内的最小闭环，B6 一页现场流顺带获得「今日预测」栏目。
- **LLM 角色**：信息聚合。把截至当天的账本事件压缩为可机检特征（威胁暴露次数/矛盾信号数/资源状态），输出 P；每条概率必须附 top-3 证据事件 id（可审计），禁止引用账本外直觉。
- **可证伪判据**：n≥300 预测点（约 30 局×10 天×1 题）后三方对比：机械特征模型 vs 基率基线（全局日死亡率）vs 朴素持续模型（今日状态外推）。机械模型 ΔBrier≥0.05 且 resolution>0 才准宣称「预测」；不达 → 降级为「风险提示」娱乐参考文案。
- **数据需求/最低可行实验**：账本格式已有，零新基建；MVP=3 局×10 天×6 席位≈180 点，只跑管线不评分，先验证 resolve 判定标准零歧义再扩量。
- **pre-mortem**：日死亡率若低于 10%，Brier 总分被基率项淹没——必须报分辨率分量，否则会把「基率准」误读成「模型准」。

### 方案 2 deepwolf 嫁接：机械矛盾信号作 belief model 的似然项

- **锚定**：调研确认 deepwolf（MIT）透明 belief model+自对局校准与参谋卡几乎同构（§C2）；本项目机械矛盾检测是实证存活的正资产。嫁接：矛盾检测输出（矛盾对/欠定度）作为每个存活玩家 P(狼) 的似然更新项——每处矛盾触发一次**有界步长**的贝叶斯更新（上限防过冲），更新前后差值显示在参谋卡双栏：左=程序化概率栏，右=LLM 第二意见栏（照调研 Top5 #2 的分离显示，两栏永不混合）。
- **LLM 角色**：基率检索。只回答「该类矛盾在同类局型的历史出现频率与含义」（类案先验），数值更新全部由公式完成——这是 deepwolf「LLM 仅作第二意见」纪律的严格继承。
- **可证伪判据**：n≥30 带真值标签历史局： belief 栏对真狼 AUC ≥ 纯机械计数基线 +0.05； LLM 直觉整卡打分作第三对照； 若不赢 → 复用 H1 砍法直接砍，只保留双栏展示不承诺推断力。
- **数据需求/最低可行实验**：需带真值的历史局 ≥30；MVP=用 80/80 测试绿的账本回放 5 局，先验证更新有界不发散（P(狼) 不因矛盾刷屏冲到 0.99）。
- **pre-mortem**：混淆变量——「话多者矛盾多」，沉默狼永远低 P；失败长相=AUC 涨但真狼低分漏检率同步涨，两个指标必须一起看。

### 方案 3 多路判词聚合的增量消融：多样性到底是真是假

- **锚定**：已排期「多路判词基线件」（照抄 BLF 3×5、跨 provider≥2、单卡≤5min）——本方案把它从「功能」升级为「实验装置」：15 份判词全量落库（不只存聚合值），消融在库上离线跑。
- **LLM 角色**：多路推理（并诚实研究其独立性）。消融主变量预注册：provider 多样性 / 温度多样性 / prompt 措辞多样性，各自单独测增量——调研 §B2.4 指出对冲靠「独立视角的多样性」而非更聪明的大脑，但同底座判词可能只是回声。
- **可证伪判据**：n≥200 已 resolve 验证点： 跨 provider 15 路中位聚合 vs 最佳单路 ΔBrier≥0.02（bootstrap 95%CI 不含 0）； 判词间一致率 >80% 判「伪独立」； 增量 <0.01 → 结论=多样性幻觉，砍回 1 路省 15× 成本（可证伪的成本结论，不是失败）。
- **数据需求/最低可行实验**：仅判词件+20 个已 resolve 验证点，一天跑完；判词相关矩阵顺手产出（L4 等级的必备品）。
- **pre-mortem**：中位聚合在分歧大时卡 0.5 毫无分辨率；另一失败长相=所有 provider 同源训练数据 → 判词相关 ρ>0.8，聚合等于给同一个错误上了 15 份保险。

### 方案 4 预测卡 → 用户判断力训练器（Good Judgment 路线）

- **锚定**：参谋卡三件套（双栏对峙+验证点 checklist+欠定度色标）×预测卡记账。嫁接流程：用户看双栏后先自报 P → 再展开机械信号与判词参考 → resolve 后回放个人 Brier 曲线+按线索类型的归因（「你在动机类验证点系统性过度自信」）。fatebook 的校准视图（调研 §B1）是现成 UI 范式。
- **LLM 角色**：校准辅助。只做两件事：①把用户口语判断转成可记账数值（「大概率」=0.7 还是 0.9，澄清后落库）；②resolve 后用账本证据解释偏差来源（归因，不是训话）。不生成预测。
- **可证伪判据**：随机对照两臂：A=看个人 Brier 曲线+归因反馈，B=只看 resolve 结果。每组≥15 用户×10 局，A 组后 5 局 Brier 比 B 组低 ≥0.05 且 A 组改善来自校准（非仅分辨率运气）。不达 → 训练器降级为复盘玩具。
- **数据需求/最低可行实验**：真人门槛高，先 N=1 自我实验（队员玩 10 局）验证反馈界面不误导，再谈 RCT。
- **pre-mortem**：Brier 是严格正则评分规则，无信息者诚实报 0.5 期望最优 → 只晒 Brier 总分会诱导「全员 0.5 假校准」；必须同时展示分辨率分量，把「敢给极端且对」与「躺 0.5」区分开。

### 方案 5 跨局校准仪表盘：把「只记不评」沉默期变成预注册实验

- **锚定**：预测卡排期原文「n≥30 局∧200 条前只记不评」——沉默期数据不是闲置，直接喂仪表盘（ECE+分桶曲线+按验证点类型分层），沉默期结束时第一份报告就是预注册检验。
- **预注册预测（可打脸）**：机械事件类验证点（死亡/投票结果）的 ECE 优于动机推断类（「他怀疑 X」类）≥10 个百分点——这条预测本身可被数据证伪，是仪表盘交付时自带的第一个实验。
- **LLM 角色**：无。纯统计件，故意零 LLM——作为其余四条方案的天然对照组，证明它们的增量不是工程噪声。
- **判据**：200 条时 ECE 可算且 <0.15；分层后每层 n<30 显示「数据不足」而非曲线（防噪声自信）。
- **pre-mortem**：分层切片样本不足 → 每层曲线纯噪声，仪表盘从「诚实工具」变成「虚假信心生成器」——所以分层判据必须预注册，宁缺毋滥。

## 四、诚实点名死路（不碰，各一句为什么）

1. **玄学/水晶球接入研判**：梅花查狼 45.1% vs 基线 67.6% 已用真数据证伪「玄学>随机」，再接=无视自家负结果资产；只许挂娱乐参考标签存在。
2. **LLM 无对照自评「我很准」**：没有基线与记账的自我评分不可证伪，等于让模型给自己发奖状；一切准确率宣称必须带对照组与样本量。
3. **长时程剧情结局预测当能力卖点**：一局一个结局，样本量数学上收敛不了校准（L1 永远过不了），只能是娱乐参考——这是「辅助研判非预言」铁律的统计版。
4. **用预测准确率给用户贴「高手/可信」标签**：n<100 的个体校准全是噪声，制造虚假高手幻觉，且与「参谋卡恒挂思路非答案」直接冲突。
5. **无真值标签的 belief model 调参**：没有 resolve 后真值，任何权重调整都在拟合噪声——deepwolf 的价值恰在 calibrate 闭环，砍掉闭环只抄模型是买椟还珠。
