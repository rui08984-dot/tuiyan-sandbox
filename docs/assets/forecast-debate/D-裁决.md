## 0. 总判决一句话

**「预测未来」作为产品叙事死亡，作为工程问题拆解为：③结构性推断（已实证存活，继续投入）+ ②限定域窗的短窗校准（窄活路，须过三道门+L0-L5 阶梯）。C 的 5 方案全部免于水晶球污染（LLM 角色全在合法四类内），3 条过门、1 条过门需修订、1 条降级缓行。**

## 2. 修订条款（两条）

**R1（方案 1 披露层修订）**：B 的 F4 自反性在对局内的形态——玩家看到「3号 P(死)=0.7」会改变玩法，预测进入因果环。修订：预测结果**默认只进账本（复盘层），不进现场页实时展示**；若未来上现场页，必须把「预测影响行为」本身列为观察项并预注册。C 的降级条款（不达→「风险提示」）保留。

**R2（方案 4 判据修订）**：15人×10局 RCT 检验力不足（B 的样本量口径胜）。修订为三级阶梯：N=1 队员自实验（验证界面不误导，零成本）→ 组内跨局 A/B 对照（同一用户两种反馈模式的局型交叉）→ 达标后再谈组间 RCT（每组 ≥30）。且必须同晒 Brier 分辨率分量（C 的 pre-mortem 已自装，防「全员 0.5 假校准」）。

## 3. 分歧裁决（B/C 冲突三处）

**D-1 样本量口径（C 方案1 n≥300 vs B「探索性样本不下结论」）**：兼容，非真冲突。C 的 n≥300 是预注册**判据**（何时允许说什么话），B 反对的是拿探索性样本**宣称结论**——两者共同要求=UI 在 n<300 前止步「风险提示」。判：C 条款成立，补 B 的 UI 文案约束。

**D-2 多路独立性（A 数据 0.122≈0.121 vs C 方案3 乐观）**：A 的 ForecastBench 数据说明同水平 LLM 互聚合的先验不乐观，但 provider 家族异质（不同训练谱系）≠同底座回声；86% 冠军 bot 集成率=实战正例。**裁决：两证据不矛盾——它们共同指向「先跑消融实验回答而非站队」**，方案 3 的预注册消融正是回答装置（C 判据原样），加速执行。

**D-3 训练器价值（C 方案4 RCT vs B 功效质疑）**：B 胜。R2 三级阶梯采纳；且训练器价值依赖 L1-L3 先过（用户得先有可信的记账与校准曲线可看），排序自然靠后。

## 5. 给发起人的最终建议（≤1 页）

### 5.1 改名（候选 3 个，按推荐序）

1. **「校准练兵场」**——方案 1（短时窗事件预测）的产品名：强调练的是用户的判断校准，不是机器预言。
2. **「假设空间压缩器」**——③（账本+矛盾检测+参谋卡）的正式叙事名：不预测未来，排除不可能。
3. **「限定域窗的短窗校准器」**——②若回归时的主张文本格式（域/窗/基线/公开性四要素强制内嵌）。

整体叙事从「预测未来」改为：**「从复盘工具到校准工具」**——B 的四条建议第 1 条采纳，水晶球叙事全线下架。

### 5.3 死路清单（合并 B/C，无异议，全线下架）

1. 玄学/水晶球接入研判（自家实验 45.1%<67.6% 已证伪）——玄学只许娱乐参考存在（排盘正经化线已按此边界施工中）。
2. LLM 无对照自评「我很准」（不可证伪=自发奖状）。
3. 长时程剧情结局预测当能力卖点（一局一结局，校准数学上收敛不了）。
4. 用预测准确率给用户贴「高手」标签（n<100 纯噪声+违反思路非答案）。
5. 无真值标签调 belief 权重（拟合噪声；deepwolf 价值在 calibrate 闭环）。
6. 「通用预测未来」主张（B §1.2 四重硬边界+项目内两组负结果同构）。

## 6. 残余风险（裁决后仍存在）

1. 视界内不可消除的不确定性——②类系统做出来也只是「比基率好一点」，永远不 magical。
2. 部署后漂移（Finlayson 2021）——校准系统上线后会静默劣化，监测成本常被低估；仪表盘恰好是监测件，绑定做。
3. 账本正确性依赖——③的全部价值建立在账本干净上；录入侧垃圾进垃圾出的问题（DEF 挂账、确认流护栏）必须持续投入。
4. ForecastBench 追赶斜率真实存在——T1 观察窗不是摆设，若 2026 年 SF 平价达成，②类预算应重开（B 也承认这是它判决的活风险）。
