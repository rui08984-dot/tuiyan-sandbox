## 一 · Q1：ForecastBench 现状（2025-11 → 2026-09）

1. 【已核】**官网本轮实测可直抓**（A 棒未测此域，I 棒补测 200 OK）：现为**三榜单制**——
   - **Tournament leaderboard**：前沿赛道，开放外部提交，允许工具/微调/集成等一切增强；官方代跑的模型在市场题上会拿到 crowd forecast 作上下文。
   - **Baseline leaderboard**：官方独跑，裸模型无工具无脚手架，追踪「原始 LLM 预测力」进展。
   - **Preliminary leaderboard**：全部已结算数据集题的早期结果（约提交后 ~10 天），正式排名以 Tournament 为准。
   - 计分：难度调整 Brier（双向固定效应分离预测者能力与题目难度）→ **Brier Index**（BI=100×(1−√mean BS)，0-100 可解释刻度：100=全对，50=等价「永远 0.5」，0=全错；Higher better）。
   - URL: https://www.forecastbench.org/leaderboards/

## 三 · Q3：T1 字面判定证据（2025-11 → 2026-09）

> T1 五要件拆解（B-泼冷水 §1.1 原文）：①免泄漏多域混合可解析题集 ②某 LLM 系统（含工具+集成）③连续 ≥2 个评测周期 ④Brier 稳定优于专家预测者中位数 ⑤优势跨 ≥3 个不相关域。

1. 【已核】**要件①成立且在扩展**：ForecastBench 题源持续多元化（Kalshi 加入、RAND 退出，§一.3）；另有 **ForecastBench-Sim**（arXiv:2606.18686，2026-06-17）：Freeciv 回合制策略游戏 rollout 上的模拟世界基准，任意时距/反事实/稀有结局可即时结算，含匿名人类 pilot；ICML 2026「Forecasting as a New Frontier of Intelligence」workshop spotlight。→ 免泄漏多域题集不是瓶颈。
   URL: https://arxiv.org/abs/2606.18686
2. 【已核】**要件②候选=BLF（2026-04，v4）**：「Bayesian Linguistic Forecaster」——agentic 系统，三组件：语言信念状态（概率+证据摘要半结构化迭代更新）、层级多试验聚合（K 独立试验 logit 空间平均+数据依赖先验收缩）、层级 Platt 校准（带先验防偏态基率源极端预测被过度收缩）。自述 **"achieves state-of-the-art performance on the ForecastBench benchmark"**：400 题 backtesting（自建框架，leakage<1.5%），Overall/Market/Dataset 三类 BI 全部第一，胜当前榜单头部公开方法（Cassi、Grok 4.20、Foresight-32B、GPT-5/Gemini-3.1-Pro 零样本）；还是唯一显著胜过「LLM-free crowd 先验基线」的方法。
   URL: https://arxiv.org/abs/2604.18576 （v4）
3. 【已核】**要件④关键数字（本复测件核心）**：BLF 全文原话——"BLF is the only one of these methods whose difficulty-adjusted Brier Index (ABI=71.0) is **close to** the human superforecaster median (**ABI=70.9**) reported on the ForecastBench leaderboard"，脚注自注："The two numbers are computed on **different question sets and time periods**, so they are **not strictly comparable**"。→ 最强系统是「**接近** SF 中位」且作者自认不可严格比较；**无任何系统声称稳定优于专家中位数**。AIA 措辞为 equal to（平价），亦非优于。
4. 【已核】**反向缩放证据（跨域稳定性的结构性反例方向）**：arXiv:2605.22672（2026-05-21 v2）《Is Capability a Liability?》——在超线性增长+变域尾部风险的任务结构（金融/流行病常见）上**更强模型分布预测更差**（inverse scaling）；FBSim 合成 SIR+COVID/麻疹/房市/恶性通胀真实数据复现；失败集中于上尾；**单阈值记分测不出该效应**，建议评测加连续（无界）记分。
   URL: https://arxiv.org/abs/2605.22672
5. **要件③「连续 ≥2 评测周期」：全空缺**【已核·缺失性证据】——
   - AIA 无第二周期数据（§二.5）；BLF 用自建 400 题 backtesting，非官方多周期计分；
   - 官网榜单 2025-10 起三次口径变更（难度调整 Brier→Brier Index、题集 1000→500、收录门槛 50 题），**「同一口径下的相邻两周期」本身难以定义**，50 天收录延迟+每轮限 3 提交进一步切分周期；
   - 未检索到任何「某系统连续两轮榜首/两轮超 SF 中位」的公开陈述。
6. **要件⑤「优势跨 ≥3 不相关域」：无证据**【已核·缺失性证据】——BLF 报 Overall/Market/Dataset 三大类全胜，但这是题源二分（数据集题 vs 市场题）不是「不相关域」分解；未检索到任何系统做域级稳定性声明；2605.22672 的 inverse scaling 直接指向「跨域稳定优势」存在结构性反例方向。
7. 【本节判定】2025-11→2026-09：**平价线（ABI≈70.9）已被两只系统摸到（AIA 自报、BLF 接近）**，但「稳定优于×连续≥2 周期×跨≥3 域」三要件全部无公开证据。检索遗漏风险见 §二.6。

## 四 · Q4：统计校准新方法（2025-2026）→ 对「对局账本+多路判词」可用性

> 每项：一句原理 + 本项目可用性判定。铁律对齐：LLM 只出逻辑/概率，后处理全在确定性代码层。

1. 【已核】**BLF 三件套**（arXiv:2604.18576v4，2026-04）——当前 ForecastBench SOTA 的配方，逐件映射本项目：
   - **语言信念状态**：数值概率+自然语言证据摘要的半结构化状态，每步工具环迭代更新，不堆 context → 账本=现成的结构化 belief state，天然适配，无需新机制。
   - **层级多试验聚合**：K 次独立试验在 logit 空间平均+数据依赖先验收缩 → 3 路判词（T0.2/0.7/1.0）聚合可由简单均值升级为 logit 平均+收缩；温度档=天然试验多样性。
   - **层级 Platt 校准**：带层级先验的 Platt scaling，防偏态基率源把极端预测过度收缩 → W2 校准 API（现 isotonic/Platt 单层）的升级路径：按判词路/题型分层拟合。
   - 附：消融（混合效应控制题目变异，题目变异占性能方差 62%）显示三组件贡献随基座 LLM 与有无 crowd prior 变化——**「哪件最重要」不可照搬，须自带消融**。
2. 【已核】**难度调整 Brier + Brier Index**（官网/leaderboards 与 BLF 论文；提出者 Kučinskas et al. 2026【转述：FRI substack 2026-03-11 文，直抓 fetch failed】）：BI=100×(1−√mean BS) → 项目记账建议改记 BI（直觉化+跨期可比）；「难度调整」需双向固定效应（样本大），L0 小样本阶段标**观察项非待办**。
3. 【已核】**CPTC：变点感知在线 conformal**（arXiv:2509.02844）：预测底层状态切换+在线 conformal，非平稳时序覆盖保证，6 数据集验证 → 账本=强非平稳短窗流；形态是「区间参考带」而非点值，恰好贴「一切数字只配参考」纪律；但需校准样本，**属门后件**——L0 阶段先把原始概率+区间记全（数据免费，日后可回放）。
   URL: https://arxiv.org/abs/2509.02844
4. 【已核】**RCCP：检索校正 conformal**（arXiv:2608.10553，2026-08）：检索相似历史残差作局部证据+标量 conformal 修正检索误差，覆盖达标且 Winkler 分最低、开销低 → 账本可直接复用（「检索过去同构对局的残差」），门后件。
   URL: https://arxiv.org/abs/2608.10553
5. 【转述】**conformal 其他 2025-2026 变体**（搜索引擎引文口径，摘要未实抓）：RareCP（arXiv:2605.08857，regime 感知检索提效）；JANET（Springer Machine Learning 2025-06，交换性失效时序的自适应区间）；Neural Conformal Control（AAAI 2025，非平稳环境自适应覆盖）；SPACE（arXiv:2608.17333，多变量样本云椭球）→ 主线一致：**在线化/非平稳化/检索化**，方向性登记即可。

6. 【转述】**聚合方法稳定性新证据**：König-Kersting et al. 2026（Innsbruck WP 2026-05）：516 种聚合算法 many-designs 研究——「哪种聚合最优」跨题集**本身不可预测**；Cooke 2026《Wisdom/Madness of Crowds and Perils of Point Forecasts》（INFORMS Decision Analysis）：聚合方法选择是最重要因子、点预报危险（PDF 未抓，引文口径）→ **项目含义：聚合函数不锁死**——记账存各路原始概率，聚合器可插拔+离线回放比较（中位/均值/logit/extremize 幅度都留档），与 GJP 旧知「extremize 幅度取决于池多样性」合并执行。
7. 【已核】**DINCO：verbalized confidence 重校准**（arXiv:2509.25532）：LLM 言语置信过自信的根源=对低信息断言的高可暗示性（实验证实）；方法=让模型对多个**自生成干扰断言**独立报价→按总置信归一化+generator-validator 分歧校正 → **项目含义：3 路判词若带自报置信，不可直接采信**，须经此类归一化后处理（确定性代码层）；「多路互相印证/互相打脸」结构=DINCO 的 coherence 思想，可低成本借入。
   URL: https://arxiv.org/abs/2509.25532
8. 【已核】**反向缩放的记分教训**（arXiv:2605.22672，§三.4 已引）：单阈值记分漏上尾成本，建议连续（无界）记分并列 → 狼人杀「谁是狼」是二值判定无上尾问题，**但若扩「胜率分布」类输出必须警惕**；记账保留连续成分（BI 即连续变换，顺带解决）。
9. 【转述·降权】**Victor Calibration**（arXiv:2512.17956）：多遍证据重评提炼标量置信+圆桌编排+治理压测——探索性案例+邀请复现，仅作方向登记，不作依据。

## 五 · T1 判定（三态定版）与②类预算含义

### 5.1 判定：**未触发**（逼近中；逼近度较 2025-11 复测点上升）

四条硬依据：
1. **「稳定优于专家预测者中位数」无人达成**【已核】：2026-04 最强系统 BLF 的难度调整 ABI=71.0 vs 人类 SF 中位 70.9——是「接近」且作者自注"不同题集与时段，不严格可比"；AIA（2025-11）措辞为 equal to（平价）。没有任何系统声称优于，更无第三方证实。
2. **「连续 ≥2 评测周期」双周期数据全空缺**【已核·缺失】：AIA 无第二周期、BLF 用自建 backtesting 非官方多周期、无任何复现；且榜单口径 2025-10 起三变（难度调整 Brier→Brier Index、题集 1000→500、收录门槛 50 题），同口径双周期目前难以定义——T1 判定技术上**尚无可判材料**。
3. **「优势跨 ≥3 不相关域」无域级证据，且有结构性反例方向**【已核】：BLF 的三类全胜是题源二分非域分解；2605.22672 证明更强模型在超线性增长+尾部风险域反而更差（inverse scaling）——「跨域稳定优势」当前存在已知反例方向。
4. **官网默认叙事仍是「平价=线性外推事件」**【已核】：/explore/ 平价图是 Projection 不是 Achievement；官网明示外推可能偏离线性。
   （逼近度上升的正面证据：追赶斜率实锤——2025-07 显著弱于 → 2025-11 平价 → 2026-04 ABI 71.0 贴 70.9；题源扩展、题集方法学持续强化。）

### 5.2 对②类预算的含义

- **不重开、不冻结**：维持队长速记初判与 D-裁决 §5.2 顺序——消融→仪表盘→短窗 MVP→deepwolf 嫁接，照常推进；T1 重开条件继续挂起。
- **Q4 方法即刻可喂的两件**：①3 路判词聚合升级=logit 空间平均+先验收缩（BLF）；②校准 API 升级=层级 Platt（按判词路/题型分层）。两者都落在「LLM 四角色」合法集合内（聚合/校准）。
- **记账口径建议**：Brier 改记 Brier Index（BI=100×(1−√mean BS)，0.5 基线=50 分），连续可变换、跨期可比、直觉化；难度调整（双向固定效应）留观察项。
- **铁律复审视记**：本复测无 T1/T4 级新证据 → 四条红线照旧（玄学娱乐参考/禁预测字样/L0 门禁/LLM 四角色）；AIA 与 BLF 的全部组件恰好都在「聚合+多路+校准」集合内，SOTA 形态再次验证四角色不是天花板而是路径图。
