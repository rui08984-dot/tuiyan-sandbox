## §2 臂机制（读 `thickcell-replay.cjs` 实码）

臂签名统一为 `(ctx, q) → p`。臂能拿到的全部数据（`buildPool` + `attachFeatures`）：

| 字段 | 含义 |
|---|---|
| `q.y` | 该题结果 0/1 |
| `q.base` | 引擎给的基线概率 |
| `q.layer` / `q.domain` / `q.id` / `resolved_at` / `created_at` | — |
| `q.kind` / `q.fam` / `q.lat` / `q.lon` / `q.month` | 由 `attachFeatures` 从 `evidence_json` 装配 |
| `ctx.history` | **已结算**题的上述字段（`resolved_at < q.resolved_at`）|

★**注意 `ctx.history` 里只有 `y`（0/1 结果）与基线，**没有序列数值**。

## §3 ★阻塞一：账本不存序列值（与 Granger H11 同根）

nowcast 的先验要求「**该序列**历史季节性均值」⇒ 必须有序列值。实测：

| 探针 | 实测 |
|---|---|
| `evidence_json LIKE '%reference_tail%'` | **1 / 1994 行**（仅 id=452，3 个月的 `{"2026-06":1.1518,…}`）|
| `evidence.baseRate` 的内容 | `{"p":0.45,"n":331,"k":149,"kind":"empirical",…}`＝**经验频率**，**不是序列值** |
| `baseRateNote` | 自然语言摘要（如「近 350 个发布日…汇率 ≥ 7.1076 占 40.0%」）——含窗口与频率，**不含逐期数值** |

⇒ **「历史季节性均值」在现账本上不可计算**。这不是取数没做，是**写端从未落序列值**。

★**同根先例**：Granger 滞后臂 2026-09-20 以 **H11**（长滞后序列不可得）封存，
`thickcell-replay.cjs:71` 原文：「实现前提不成立：账本不存序列值（v1.1 §2；须先定『联网重取数／封存』路径）」。
⇒ **nowcast 撞上的是同一堵墙**，只是当时未测（v1 §9④ 只测了 P2 覆盖率，没测先验可得性）。

## §5 为什么**不**先做一个「能跑」的臂

三条纪律同时指向「不」：

1. **铁律⑥ PREREG 冻结禁改**：臂的构造（季节性先验＋桥接证据行）已冻结。
   用 `baseRate` 的经验频率冒充「季节性均值」＝**换判据还叫原名**——与 E1/E2 两条已结案负结果
   （H10 DNA 线终止／路由线全灭）同一形状。
2. **禁编数**：P2 人口为 0 时产出任何臂读数，都只能是无法判读的数字，**却会被下游当读数消费**。
3. **kNN 先例是正面参照**：`makeKnnArm` 的无历史分支是 `return q.base;`（**退基率、不猜**），
   且 `DECLARED_ARMS.knn.impl` 只在**参数已预注册（v1.2）**后才赋值。
   ⇒ nowcast 的参数（先验构造/桥接规则）**尚未预注册**，赋值时机未到。
