## 1. 切片设计与屏蔽纪律（预注册，点火后不可变）

1. **逐日切片**沿用模板 v1.2：每个切片派全新无上下文子代理，实验轨/基线轨各一。
2. **头部屏蔽（重要）**：给切片 AI 的档案内容从正文第一个「## 夜/昼」节开始，**裁掉档案标题行+头部元信息块**（含对局名、结果行、完整度声明）。理由：① botc 范本头部无结果行，两局头部「结果：狼人获胜」属终局泄露且会进入每一切片；② Lyingman 标题含「JY封神之路」、Pandakill 来源含「阴阳倒钩」——探针已证模型对这两个叙事标签有背景知识（轻度污染源），屏蔽后盲测更纯。档案文件本身不改，屏蔽在组装切片时执行。
3. 切片数：Lyingman=3（昼1/昼2/昼3）、Pandakill=2（警上放逐日/收割日，按档案章节切，等质检确认 E-编号分段后定案）。合计 5 切片 × 2 轨 = 10 次研判。
4. **双轨同日跑**（防模型路由漂移）；子代理并行上限 3，防运行时强杀。
5. 输出原样存 runs/{lyingman-s02e01|pandakill-s1e7}/day{D}-{exp|base}.md，**完整输出必须落盘**（P0 昼1 捕获缺陷教训），且前台长跑压缩输出重试方案备用。

## 2. 命中计分（每切片 0–2 分）

- 实验轨取其「嫌疑排序 Top-2」；基线轨取其 Top-2。
- Top-2 中每含 1 名真狼记 1 分（连续计分：0 / 0.5 / 1 / 1.5 / 2——0.5 用于列名正确但席位错误或反之，需评分时注明理由；默认按席位计）。
- 白狼王（Pandakill 6号）计入真狼（它是狼阵营）。
- **主考点附加位**（不影响 H1 主判定，单独记录）：实验轨矛盾清单或假设是否独立点名主考点（Lyingman 6号 JY / Pandakill 8号 JY）及其依据事件。
- 引用真实性抽查：每实验轨切片随机抽 5 条事件引用核对公开层，虚构引用 ≥1 条 → 该切片实验轨计 0 分并记录（防"幻觉镀金"刷分）。

## 3. H1 终判口径（预注册）

- 局级命中率 = 该局全部切片命中分之和 ÷ 切片数（实验轨、基线轨分开算）。
- 总命中率 = 两局切片合并计算。
- **H1 通过**：实验轨总命中率 − 基线轨总命中率 ≥ 0.5（10 切片尺度上＝实验轨多命中 ≥5 个狼位；P0 全脱靶基线下，此阈值代表"明显有感的信息增量"，避免 n=2 噪声误判）。
- **H1 不过但确定层达标**（审查 R1 三档之二）：实验轨矛盾清单经抽查有效率高 ≥80% 且基线轨无此产出 → 砍概率层保留账本+矛盾检测，产品=复盘工具。
- **杀项目**：确定层有效矛盾也产不出（抽查有效率 <50%）。
- 预期管理（预注册）：两局材料完整度 85%/70%+私密信息不可见 → 命中率天花板客观存在；本复测回答的是「结构化账本研判是否优于裸聊」，不是「AI 能否破案」。
- 叙事污染口径：Lyingman 局押 6号 JY 仅在依据引用公开查杀（E-3）等真实事件时计分；无引用的叙事直觉不得分。
- 模型侧：全部切片用当前默认路由模型（与探针同模型），模型身份记入评分表。

4. 队长按本协议评分填 score-lyingman-s02e01.md / score-pandakill-s1e7.md。
5. H1 终判 → 三档结局 → 更新设计文档 §9.4 与 gate 表。
