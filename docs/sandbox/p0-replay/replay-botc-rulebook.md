# replay-botc-rulebook ｜ 公开信息流（盲测 AI 可读）

对局：Blood on the Clocktower 官方规则书示例局（Trouble Brewing 剧本，11 人：3 邪恶 / 8 善良——此为公开常识）
说明：本文件只含"牌桌上所有玩家都能知道"的公开信息。事件编号 E-1 起。玩家名单（11人）：Amy, Alex, Abdallah, Benjamin, Douglas, Evin, Julian, Lachlan, Lewis, Marianna, Sarah。

## 昼 1（第一次讨论与处决）
- E-1: Marianna 公开宣称身份=Investigator（调查员），并公布其信息："Abdallah 或 Sarah 中有一人是邪恶爪牙——具体是 Scarlet Woman（绯红女人）"。
- E-2: Abdallah 公开宣称身份=Saint（圣徒），警告"处决我则全体输"，指认 Sarah 为邪恶。
- E-3: Sarah 公开宣称身份=Fortune Teller（占卜师），自称好人，指认 Abdallah 邪恶，呼吁留她活命以持续提供信息。
- E-4: Alex 公开宣称身份=Empath（共情者），称"我的两位邻居一邪一善：要么 Julian 邪恶，要么 Sarah 邪恶"。
- E-5: Lewis 与 Evin 全程沉默，未宣称身份。
- E-6: Douglas 公开宣称身份=Chef（厨师），称"有两名邪恶玩家相邻"，给出候选对：Marianna+Julian，或 Alex+Sarah，或 Sarah+Lachlan；表态倾向处决 Sarah。
- E-7: 群体投票决定处决 Sarah；Sarah 被处决并死亡。说书人公布：Sarah 不是恶魔（因恶魔仍存活，游戏继续）。
- E-8: Amy、Benjamin、Lachlan 在昼 1 无公开发言与身份宣称记录。

## 昼 2
- E-9: 说书人公布：Douglas 于夜间死亡。
- E-10: Julian 公开宣称身份=Undertaker（送葬者），公布其信息："Sarah 是 Drunk（醉汉）——一个自以为是重要角色的好人"。并推论："Sarah 是好人，所以 Abdallah 或 Marianna 之中有一人在撒谎。"
- E-11: Lachlan 公开附和 Julian 的信息（"被投毒的送葬者的假消息帮邪恶扳回一城"为 Lachlan 内心独白，未公开；其公开行为=附和并推动 Amy 公开身份："Amy，把Earlier私下告诉我的告诉大家，你是强力角色，对我们好人很有用"）。
- E-12: Amy 公开宣称身份=Slayer（杀手）："若猜中恶魔可立即将其杀死，仅一次机会。"
- E-13: Benjamin 公开宣称身份=Washerwoman（洗衣妇），称"我知道 Lewis 是 Soldier"。
- E-14: Lewis 公开宣称身份=Soldier（士兵），解释此前沉默是想吸引恶魔攻击自己。
- E-15: Evin 公开宣称身份=Monk（僧侣），宣称昨夜保护了 Julian。
- E-16: Amy 行使 Slayer 技能，指认 Abdallah 为恶魔；说书人公布：未命中（"Slayer 今天没有找到目标"）。Evin 据此总结："要么 Abdallah 是好人，要么 Amy 在撒谎。"
