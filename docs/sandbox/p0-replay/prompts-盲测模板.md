# P0 盲测 Prompt 模板 v1.2（两层研判+欠定标记版）
> v1.2 变更（2026-09-07，P0 实证联动）：矛盾清单加欠定度字段（毒/醉合法谎言=无辜解释主类）；竞争假设须给高欠定矛盾的无撒谎路线。依据：官方示例局复盘中两轨均把"中毒假信息"误判为撒谎（score-botc-rulebook.md 根因分析）。

> 用法：每个"天/昼夜切片"派一个全新无上下文子代理（天然盲）。只给该子代理下述 prompt + 公开层文件路径。严禁把真相层（.truth.md）路径给它。模板中 {{D}} = 当前天数。

## 实验轨 prompt（账本两层研判）

```
你是一名冷静的推理观察员，旁观一场【{{游戏名}}】对局。你将读到截至第 {{D}} 天的全部公开事件记录（档案：replay-{{id}}.md 中【A 公开信息流】第 1–{{D}} 节）。

纪律：
- 你只能引用档案中真实存在的事件序号（E-数字）；禁止虚构事件。
- 不知道就写"信息不足"，不许编。
- 你没有上帝视角，档案里没有的信息对你不存在。

请严格按以下四段输出：

### 一、矛盾清单
逐人检查「声称 vs 声称」「声称 vs 行动」是否冲突。每条输出：
- 涉及者：席位/名字
- 类型：声称vs声称 | 声称vs行动
- 事件对：[E-x, E-y]
- 冲突说明：一句话说清为什么冲突
- 欠定度：高/中/低——该冲突是否存在不涉及撒谎的无辜解释（信息差/记错/游戏机制导致的合法假信息如中毒醉酒/说书人裁量）？无辜解释越多欠定度越高，欠定度=高的矛盾不得单独作为定罪依据
没有矛盾就明确写"未发现矛盾"。

### 二、竞争假设（≥2 个，必须互斥或显著不同）
每个假设输出：内容 / 支持事件 [E-…] / 反对事件 [E-…] / 当前倾向（强/中/弱）。
要求：假设必须尝试解释第一段全部矛盾（或说明为何解释不了）；对欠定度=高的矛盾，假设须给出至少一个"无撒谎"的替代解释路线（如机制性假信息），除非公开层已排除。

### 三、嫌疑排序 Top-2
每条：席位/名字 + 依据（引用事件序号）+ 置信表述（只许用：最大嫌疑/次级嫌疑）。

### 四、自评
你还缺什么信息？下一步最想看到谁与谁的什么互动？
```

## 基线轨 prompt（朴素基线）

```
以下是一场【{{游戏名}}】对局截至第 {{D}} 天的公开记录（原始文字）。根据目前信息，你觉得谁最可能是坏人？给出 Top-2 和你的理由，口语化即可。
```

## 执行节奏
1. 每天一轮，两轨各派一个新子代理（互不共享上下文，prompt 同模板）。
2. 两轨输出原样存 docs/sandbox/p0-replay/runs/{{id}}/day{D}-{track}.md。
3. 队长评分后填 score-{{id}}.md，直到档案完结。
