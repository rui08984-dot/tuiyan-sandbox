# R2-③ 方法学审稿人（第二轮发言）

## 一、对三位同事的裁决

### (a) 创新研究员·命题A（离线公开数据集）：绕开成立一半，换来的是三个新检查而非免检
- **"两码事"裁决：确实是两码事，分别判。** 消融实验的真值=角色配置，局始由发牌器/组织者冻结、与预测者无利害关系→我的 #1（真值可偏）/#6（Goodhart）对该实验不适用；朋友局闭环的真值=用户自己预测的事件+自己裁决，#1/#6 全额适用，公开数据集帮不上。故命题A绕开的是"科学声称"的真值口，绕不开"产品闭环"的真值口——它是补充轨，不是替代轨。
- 三个新检查：①矛盾特征是在自家账本 schema 上建并单测的，移植到 Avalon/HiPT 自由文本对话=抽取层重建，特征抽取错误会直接污染消融——须人工抽检 ≥50 条并报告错误率，否则"机械特征"名不副实；②知识污染：数据集 2026-01 已公开，被评模型 cutoff 晚于此者可能见过，绝对校准数字须逐模型排查；③63 局≠300 条门槛：每局 1 条猜狼命题仅 63 条；多时点快照可凑量但同局相关回潮，按局聚类后有效样本≈40 局当量，且真人局 28 局标注质量未核、单独看连方向性都勉强——结论：够"反馈级/方向性"，不够"证据级"。同事的"自对局千局"是对策，但 AI 自对局行为分布≠真人局，真人局子集必须单列报告。

### (b) 首席架构师·L2 个人域：机制更糟，危害更轻，分层可救
- 自裁决把 #1 从"转录偏差"升级为"真值由预测者自己构造"——机制上确实更糟；但 #6 危害反而降级：L1 的 Goodhart 押着"护城河"声称，L2 刷分=骗自己，无外部受害者。
- API 证据救多少：只救机械可判定子集（天气/账单/打卡）；**机器可判定性与弱项诊断价值近乎负相关**——⑥要诊断的自律/承诺/社交恰是 API 够不着的软命题，全靠 API 会把他自己 kill_test ③号死法（全出 0.9 安全题）变成结构性必然。堵法：两级记分——Tier A（API 可机检）进 Brier 账；Tier B（自裁决）只进描述日志，永不进校准曲线；月报强制披露 Tier A 占比，<50% 即③号死法前兆。判据落库时冻结哈希，结算改判据=void。"人机各存一概率"支持用于诊断（反馈级），但人类自报置信度是已知失准源，只进日志不进证据。
- kill_test 7 天纸面实验是全场最便宜的真值供给验证，支持；追加：kill_test 数据直接按 predictions schema 记，别白记。

### (c) 验尸官·G3"只记不评"：字面兼容，留了一个自我拆台的洞
- 我的 ≥30局∧200条 是"出曲线/出声称"的门槛，不是"记"的门槛——字面兼容。但两洞：①"n≥30"单位不明（局？条？），建议对齐为"≥30局且≥200条 resolved"；②只记不评期恰是数据质量最危险期：无反馈→录入者学不会"什么算好判据"、动力衰减→糊弄记录，n 攒够时数据已烂（他自己 R1/R4 死法在数据层重现）。堵法：**评分冻结≠反馈冻结**——期间只出过程仪表（created/resolved/void 三率、Tier A 占比、判据返工率），禁一切"准不准"语言。另 G3 内部矛盾：同条 gate 的"校准差>25pp→prompt回炉"预设评价已发生，须加 n 条件（<30局时该差值只记为假设，不触发动作）。

## 二、自我翻转：标准确实错位，但只错了一半

| 审计项 | 作为"证据"（发表级声称）需要 | 作为"反馈"（自用回路）最少需要 |
|---|---|---|
| #1 真值 | 外部冻结+录入/记分分离+盲抽复核 | 预测时冻结判据+机检子集；自裁条目分层不入曲线 |
| #3 漏记 | 100% 自动升卡+skip 全留痕 | 同左——烂反馈比没反馈更毒，门槛降为"漏记率可观测" |
| #2/#4 样本与非独立 | ≥30局∧200条+按局聚类+CI | n>0 即可，趋势仅作假设，禁"显著"语言 |
| #5 基线 | 常数基率+裸 LLM 轨必须 | 一期先跟自己比，基线二期补 |
| #6 Goodhart | 角色分离+预注册 | 分数不驱动弃用/奖励决策即可（G3"此分数驱动哪个决定"即答案） |
| #7 迁移 | 禁跨域声称 | 管线纪律可复用，校准数据不搬 |

承认：R1 我把六项全按左栏审，#2/#4/#5/#6 对"自用反馈回路"判死刑属标准错位；但 #1/#3 在右栏同样成立，这两项维持全额。

## 三、立场更新（3 条）
1. **维持**：#1 真值协议 + #3 漏记留痕，两轨通用不让步；最小版=验证点 100% 自动落库+判据冻结哈希+void 枚举+三率披露。
2. **修改**：#2/#4/#5/#6 由"否决"改"分轨裁决"——朋友局在线轨按反馈轨运行（过程仪表，无曲线无声称）；任何证据级声称（含命题A自录部分）必须走离线轨+预注册。
3. **部分撤回**：#7 不再整体否决 L2/L3；接受"管线纪律可迁移、校准数据不跨域"切分，L2 以 Tier A/B 分层形态入栈。

## 最小可行闭环·终版
- **轨A·服务证据**：Avalon 20 + HiPT 63 局离线消融（真值=官方，#1/#6 豁免）；前置=特征抽取错误率抽检+cutoff 排查；结论语言限"方向性"；要发表→开源 pipeline 自对局 ≥500 局+预注册+按局分割+真人局单列。
- **轨B·服务反馈**：朋友局（L1）+个人域（L2 Tier A/B）；验证点自动升卡、skip/void 留痕；n<30局只出过程仪表；裸 LLM 同刻轨保留（一条 prompt 的成本，防"自我感觉良好"）。
- 汇合：轨A 证明矛盾特征有边际贡献→轨B 才有资格在 n 攒够后出校准报告；轨B 的判据写法实战反哺轨A 自对局出题器。

## 一句话总评
我撤回"闭环不可救"的整体否决——正确解法是分轨：公开数据集扛证据、朋友局与个人域扛反馈，两栏各守各的底线；而 #1（真值协议）与 #3（漏记留痕）是两条轨共同的最低水位线，这一条我一步不退。
