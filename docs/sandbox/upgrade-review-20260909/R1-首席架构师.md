# R1-④ 首席架构师报告（钢人×第一性原理：AI 推演沙盘 → 预测万物引擎）

## A. 第一性原理重建

### claimed_constraints（被当作固定的约束，逐条追问独立支撑）

| 被当固定的约束 | 类别 | 有独立支撑吗 |
|---|---|---|
| 录入必须 ≤30 秒/条 | 实测 gate（体验） | 只对"社交局现场"成立；是 L1 适配器约束，非内核约束 |
| LLM 判词 = 单 prompt | 惯例 | 无。调研实证多路独立×聚合是主流打法（forecasting-tools 3×5） |
| 预测必须展示概率 | 数学×惯例 | 拆开：Brier 记分内部必须有数值（数学）；展示可只给排序+相对强度（复测已证伪精确数字无增量） |
| LLM 猜不准 | 实测 | 成立，但范围=社交推理高欠定域；不可外推为"LLM 一切预测不准" |
| 万物=公共事件起步 | 纯类比 | 无。恰恰选了真值最慢、判定最争、竞品最重的域 |
| 新闻→自动出可判定假设 | 未验证推断 | 无实证；P0 欠定根因在开放域只会放大 |
| 玄学只能娱乐 | 实测+纪律 | 成立（自有数据：梅花查狼 46/102 vs 基线 67.6% 全随机）；但"娱乐"是价值定位，非废纸 |
| 账本=人工录入唯一形态 | 惯例 | 无。schema 与录入通道可解耦，API/导入/feed 都是事件源 |

### primitives（仅留可独立支撑的事实）

1. 三重盲测实证：LLM 在社交推理局直接猜身份不优于基线（P0 全脱靶；真实局 5:7），失分集中于公开证据欠定区，显性信号稳抓
2. 机械矛盾检测可靠：比对器单测 100%，29 条矛盾语义有效率 100%、事件引用零虚构（多轮程序校验）
3. LIVE 抽取可用但非零错（extract-live-test.md 已落盘）：9/9 结构成功、中位约 22s，语义 4✅/2⚠️/3❌（归属丢失/无标注推断）→ 人工回显确认不可省
4. 数学：Brier/任何校准需要①可判定原子命题②真值回流；反事实与无判定标准命题永远无法记分
5. 自有数据：玄学排盘对局结果全随机→无预测力；但补偿性控制/社交货币需求有文献支撑
6. 人类工作记忆装不下全量离散事件流；LLM 强于结构化提取/比对/生成假设
7. 外部（已核）：预测管线五环各有 MIT/BSD 开源实现；ForecastBench（ICLR 2025）实证顶尖 LLM 公共事件预测显著逊于人类专家（p<0.001）

### discarded_assumptions

- 丢"万物必须从公共事件起步"→ 改评个人生活事件：真值回流最快（自裁决+账单/天气/打卡 API 证据，周级）、判定标准自己写（可判定性可控）、私域数据零竞品；且⑥弱项诊断只有在围绕你自己生活的长期记录上才成立——公共事件题测不出"你"的弱项。判定：强支持，是 L1→L3 唯不断的桥
- 丢"LLM 是预测主体"→ LLM=假设生成器+验证点提出者+比对器；预测主体=可判定命题；人机各存一概率、分开记校准，弱项诊断从此有数据地基
- 丢"账本=手工录入"→ 事件源是适配器插槽，不是内核
- 丢"万物=换个新闻源"→ 万物=任意可判定命题的预测账本，新闻只是 L3 的事件源之一

### rebuild（最简架构）

统一内核=五元组闭环：事件→机械矛盾→竞争假设→可判定预测卡→真值→Brier 记分。纯代码件（比对/记分/聚合/校验）恒在内核；LLM 只有三个受控角色（抽取[回显]/假设生成/无辜解释），永不碰记分。账本/事件源/真值/记分四件套=同一内核的四个插槽，适配器只回答四问：事件从哪来？真值谁裁决？多久回流？分数喂给谁？L1 对局只是插槽的一种填法。

### kill_test（最便宜证伪）

7 天纸面实验（零代码）：每天记 3–5 条自己生活的可判定预测（概率+判定标准+到期日），周末手算 Brier。三条证伪线：①凑不出 20 条真愿意记的命题→个人域供给不足，L2 死；②过半无法裁决→记分闭环断，L2 死；③全出 0.9 安全题→退化为日记，L2 降级。可并行加测（一天）：把 P0 的 29 条验证点手工转预测卡，测可判定率。

## B. 最强形态蓝图（钢人三层）

| 层 | 内核复用 | 新适配器 | 真值来源 | 记分闭环 | 独有护城河 |
|---|---|---|---|---|---|
| L1 对局参谋（在建） | 全内核首发 | 人工录入+宏+欠定标记 | 赛后档案·天级 | 验证点→预测卡，局结 Brier | 双表账本+合法谎言建模；deepwolf 仅 2★ 证无竞品 |
| L2 个人生活预测账本 | 全内核+记分器 | 日历/账单/健身/承诺清单半自动喂入 | 自裁决+API 证据·周级 | 周报校准曲线+人机分歧→⑥弱项诊断 | 私域数据+回流最快；Metaculus 们做不了你的生活 |
| L3 万物 | 全内核 | 新闻/feed+出题器（最难新件） | 公共可判定事件·月级 | 对照公开榜单 | 前两层养出的个人校准画像+领域专注；定位=应用层非竞赛 |

为何 L1→L2→L3 优于直接跳 L3：①校准需要样本量，样本量受制于真值回流速度（L1 天级/L2 周级/L3 月级）——跳 L3 等于校准曲线一年攒不出 50 条已解决预测，⑥直接死；②最难新件是"把模糊事件写成可判定题"（新闻→原子命题），ForecastBench 实证这是 LLM 已知短板区，先在 L2 用自己出题练熟判定标准写法，schema 直通 L3；③每层给下层养数据——到 L3 启动时已有数百条个人已解决预测的校准画像，这是 Metaculus 用户都没有的个人资产。

玄学断语层位置：不进预测管线（自有随机性数据背书），挂叙事层跨三层复用——L1 天结算判词卡（已设计）、L2 校准周报运势化（"本周高估自己自律，如水逆"）、L3 重大预测命运感包装。它是记分数据的可消费皮肤+留存钩子，恒挂娱乐、永不入 Brier 账本。

```
事件源适配器        统一内核（纯代码+受控LLM）        真值适配器       记分内核
L1 人工录入+宏  ─▶  账本→机械矛盾检测(单测)     ─▶  L1 赛后档案·天级 ─▶ Brier+校准曲线
L2 日历/账单/健身   →多路LLM假设×独立聚合          L2 自裁+API·周级     ↓
L3 新闻/feed       →验证点=可判定预测卡(人机双概率)  L3 公共判定·月级   人机分歧→弱项诊断⑥
                   →belief×LLM双栏 + Argdown图
      叙事层侧挂(跨层复用): 玄学判词/运势周报 —— 恒挂「娱乐」, 永不入Brier账本
```

## 最大的一个断点（诚实预警）

L2 的记录惰性。L1 有场景刚需（局上要用），L2 预测生活琐事没有天然需求——"热情死在表单上"这条已被对抗审查预言过，在 L2 会放大十倍。L2 若撑不起记录习惯，L1→L3 的迁移桥就断，"万物引擎"退化为"对局复盘工具+一本没人打开的预测日记"。这是行为问题不是架构问题，架构救不了不录数据的人；缓解靠把 L2 做成 L1 副产品（赛后顺手下注"下次我还会犯这个错吗"）+ 数据源全自动静默喂入（零表单）——而 7 天 kill_test 花十分钟即可先验证这条命门。
