## 二、候选创新命题

### 命题 A：机械矛盾图谱是 LLM 社交预测的外生校准信号（对应构想③+①）
- 新在哪：角色推断文献全是 end-to-end；UQ 文献的"矛盾"只在单模型内部采样间。没人把程序化、可分离的矛盾特征层接到 LLM 概率输出上并测 Brier 边际贡献。
- 为什么可能牛逼：若成立，给出"符号可验证结构×LLM"混合预测的可推广模板（新闻核查、审计、冲突医疗信息）；矛盾特征可消融=因果性证据。
- 最便宜证伪：现成数据（Avalon-NLU 20 局 + Hidden in Plain Text 的 63 局 + 自录局），逻辑回归比三组 Brier：纯 LLM 概率 / 纯矛盾特征 / LLM+矛盾数，配对 bootstrap。一两周工作量。
- 审稿人最狠一刀："真人局 n≈几十，置信区间盖不住效应"。对策：用其开源 pipeline 自对局造千局。

### 命题 B：封闭对抗小域 vs 公共开放域的 LLM 校准差异（构想①的对比实验版）
- 新在哪：ForecastBench-Sim 只建了策略游戏数值域 benchmark；无人同一批模型在"对抗语言声称域"与"公共事件域"上做校准对比（Brier 分解、过度自信率）。
- 为什么可能牛逼：若封闭域暴露不同失准模式（如被说服后概率崩塌），给 LLM 预测能力加"对抗鲁棒校准"新维度，可反哺 AI 安全评估。
- 最便宜证伪：自有验证点题库 + ForecastBench 公开题，同模型跑，报告 ECE/overconfidence 率；再试 BLF 的层次 Platt 参数能否跨域迁移。
- 审稿人最狠一刀："两域题目难度不可比，Brier 差异归因不到域"。需人类基线分位数对齐做难度匹配。

### 命题 C：策略性信息源下的序贯贝叶斯预测（BLF 迁移+内生化源可靠性）
- 新在哪：BLF 假设来源善意；社交推理域中信息源在策略性撒谎，源可信度必须内生化（如矛盾计数→源权重先验）。这是 forecasting 方法论上真缺的一块。
- 为什么可能牛逼："如何为会骗你的信息源校准"直接对接超预测者实践与 adversary-aware forecasting；游戏域有真值、可无限自对局。
- 最便宜证伪：最小复现 BLF 式 3×5 独立判词聚合，均匀权重 vs 矛盾加权源权重，比 Brier。
- 审稿人最狠一刀："BLF 域迁移+一个小 trick，增量不够顶会"。对策：把"策略源下的校准"形式化或升格为公开 benchmark。

## 三、泼冷水总评
- 构想②③（多路聚合+belief 栏）在公共事件侧已被 BLF 占位，单独做不构成创新，必须绑定 A（矛盾特征）或 C（策略源内生化）才有差异点。
- ForecastBench-Sim 的出现说明"封闭域自动结算预测"正在升温，窗口期可能只有 1-2 年，先发数据集+benchmark 是性价比最高的占位方式。
- 血染钟楼方向文献检索几乎全空，若做"血染账本数据集+校准基准"即为首个公开资源（未找到任何血染钟楼 AI 论文）。
