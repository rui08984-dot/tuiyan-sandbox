## 三个最致命漏洞与堵法

1. 漏记偏差不可逆（#3+#2 复合）：跳过的预测不留痕，事后无法补录，校准曲线被系统性美化，且无任何统计手段可修。
   → 堵法：验证点 100% 自动升卡，用户无挑卡权；skip/void 全量留痕+原因枚举；每份报告强制披露 created/resolved/void 三率与每概率桶 n；恒真/恒假条目由机械规则拒绝入卡。
2. 真值源头未分离（#1+#6 复合）：判分代码再纯，真值录入可偏即全链污染——"护城河"声称恰恰押在这条真值上。
   → 堵法：录入与记分物理隔离（录入者界面不可见 Brier 分）；狼人杀=局终亮牌逐席录入+夜行动当事人确认，BOTC=说书人录入（§11.2④ 旁观者模式是现成落点）；void 仅限枚举原因；每月盲抽 10% 已结算卡复核（复核者不见先验概率）。
3. 无基线+伪重复（#5+#4 复合）：有曲线≠有证据；按条聚合有效样本约虚高 2.5 倍。
   → 堵法：三轨同题同刻——实验轨 / 裸 LLM 轨 / 基率常数基线（双轨纪律直接沿用已预注册的 score-protocol §1"双轨同日跑防模型路由漂移"）；主指标=局均 Brier 差，按局 block bootstrap 出 95% CI；按条曲线仅作描述。

## 修订后的最小可行实验设计

1. 工程前置：schema 增 predictions 表（先验/判定标准/到期事件/真值/录入者/void 原因）——验证点当前不落库，闭环无处挂靠。
2. 先离线后在线：用已有零缺口真值档案局（Pandakill 等）验证管线与记分，再上朋友局。
3. 预测卡生成：LLM 生成时强制结构化（先验概率+绑定账本谓词的机检判定标准+到期事件），非二值条目拆为二值分解。
4. 三轨同刻生成，模型版本锁定并记档（对齐 score-protocol §3"模型身份记入评分表"）。
5. 预注册判定（学 score-protocol v1.0"点火后不可改"纪律）：主指标=局均 Brier（实验−裸 LLM）+ 阈值；ECE/校准图仅描述性；门槛=≥30 局且 ≥200 条 resolved 才允许产出"曲线"。
6. 声称降级："护城河"改为"带基线对照的局内 Brier 记分"；万物模式仅声明管线复用；§12.3 纪律清单增补"校准数据不跨域迁移"；与"参谋卡恒挂思路非答案"的产品承诺保持一致。

## 一句话总评

方向有价值（狼人杀确是真值回流最快的校准沙盘），但当前形态是无基线、无对账、无真值协议的自评闭环——先堵住漏记、真值与基线三个口子，它才从"记账玩具"升格为"可累积的证据"。
