2. 【人员面·自裁决】L1 有赛后亮牌/说书人当外部真值锚；L2 判据自己写、兑现自己判、void 自己裁、分数自己看——全链零外部节点，赌徒式记账（输的 void 掉、赢的记入）结构上零成本。乙的月度盲抽在 L2 无处安放，因为复核者就是本人：无外部审计的私人 Brier 不是校准，是自画像。
3. 【流程面·"零表单静默喂入"偷换时序】日历/账单喂进来的是事后事件，预测必须事前注册——要么人手动下注（你预警过的表单惰性回归），要么 LLM 代出题（你自己的 extract-live-test 实证 3/9 语义错、人工回显确认不可省）。喂入自动化的是账本半边，下注半边零自动化：7 天 kill_test 请只测"愿不愿意天天下注"，那一半才是命门。

## 二、自我翻转（打倒我 R1 的两条）

8. 【打倒一】G1-G5+Z 全是减速带，没有一条回答"这个项目凭什么值得继续"。防守型计划的终局是防守到死：全部 gate 通过的项目=一个什么都不做的项目。我 R1 只看得见死法，看不见活着的理由——甲的命题 A/C 与丙的 L2 恰好在答那半边，我的 gate 该给他们让路。修正规则：**每道 gate 必须绑定"过 gate 的最短路径"，否则 gate 就是死刑缓期执行。**
9. 【打倒二】G2 是永门："Brier<基准率×0.9"需 40-50 局/300 条才有检验力（乙的数字背书），G2 自己却只批 10 题试点——试点永远过不了自己这扇门，"门后实验"被我写成了封杀裁决。连带错误："长时域/反事实永久禁入"一刀切错了对象——丙的承诺类个人命题（"下周跑步三次"：周级、外部证据、可判定）正撞在我的禁令上；该禁的是"无真值锚"，不是"长时域"。
