# AI 推演沙盘 → 预测万物：专家团两轮终审 · 总裁决方案

> 日期：2026-09-09 ｜ 状态：纯研判，零代码改动 ｜ 存档：`reviews/sandbox-deliberation-r1/`（R1×4 + R2×4）
> 团队：创新研究员 / 事前验尸官 / 方法学审稿人 / 首席架构师（背对背两轮，第二轮互审翻转后全场收敛）
> 背景事实：LLM 直接猜狼已实证不准（AvalonBench 22.2% vs 38.2%；Werewolf Arena 无信息 1.2%）；梅花查狼=随机；真人局场外参谋全球无竞品；BLF（arXiv 2604.18576）已占"多路聚合+层次校准"；ForecastBench-Sim（arXiv 2606.18686）窗口期 1-2 年。

## 〇、G0——"这项目就算活着，用户图什么"（全场最高优先，先答）

三位理由，任一成立项目就有活着的理由，三个都不成立→只维护不开发：

1. **工具价值**：P1b-5 手机实测通过后，参谋卡能改变朋友局的实际决策（信息增量>裸聊）。
2. **科研价值**：命题 A（矛盾特征层×可消融×外生校准信号）是四路查证确认的全球空位，离线数据即可证伪，是个人够得着的"很牛逼"。
3. **叙事价值**：玄学判词+运势周报挂叙事层，是留存钩子，恒挂娱乐永不入记分。

## 一、总裁决（三句话）

1. **蓝图降级为"L1 终点 + 门后件"**：账本+矛盾检测+参谋卡+P1b-5 实测 = 本工程终点站；L2 个人生活域是"用户没下单的假说"，L3 万物是"门后实验"。
2. **双轨分轨**：公开数据集扛**证据**（轨A），朋友局/个人域扛**反馈**（轨B）——两轨共用最低水位线（真值协议+漏记留痕），各守各的底线。
3. **科研野心只留命题 A（C 并入作消融组）**，其余全部降为基线件或门后件。

## 二、七项升级 · 最终裁决表

| # | 原提案 | 终审裁决 | 依据（R2 收敛） |

## 三、门体系终版（每道 gate 绑定"最短通过路径"）

| 门 | 内容 | 最短通过路径 | 不过的后果 |
|---|---|---|---|
| **G0** | 用户图什么（见〇） | 三理由任一成立 | 只维护不开发 |
| **G1** | P1b-5 手机实测：录入≤30s/条 + 参谋卡有感知 + ≥1 条矛盾改变复盘结论 | P1b 收口后真机测 | L1 降级纯复盘，③④⑥随作废清单死 |
| **kill_test**（并行） | 7 天纸面：每天 3-5 条个人可判定预测（概率+判据+到期日），周末手算 | 10 分钟/天，数据直接按 predictions schema 记 | L2/L3 桥断，蓝图= L1 终点论 |
| **G2** | L3 放行：可判定率、判据争议率、月 resolve 吞吐三过程指标达标（Brier 仅描述） | 轨B 数据积累 | L3 不写检索代码 |
| **G3** | n<30局：只记不评；期间只出过程仪表（created/resolved/void 三率、Tier A 占比、判据返工率），禁"准不准"语言 | 自动升卡+一键 void | ①砍为纯记账 |
| **G4** | 4 周无新局/无 resolve → 只维护不开发 | — | 冻结开发 |
| **G5** | 单卡≤5min + 单局 token 预算；②强制跨模型 | — | 砍路数 |

L2 附加三条 gate（若 G1/kill_test 任一通过且用户下单）：①下注时冻结机检判据哈希；②void 率>20% 红警停记分；③安全题占比>40% 降级为日记。

## 四、双轨设计（方法学终版，验尸官裁剪为单人可执行）

**轨A · 服务证据**（离线，零工程侵入，不占施工线）：
- 数据：Avalon-NLU 20 局 + Hidden in Plain Text 63 局（已开源）+ 自录局；真值=官方配置，#1/#6 豁免
- 设计：**四臂消融**——纯 LLM 概率 / 纯矛盾特征 / LLM+矛盾数 / LLM+全文无标注；逻辑回归比 Brier，配对 bootstrap
- 前置检查：①特征抽取错误率人工抽检≥50 条并报告（移植=抽取层重建）②cutoff 知识污染逐模型排查 ③按局聚类，真人局子集单列
- 防线：矛盾特征对账本长度偏相关 >0.8 → 命题 A 认死；结论语言限"方向性"；要发表→自对局 ≥500 局+预注册

**轨B · 服务反馈**（产品线，L1 + L2 Tier 分层）：
- 验证点 100% 自动升卡（用户无挑卡权）+ skip/void 枚举留痕 + 三率全披露；判据落库冻结哈希，结算改判据=void
- Tier A（API 可机检：天气/账单/打卡）进 Brier 账；Tier B（自裁决）只进描述日志永不进曲线；月报披露 Tier A 占比<50%=降级前兆
- 裸 LLM 同刻轨保留（一条 prompt 的成本，防自我感觉良好）；n≥30 后再上裸 LLM 对比轨
- 汇合：轨A 证明矛盾特征有边际贡献 → 轨B 才有资格出校准报告；轨B 判据写作实战反哺轨A 自对局出题器

## 五、科研创新命题（终版排序）

| 命题 | 状态 | 一句话 | 价值 |
|---|---|---|---|
| **A：机械矛盾特征=外生校准信号** | **唯一保留的科研野心** | 程序化矛盾特征层接到 LLM 概率输出上测 Brier 边际贡献，可消融 | 三面合围确认空位；自有矛盾检测 100% 单测背书；离线数据 2-4 周爆发+硬死线 |
| **C：策略性信息源内生化** | 并入 A 作消融组 | 矛盾计数→源权重先验（BLF 假设来源善意，游戏域天然违反） | 真方法缺口，但独立做增量不够 |
| **B：LLM 校准的域依存性表征** | 门后实验 | 封闭对抗语言域 vs 公共域：Brier 分解+过度自信率；对比研究≠迁移声称 | 跑完两边都赢（证实/证伪"不跨域"都是发现） |
| **血染钟楼校准数据集+benchmark** | 免费期权 | 首个公开资源（文献全空），窗口期 1-2 年 | 非开发者不赶工：schema 留兼容位即可，G1 后视情况兑现 |

## 六、修订路线图（时间序）

1. **现在**（不动 DSH 施工线）：用户跑 7 天 kill_test（10 分钟/天）；轨A 命题 A 离线消融可另线启动（2-4 周爆发）
2. **P1b 收口后**：G1 手机实测 → ①②最小版（⑤ 可并行）→ 按 G1 数据定 ③④⑥
3. **任一记录门通过 + 用户口头下单**：重开 L2 讨论（带三条 L2-gate）
4. **G2 过程指标达标**：才允许 L3 试点（≤30 天、判据客观、cutoff 后事件，预注册判定）
5. 持续：4 周无活动→只维护（G4）；季度复燃检查

## 七、纪律清单增补（写入 §12.3）

- **校准数据不跨域迁移**；跨层只携带 schema / 判据写作技能 / 记录习惯，校准数字域内从零重攒
- "无真值锚禁入"（替代"长时域禁入"）；承诺类个人命题（周级+外部证据+可判定）不在此列
- 玄学恒挂「娱乐」，永不入 Brier 账本；参谋卡恒挂「思路非答案」
- ②多路聚合=基线件非卖点；禁止用"窗口期"绕过实测（紧迫感是烂尾加速器）

## 八、明确不做（反 scope-creep）

- ❌ 不赶工血染 benchmark（维护负债>先发收益，等 G1 后视情况）
- ❌ 不做 L2 的日历/账单/健身适配器（每个=一个 M 级工程，撞 R4 死法；最多纯手填）
- ❌ 不做月度盲抽复核、block bootstrap 等实验室级工程（单人不可执行）
- ❌ 不把科研命题注入产品轨（论文饥渴是隐蔽的 scope creep）
- ❌ G2 未过前 L3 不写一行检索代码；不做长时域/反事实题

---
**一句话总决**：先让 L1 成为真正好用的复盘工具（G1），同时用十块钱的 kill_test 和离线四臂消融试出"矛盾特征校准信号"这条可能是全球第一的科研线——"预测万物"不是现在的工程，是这两条线攒够证据后的自然出口。
