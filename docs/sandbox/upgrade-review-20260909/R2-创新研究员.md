# R2-① 创新研究员（第二轮发言）

> 引文 1906.02530 / 2207.05221 / 2311.09553 均本轮经 arXiv 逐条复核。

## 一、对三位的反驳

**打乙（方法学）："校准不跨域迁移"这条裁定本身无引文，且打错了靶子**
1. 不迁移有强文献证据：Ovadia 2019（arXiv 1906.02530）证分布偏移下事后校准失效；Kadavath 2022（2207.05221）证同一模型换任务/格式校准即变、P(IK) 仅部分跨任务泛化；2311.09553 证换提示格式校准就不同。但共识恰恰是：**校准是 (模型×域×格式) 三元组的经验属性，须逐域测量**——它是待检验结论，不是可当前提的公理。拿一条未检验断言去毙一个专门测量它的实验，是循环论证。
2. 乙打中的是命题 B 的后半句（"试 BLF Platt 参数跨域迁移"——那是迁移声称，删）。**对比研究≠迁移声称**：对比的合法结局包括"证实不迁移、且失准模式系统性不同"，后者照样是可发表的表征性发现。审计#7 与命题 B 是同一枚硬币：乙当纪律、我当被检假设——实验跑完，"校准数据不跨域迁移"纪律才从口号变成证据。
3. 乙的样本量论证（n≥30 局/≥200 条才准出曲线）只对产品轨成立；研究轨吃公开数据集+自对局，n 是千级不是年积几十。这条论证支持的是两轨分离，不是毙题。

**打甲（验尸官）：gate 内容大多对，排序逻辑把两条独立失败域缝死在一起**
1. G2 与 G3 内在不一致：G3 定"n≥30 前只记不评"，G2 却拿 10 道题的 Brier<基准率×0.9 当放行门。n=10 时 Brier 抽样噪声约 ±0.1 量级，这道门近乎抛硬币——要么 n 提到 30，要么 G2 只保留"判据零争议"。
2. 命题 A 的最便宜证伪全部跑在现成数据上（Avalon-NLU 20 局、Hidden in Plain Text 63 局已开源+自对局），不吃 P1b-5 手机录入一粒米。G1 卡死的是产品线，卡不住数据集线。把一切排到实测之后，是把你最准的死因 R1"顶线未闭先盖楼"用到了不需要这根顶线的楼层上。
3. R2"新闻题必撞训练污染"全收——但结论应反转：正因为动态出题是唯一躲法，"对抗语言域+自动结算"的 benchmark 才是时间敏感资产。你的框架只计维护成本、不计等待成本：ForecastBench-Sim（2026-06）三个月吃掉一半空位，这个温度下"实测通过再动手"≈把首发让出去。

**打丙（架构师）：L2 当产品是钢人，当科研主线是自走死胡同**
1. L2 桥的承重论证自相矛盾："到 L3 时带着数百条个人校准画像"——这正是乙裁定的"校准数据跨域迁移"，你在用被没收的货币付桥钱。过审改法：L2 产出重述为程序性资产（出题手艺、schema 成熟度、记录习惯），你"练熟判定标准写法"一句其实已写对，但它撑不起"唯一不断的桥"的强度。
2. 科研视角裁决：个人域 n=1、无公开基准、隐私使数据不可发布，ML 会议没戏；唯一出口是 CHI/CSCW 式 self-tracking/n-of-1 传统，卖的是行为与系统设计、不是校准科学。L2=留存钩子+⑥弱项诊断地基，成立；L2=命题 B 类科研的载体，不成立。
3. "日历/账单/健身半自动喂入"对非开发者=每个适配器一个 M 级工程，正撞甲 R4 腐烂死法。你的 kill_test 测了"愿不愿记"，没测"建不建得起"——补一条：任一适配器超 3 晚工时，L2 即降级纯手填。

## 二、自我翻转（假如我是反方）
1. 命题 A 的"矛盾特征"可能只是信息量的代理：矛盾数与账本密度近似单调，裸 LLM 喂全文可能吃掉全部边际贡献；且机械检出的矛盾与 LLM 自行读出的矛盾高度共线，"符号层可分离"是我宣称的、未证明的。补强：三臂改四臂（+LLM+全文无标注），并报告矛盾特征对账本长度的偏相关——>0.8 则命题 A 认死。
2. 科研框架对非开发者个人项目是 scope creep：锁版本、预注册、bootstrap、千局自对局，叠上甲 R4（环境一崩即死）与乙的工程前置清单，科研轨本身就是新增烂尾面。用户要参谋卡、不要 paper；把论文饥渴注入个人工具是最隐蔽的作弊——R1 里我一半的热情服务的是我的议程而非用户的。（附小翻转：血染"文献全空"可能=没需求，空白≠机会。）
