# 推演沙盘 · 使用指南（2026-09-11 版，B6 一页流+P9 排盘）

> 旧版 p5-手机实测指引.md 的 UI 已改版（四 Tab → 三区一页流），本文以当前版本为准。

## 起动（每次）

1. 双击 `p1b\start-p1b.bat`（真 LLM 模式+共享真库 p1a.db）。
2. 窗口保持打开（关窗=停服）；停止=窗口内 Ctrl+C。
3. 浏览器开 **http://127.0.0.1:8787**（本机；手机同 Wi-Fi 用 http://10.38.23.183:8787，需管理员防火墙放行 8787 才可达——本机自测不需要）。

## 三区导览

| 区 | 干什么 |
|---|---|
| **现场 /**（默认页） | 打局主战场：事件录入（自由文本+3 宏）→ 天结算 → 参谋卡（异步生成）→ 赛后判词彩蛋弹层 |
| **管理 /manage** | 建局（局名/类型 werewolf\|botc/人数→自动建席）/ 座位名单 / 天数推进 / 历史局 |
| **设置 ⚙ /settings** | 供应商管理（tokenrhythm 已配好勿动；换 key 在这里） |
| **☯ 排盘**（导航新增） | 独立玄学页：数字/时间/随机三法起卦+历史档案（与对局无关，随便玩） |

## 一局的完整流程

1. **管理页建局**：局名+类型+人数 → 自动建座位名单（可改真名）。
2. **打局中 → 现场页录入**：
   - 高频三件事点**宏按钮**：跳身份 / 查杀 / 金水 → 小表单填席位 → 直接结构化入账（不走 LLM，最快）→ 仍弹确认卡复核；
   - 其它发言/行动：底部输入条打自由文本（如「5号说自己是女巫」）→「AI 拆解」→ **待确认卡**（有错直接改）→「确认入账」；
   - 死亡/夜晚行动照实录；录错的事件可 edit/retract。
3. **每天结算**：点「天结算」→ 后台生成参谋卡（约 2-3 分钟，角标提醒，录入不被阻塞）→ 点开看卡：矛盾区（欠定度色标 high=红）/ 假设双栏对峙 / 验证点 checklist——**这是思路参考，不是答案**。
4. **天数推进**：管理页把天数+1，继续录。
5. **局终**：赛后现场页会出现**玄学判词彩蛋**（本局数据起卦+LLM 断语，恒挂「娱乐参考」）；弹层里「进入排盘」可跳独立玄学页。
6. **后台自动**：验证点会自动转成预测卡落库（L0 期只记不评，UI 无感）——这是在为校准曲线攒数据。

## G1 实测三判据（对照着感受）

1. 录入 ≤30 秒/条（宏+确认卡应该让你无感达成）；
2. 参谋卡有感知（异步生成不打断你，出卡后内容确实改变你对局面的理解）；
3. ≥1 条矛盾检测改变了你的复盘结论。

## 常见问题

- 页面打不开 → 服务窗口是不是关了；地址必须带 http:// 和 8787。
- 手机打不开 → 防火墙（本机自测无此问题）；手机开 VPN/流量也会挡。
- 网页与终端数据互通 → 共用同一 p1a.db，正常。
- 判词/参谋卡生成失败 → 看服务窗口报错；key 问题去设置页测连接。
