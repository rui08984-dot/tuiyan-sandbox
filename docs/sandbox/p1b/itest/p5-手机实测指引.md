## 第 0 步（一次性，仅当手机打不开时）：防火墙放行

本机已查实：Windows 防火墙**没有** 8787 端口的任何入站规则，且三档配置（Domain/Private/Public）全部 ON；
当前 WLAN 网络类别为 **Public** —— 不放行时手机访问会被静默超时。
集成测试未改动防火墙（按纪律只查不改）。需要真机访问时，请用户在**管理员** PowerShell 执行：

    netsh advfirewall firewall add rule name="p1b-sandbox-8787" dir=in action=allow protocol=TCP localport=8787 profile=public

（回滚：netsh advfirewall firewall delete rule name="p1b-sandbox-8787"）
注：本机自己 curl http://10.38.23.183:8787/api/health 返回 200 不代表手机可达——本机自连不穿越入站规则，这是防火墙结论以 netsh 查询为准的原因。
