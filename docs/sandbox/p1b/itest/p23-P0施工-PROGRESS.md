## 【2026-09-17 · 更正：CRLF 字节级事故（第三次同类：口径/字节没对齐）】

- **现象**：用 `py`（文本模式默认 newline=None）写回 E2 冻结件 ⇒ **LF 被翻译成 CRLF**，字节级 sha 从 `5c354501…` 漂到 `c9714caa…`，MATCH 变 false。
