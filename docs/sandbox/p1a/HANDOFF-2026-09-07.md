## 四、环境坑（今天实测沉淀，接手者必读）

- tools.write 单次参数 >6KB 中文会失败 → 分块写+edit 追加或分段文件拼接
- pwsh stdout 可能不回显 → 验证一律写文件读回
- pwsh 5.1 Get-Content 不加 -Encoding UTF8 会按 GBK 误读中文
- run_code 沙箱无 require/node API
- 后台子代理偶发 TRANSPORT 死亡 → 死亡后 send_message 恢复令可续跑；日志在 ~/.dsh/sessions/<项目key>/<id>/session.jsonl.zstd（py zstandard 解压）
- pwsh 编辑文件会写 CRLF → LF 文件修改走 tools.edit 或 node 脚本
- fast_locate 的 mtime 是 UTC（差 8 小时）
