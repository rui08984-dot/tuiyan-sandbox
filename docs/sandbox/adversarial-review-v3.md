## 二、方案层根本性审查（第一性原理 + steel-manning）

从"不被动摇的基本事实"重推一遍方案骨架，找它的承重墙和裂缝：

### 2.1 基本事实清单（逐条独立支撑）
1. 人类 10 人局记不住全量发言 → 账本有真实痛点（工作记忆外包）✅ 常识级成立
2. 矛盾检测=声称集×行动集机械比对 → 不依赖 LLM 灵感，可单测 ✅ 逻辑必然
3. P0 实证：真相 hinges on 公开层不可见私密信息（投毒/查验）→ **命中率有信息论天花板** ✅ 本项目最强的一条实证
4. LLM 弱于蓄意欺骗建模、强于结构化提取比对 → 两层化架构对症 ✅ P0 H2/H3 通过佐证
5. 玄学需求真实但同质化 → 玄学不能当差异化主轴 ✅（F10 未复验，但方向性结论由多源检索支撑）

### 2.2 红线发现（会在 gate 判定时造成错误决策，必须先修）

**R1｜gate 失败处置与 v2.5 价值主张存在张力（三档结局未写明）**
- 入口：§9.4「真实局复测实验轨命中率>基线轨，未过不进 P1a，过不了即杀引擎」 vs §12.1 价值主张收窄为「外脑记忆+一致性检查+假设管理」。
- 问题：若复测 H1 再不过，按 §9.4 字面要"杀引擎"——但 P0 已实证机制层（H2/H3）通过、确定层产出过真实结构发现（"Chef 候选对均不含 Abdallah"）。把被证据支持的部分一并杀掉，是被一句话误伤。
- 修法（已可执行）：gate 失败处置改三档——① H1 过 → P1a 全量；② H1 不过但确定层线索质量≥基线 → 砍概率层，保留账本+矛盾检测（产品=复盘工具+矛盾检测器，v2.5 收窄主张的忠实形态）；③ 确定层也崩 → 杀项目。**"杀引擎"只能指概率层。**

**R2｜复测评分规则未预先钉死（裁判偏倚风险 + n=2 统计现实）**
- 入口：§9.4 硬 gate「实验轨>基线轨」——但 Top-N 命中定义、并列处理、部分命中计分、逐日口径均未落盘。
- 问题：跑完再定评分=赛后来找对自己有利的口径；n=2 双轨下「命中率>基线」无统计意义，gate 实际是「无翻车信号」而非「证明价值」。
- 修法：复测点火前落盘 score-protocol-realgames.md（预注册式），明确：命中=Top-3 含真狼；部分命中计 0.5；基线=同档案裸聊同日同模型；预期钉死为方向信号。Lyingman 局评分按「公开证据支撑度」判，不按对错判（E-3 查杀 6号 JY 本就是最强公开证据，押 JY 无法区分推理与叙事直觉——探针 F11 的背景污染计入口径）。

### 2.3 黄线发现（影响产品成败，不阻塞 gate）

**Y1｜录入成本 gate（≤30秒）从未实测**——P0 测的是 AI 研判，录入成本是人的成本；真实局复盘导入≠真人局实时录入。这是方案最大未测前提。处置：明确实测推迟至 P1a 首次真人局；「纯复盘工具」为已备案降级终点（§2.1 已有，重申防止漂移）。

**Y2｜欠定性须转化为预期管理**——档案完整度 85%/70% + 私密信息不可见 → 命中率天花板客观存在。产品叙事钉死「辅助研判非预言」；复测评估「比基线更少犯错+线索可复核」，不评估「猜中」。

**Y3｜探针能力边界**——探针只测显性知识，测不出「见过但没记住」的隐性污染。已按 F11 处理：Lyingman 局污染计入口径；如需更强隔离可事后追加冷门局，但当前两局可用性判定不变。

### 2.4 steel-manning 通过项（最强反方也推不倒的）
- **两层化研判**：正面反制「LLM 欺骗建模弱」这一训练目标级局限，P0 实证确定层独立产出价值——这是全方案最硬的一块承重墙。
- **验证先行路线**：P0 一天级纸面实验买到了"哪种失败"的答案（欠定根因），而不是在错误方向上烧两周工程——顺序纪律已被实战验证。
- **玄学 B 双板块**：叙事皮肤定位使其失败不伤理性核；红线（映射层降级、承诺话术分离）已收。
- **FPS 合规设计**：纯浏览器+口述回合，与 Vanguard 风险面物理隔离。
- **梅花纯数学自写+单测**：口径分歧显式列出、时间起卦 out-of-scope——正确的可测试边界。
- **18 分钟延迟已适配**：天结算+推送式（§11.2 ③）与延迟现实自洽。
