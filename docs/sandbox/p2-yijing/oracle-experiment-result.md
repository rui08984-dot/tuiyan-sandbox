## 结论：三种取数法均为随机水平，显著低于最笨策略

| 取数法 | 命中 | 命中率 | 全猜好人基线 | 二项 p（vs 基线） |
|---|---|---|---|---|
| 法A「座位数」 | 15/34 | 44.1% | 67.6% | 0.9987（不显著，方向相反） |
| 法B「倍乘」 | 19/34 | 55.9% | 67.6% | 0.9476（不显著） |
| 法C「名字」 | 12/34 | 35.3% | 67.6% | 1.0000（不显著） |
| **合计** | **46/102** | **45.1%** | **67.6%** | — |

- 断语判狼比例（16/10/17 per 法）与真值狼比例（11/34=32%）不匹配；各法命中率全部落在「纯随机二选一」的 50% 期望噪声带内（44.1% / 55.9% / 35.3%）。
- **判读**：梅花起卦（本实现口径）+ LLM 断语查狼 = 随机水平，且低于「无脑全猜好人」这一最笨一致策略 22.5 个百分点。与文献先例（占星双盲 Nature 1985、塔罗真假解读对照）方向一致。
- 口径对比附带发现：纯机械映射口径（LY/PK 局）与复合打分口径（botc 局，体用打分+变卦修正+卦名裁决）无命中率差异——增加断语规则复杂度未带来增益。
- 协议诚实边界适用：n=34×3 探索性样本；无法区分「卦无效」与「LLM 断语能力不足」；本实验不构成对梅花易数整体的否定，仅覆盖「数字起卦+体用生克断阵营」这一实现路径。
