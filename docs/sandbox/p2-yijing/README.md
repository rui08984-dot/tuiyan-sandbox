# meihua.js — 梅花易数「确定层」起卦模块

AI 推演沙盘 P2 易经板块。纯 Node、零依赖、CommonJS。只做确定性推导（数字→本卦/互卦/变卦/动爻/体用/五行生克），**不做吉凶断语**（断语属 LLM 推断层，见设计文档 §2.3：排盘=纯数学，断语=LLM）。

## 文件

- meihua.js — 主模块（CommonJS，require 即用）
- meihua.test.cjs — 17 用例单元测试（node meihua.test.cjs 直接跑，零依赖 assert）
- test-out.txt — 最近一次测试输出存档（17/17 PASS，2026-09-07）

## 所采规则与出处（通行本口径）

| 规则 | 口径 | 出处 |
|---|---|---|
| 先天八卦数 | 乾1 兑2 离3 震4 巽5 坎6 艮7 坤8 | 《梅花易数》通行本（故宫珍本丛刊体系）卷首"八卦数" |
| 上卦/下卦 | 数A%8、数B%8，余 0 取 8 | 通行"除八以八作除数，起上卦"法 |
| 动爻 | (数A+数B)%6，余 0 取 6 | 通行"除六以六作除数，起动爻"法 |
| 互卦 | 本卦 2,3,4 爻为下卦、3,4,5 爻为上卦 | 通行互卦取法 |
| 变卦 | 动爻阴阳互变 | 通行 |
| 体用 | 动爻所在经卦为"用"，另一为"体"（初~三爻动属下卦用，四~六爻动属上卦用） | 通行"体用总诀" |
| 五行归属 | 乾兑金、离火、震巽木、坎水、艮坤土 | 先天五行后天配，通行 |
| 生克循环 | 相生金水木火土金；相克金木土水火金 | 通行 |
| 总数起卦默认拆法 | 对半拆 a=floor(total/2), b=total-a | **模块自定口径**（非古籍原法）；splitFn 参数支持调用方自定义拆法 |

## 规则分歧（不静默选边）

1. **动爻取余**：通行本作"%6 余 0 取 6"；另有流派作"%5+1"（将动爻压到 1-5 再含上爻特例）。本模块采通行本 %6 口径。
2. **总数拆卦**：古法有"以总数十位/个位拆""先上后下拆"等多派；本模块默认对半拆仅为一致性约定，正式起卦建议用 qiGuaByNumbers 传明确两数。
3. **体用判定**：通行"动爻所在经卦为用"；亦有"动爻所在为体"的少数派记法。本模块采通行（动爻所在=用）。
4. **爻序**：本模块统一"自下而上"（数组第 0 位=初爻），与古籍画卦方向（自上而下书）相反，属工程表示选择，不影响卦理。
