## 七、环境坑（本机实测沉淀，接手必读）

- tools.write 单次参数 >6KB 中文失败 → 分块 ≤5KB+edit 追加或分段拼接
- pwsh stdout 可能不回显 → 验证一律写文件读回
- pwsh 5.1 Get-Content 不加 -Encoding UTF8 按 GBK 误读中文
- cmd/bat 编码：bat 骨架纯 ASCII+chcp 65001+中文内容独立 UTF-8 txt（GBK 转码方案已废弃）
- run_code 沙箱无 require/node API
- 后台子代理偶发 TRANSPORT 死亡 → send_message 恢复令可续跑（上下文保留）；日志 ~/.dsh/sessions/<项目key>/<id>/session.jsonl.zstd（py zstandard 解压）
- pwsh Set-Content 写 CRLF → LF 文件走 tools.edit 或 node
- fast_locate mtime 是 UTC（差 8 小时）
- mnemon_runtime_memory：content 禁含 § 字符；replace 的 old_text 会被投影格式漂移——匹配失败就换 add 追加
- npm 用 npm.cmd（npm.ps1 被执行策略拦截）
- run_code 禁长阻塞等待；大模型推理调用走后台 job
