## §2 风格定位（采自 skill `styles.csv`）
**组合三条既有类目，不发明新风格**：
1. **Data-Dense Dashboard**（BI/Analytics）— 主基调。关键词：KPI 卡行、数据表、**最小内距 8–12px**、12 列栅格、最大信息密度。其变量表可直接用：`--grid-gap:8px`、`--card-padding:12px`、`--font-size-small:12px`、`--table-row-height:36px`、`--header-height:56px`、`--sidebar-width:240px`
2. **Drill-Down Analytics** — 治「长竖列」的正解：**面包屑＋可展开段＋摘要→明细**，`<details>/<summary>`＋粘性面包屑，保留上下文
3. **Real-Time Monitoring** — 用于「待解前瞻／门域外告警」：状态点、告警优先级色、最后更新时间

**字体（采纳 skill 推荐）**：**Fira Sans（正文）＋ Fira Code（数字/判据/ID）**，配合 `font-variant-numeric: tabular-nums`。理由：仪表盘/数据/技术，且等宽数字防列错位。
**配色（不采纳其推荐）**：它给的是蓝色亮色系（`#1E40AF` on `#F8FAFC`）——**与我们已成型暖暗色身份冲突**，硬换丢领域感。**保留** `--bg #14110c / --panel #1e1913 / --accent #e0a83c`，只**补全尺度并校验对比度 ≥4.5:1**。

## §3 布局架构（治「长竖列」）
- **容器分两类**：数据页 **1280px**（`.content--wide`）／表单页 **720px**（`.content--form`）——现行 860px 一刀切是 D1 的根因
- **主栅格**：12 列，`gap:8px`；断点 **375／768／1024／1440**（skill 检查清单要求四档）
- **审计页新信息架构**（替换现行三屏顺序下排）：
  1. **KPI 行**：6 格横排 —— 总题量｜已解真值｜合格池｜最难档｜待解前瞻｜**门域外**（一行看完，取代逐个下滚）
  2. **分层矩阵表**：**一张表 6 行**（层｜题量｜已解｜校准参考(带CI)｜基率｜引擎位｜gate）⇒ 点行**展开内联详情或右侧抽屉**；**取代** D2 的 6 张卡
  3. **告警栏**（右或顶部）：域外行数／积压／薄样本(n<100)／清单过期／快照 hash 异常
  4. 明细区：账本×判据版本表、gate 分布、分层校准汇总、待解前瞻 —— 全部**折叠或 Tab**
  5. **面包屑**：`审计 / 分层 / L3 · 短窗混沌`（drill-down 保留上下文）
- **窄屏**：表格转**卡片列表**且只留 3 个关键字段（skill `ux` 的 Table Handling 条目）
