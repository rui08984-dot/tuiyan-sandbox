# Spec: first-run-ux · 个人态首屏与首次回声

> 能力地图模块 id `first-run-ux` · 依赖：`runtime-paths` · 规模 2.2 人日
> 面向的是**陌生人打开的第一分钟**。这一分钟决定他留不留。

## Objective

让一个陌生人第一次打开时，看到的每一个数字都是**他自己的**，并且他记完第一道题、答完第一道题之后，**界面承认这件事发生过**。

**给谁用**：第一次打开、账本里 1994 条数据没有一条是他自己记的那个陌生人。
**成功的样子**：他打开看到「你还没有记过任何一道题」 ＋ 一个「记下第一道」按钮，而不是首页大字「294」。

## Code Style

复用现有的 `Term` 组件与 `api.ts`，**零新依赖**。形态照现有页面的做法：不另立一套设计语言。

## Testing Strategy

1. **空态分支**：全新访客 ⇒ 首页显示「你还没有记过任何一道题」；**断言那个 294 不出现**
2. **归属条常驻**：任何页面上都有一行说明账本里的数据是谁的
3. **回声三处各出现一次**：记 1 道 → 落定 1 道 → 复盘看到偏差
4. **★n<30 纪律不许被绕过**：R3 的最后半句「1 道题不构成结论」必须**始终**在
5. **反向锁**：喂一个 n=1 的已结算题，断言 R3 出现了但**没有**给「你偏乐观」这类结论

## Boundaries

- **Always**：空态必须给可点的下一步（只说空、不给按钮＝把用户晾在原地）；n<30 时只记条数不给比例
- **Ask first**：改任何已有页面的既有文案
- **Never**：给出「为你推荐下一步」式的引导（见下）；在 n<30 时给任何倾向性结论

## ★核心原则：引导「只指路，不判断」

作者在 `HomePage.tsx:67-73` 写死了正确的原则：

> 「任何『为你推荐下一步』式的引导都会撒谎——它会让人以为那 19 个薄格也是可读的。**欠账是事实，推荐是观点。**」

★**这条原则对「推荐」成立，但对「指路」不成立。原作者把两件事混为一谈了。**

| 它可以说 | 它不能说 |
|---|---|
| 「这一页是『记一笔』。① 上面写你要问什么 ② 中间选答案去哪里查 ③ 下面填你有多确信 ④ 点『记下』」 | 「建议你预测天气」「你可能擅长汇率」「类似题历史频率 21.3%」（← 这是**读数**，属 NotePage 自己的回执区，**不属引导**） |

**形态**：每个页面右上角一个可折叠 1 行提示条，`×` 关掉即永久不再出现，**不遮挡任何内容**。
4 步恰好是 `HomePage` 已有的三张动作卡——**引导只是把它们逐个点亮**，不新增导航结构。

## ★三个回声（现在一个都没有）

现状：落定后 toast 消失；`WhereOffPage` 在陌生人 0 题时是空态。
**他记完第一道题、答完第一道题，界面没有任何东西承认这件事发生过。**

| 触发 | 位置 | 改法 |
|---|---|---|
| **R1 记下第一道题** | `NotePage` 的回执 | 加一行：「**这是你的第 1 道题。{到期日} 回来回答一次，它才算落定。**」 |
| **R2 第一次落定** | `ResolvePage` 的 toast | 现文案「已落定：{题面前 40 字}」⇒ 改：「**已落定。这是你的第 1 道落定的题 —— 失分 0.XXX（永远答 50% 是 0.25）。去『我在哪儿偏了』看它。**」＋ 跳 `/question/:id` 的链接 |
| **R3 第一次有自己的偏差** | `WhereOffPage` 顶部 | 当该访客 ≥1 条已结算题：「你有 1 道已落定的题。它是**说大了 0.12**（你给 60%，实际 42%）。**1 道题不构成结论——记满 5 道再来比。**」 |

★**R3 的最后半句是纪律核心。** 项目现有门槛是 n<30（`auditKpi.brierCi`），而陌生人到 n=30 要几个月。
**首次回声必须诚实说明「1 道题什么都不说明」，否则这就是一个会骗人的产品。**

## ★与 resolve-queue 脱敏的协同（★不要覆盖掉那条红线）

`ResolvePage` 的「待你确认」块里含全部写键，而该端点**已在服务端对别人的桶整行脱敏**（见 `p1b/src/routes/disclosure.js`
与 `p1b/test/reveal-class.test.cjs` 的红线测试）。做 R2 时：

- **不得**为了「让回声更好看」而把 `others` 桶的题面重新取回来
- 页面侧 `bucket !== 'others'` 的渲染守卫**要保留**，服务端脱敏是第二道防线，不是唯一一道

## Success Criteria

- [ ] 全新访客打开首页 ⇒ 显示「你还没有记过任何一道题」＋「记下第一道」按钮，**294 不出现**
- [ ] 归属常驻条在任何页面都可见，写清账本里的数据是谁的
- [ ] `localStorage.clear()` 后能走完 4 步引导，每步只「指路」不含推荐
- [ ] R1/R2/R3 三处回声各出现一次，且 R3 的「1 道题不构成结论」半句始终在
- [ ] **反向锁**：n=1 的已结算题出现 R3 但**不出现**任何倾向性结论
- [ ] 0 题、1 题、5 题、30 题四个状态的行为都测到（n<30 一律只记条数不给比例）
- [ ] 零新依赖；四道闸门 exit 0

## Open Questions
