## §0 立题

**要回答的那一问**：账本里那 1700 道已结算题上，**按诚实基率 `assigned_prob` 决策**，
与**按 0.5 决策**，结果**有没有差别**。

**为什么现在问**：评审给技术 5.0 分，但项目至今**没有任何实验**测过这一问。
`docs/specs/对外口径-20260928.md` 已撤下「优于 0.2500」，改挂随机基线 `E[p(1−p)] = 0.226656`，
观测 Brier `0.225920` 落在其 CI `[0.219415, 0.232425]` 内 ⇒ **「不可区分」**。
「不可区分随机」**不等于**「不可区分 0.5」——后一问**至今无人测过**，而它才是「该不该用基率」的直接依据。
steel-manning 岗已承认：最强的反方论证是「不敢给数＝把可用的弱信号藏起来」，而它拿不出证据反驳。
本件就是去把那证据取出来——**取正取负都算交付**。

## §1 池（写死）

```sql
p.resolved_at IS NOT NULL
AND p.outcome IN ('true','false')
AND p.assigned_prob IS NOT NULL
AND p.assigned_prob >= 0 AND p.assigned_prob <= 1
AND <NOT_TRUTH_BASIS_DEFECT_SQL()>
```

- 泄漏防线①：**只读已结算题**（`resolved_at IS NOT NULL AND outcome IN ('true','false')`）。
- 泄漏防线②：**排除真值口径缺陷集**——**直接复用** `p1b/src/evidence/truthBasis.js` 的
  `NOT_TRUTH_BASIS_DEFECT_SQL()`，**禁自写一套谓词**（用户任务书点名；单一真源纪律）。
- `[0,1]` 越界行实测 0 条，规则写死只为「将来有行越界时不静默算进池」。
- `g2_regime` 全为 `R4` ⇒ **不加 regime 过滤**（无判别力的条件不进 WHERE）。
- ★`p` 的来源＝**账本写入时冻结的 `assigned_prob`**，本件**不重跑任何引擎、不重算任何 p**。
  这是「诚实基率」的定义位置；重算 p 会把「引擎今天能不能复现当时的 p」混进「当时的 p 有没有决策价值」。

## §2 判据一：校准性（C1）

**分档（写死）**：`pct = Math.round(p × 100)`（**整数百分点**），再落档——

| 档 | pct 区间 | 档标 |
|---|---|---|
| B1 | 0–19 | 0.1 |
| B2 | 20–39 | 0.3 |
| B3 | 40–59 | 0.5 |
| B4 | 60–79 | 0.7 |
| B5 | 80–100 | 0.9 |

- 「按整数百分点落档」是任务书原文。取整**在前**、落档**在后** ⇒ 边界唯一、浮点无歧义、
  五档**恰好铺满 [0,1]**，**不丢行**（`p=0.2` → pct 20 → B2；`p=0.8` → pct 80 → B5；规则本身定死，不留裁量）。
- 每档算：**实际发生率** `obs_b = mean(y)`、**该档 p** `meanp_b = mean(p)`（**档内均值**，非档标常数）。
- **加权绝对偏差** `WAD = Σ_{b∈合格档} (n_b / N_合格) · |obs_b − meanp_b|`。
- **C1 判据（写死）**：`WAD ≤ 0.02` ⇒ **基率已校准**；`> 0.02` ⇒ **未校准**。
- **MIN_N = 30**（沿用 `stage4-run.cjs` / `thickcell-replay.cjs` 既有口径，不新造阈值）：
  `n_b < 30` 的档**只作方向披露、禁入判读**，且**不参与 WAD 的权重归一**（`N_合格` 只累加合格档）。
  ⇒ 五档若全不合格 ⇒ C1 判为 **n/a（不出结论）**，禁「就近归档」。
- ★**旁挂敏感性（只披露、不据以判生死）**：另算一版 `WAD_档标 = Σ w_b·|obs_b − 档标常数|`。
  登记它的理由：「该档 p」有两种读法（档内均值 vs 档标），主判据取前者，**事前**把后者也摆出来，
  防事后挑对自己有利的那一版。**C1 的生死只由 `WAD`（档内均值版）决定。**

## §3 判据二：决策价值（★C2·本实验主判据·不许弱化）

**逐题配对差**（配对保留，同一题内两臂共享同一个 `y`）：

```
d_i = (p_i − y_i)² − (0.5 − y_i)²      # 负 = 按 p 更好
Δ   = mean(d_i)
```

- **C2 判据（写死）**：**Δ 的配对 bootstrap CI95 上界 < 0** ⇒ **基率有决策价值**。
  上界 ≥ 0（含 0）⇒ **不构成「有决策价值」的证据**（如实登记；**不得**改口说成「有趋势」当结论）。
- **bootstrap 口径照抄** `p1b/scripts/thickcell-replay.cjs` 的 `bootCI`：同一条 LCG
  （`s = (s×1664525 + 1013904223) >>> 0`）、**B = 1000**、**seed = 987654321**、
  百分位法 `q(p) = sortedMeans[floor(p×B)]`。**禁换种子事后凑结论。**
- **MDE 义务（写死）**：每次报 Δ 与 CI，**必须同报** `σ̂_d`（配对差样本标准差，n−1）与
  **`MDE ≈ 2.8·σ̂_d/√n`**。理由：不知道 MDE 就不知道「这个检验能分辨多小的效应」，
  CI 宽只说明精度不够，**不构成「无效应」的证据**。
- ★**walk-forward 的诚实处置**：`thickcell-replay.cjs` 的 walk-forward 服务于「臂要从历史里学东西」。
  本实验的**两臂都是常数函数**（`p_i` 是写入时冻结的账本值；0.5 是常数）⇒ **walk-forward 在此退化**，
  硬套只会造出一层没有信息流的壳。故本件把它落成**两条可执行断言**（禁写成口号）：
  1. **序无关性**：把入池行任意打乱后重算，`d` 向量**逐位相同**（常数臂不可能看见未来）；
  2. **时序单调零泄漏**：按 `resolved_at` 升序推进时，题 t 的 `d_t` 只由 `p_t` 与 `y_t` 决定，
     断言对 `t` 之后任何行的 `y` 做扰动，`d_t` **逐位不变**。
  同刻题（同一 `resolved_at`）互不影响——由断言 1 覆盖。
  ★**如实声明**：这是「该退化处的退化」，**不是**「跑了一次 walk-forward」。任何对外表述禁把它写成后者。

## §4 「禁跨层池化」的落地口径（★歧义处置·写死）

任务书同时要求「C1／C2 在全池上算」与「禁跨层池化」。两条并存即歧义，**事前**处置如下：

1. **全池读数是本实验被授权的唯一主读数单元**——因为本实验问的是「账本的 p 作为**一条决策规则**
   整体有没有价值」，这个问题本身就是全池问题。任务书对 C1／C2 的措辞（「1700 条」「对每条题」）
   也只有全池解。
2. **层是分组披露单元，不是可池化单元**。每个 `layer` 独立出 `n`／`Δ`／`CI`／`σ̂_d`／`MDE`／`WAD`，
   **各层独立判读**（层 `n<30` ⇒ 只作方向披露）。
3. **三条禁搬运**（写死，违反即本件读数作废）：
   - 禁把**全池**的结论说成**某一层**的性质（反向亦然）；
   - 禁把**层 A** 的数字**加总／平均**成「层的效果」，也禁用全池数**倒推**单层；
   - 禁**只报对自己有利的那一层**——五层**必须全列**（含 n<30 的方向披露行）。
4. C1 的分档（B1–B5）**是 p 的分档、不是层的分档**；WAD 跨层加权**只在 C1 一处发生**，
   C2 不用分档。分档结果同样受本条第 3 款约束：**不得**由 B1 的表现断言 B5。

## §6 旁证 F2（★任务书点名要核的独立事实·**不是判据**）

核「账本里 `assigned_prob` 与 `evidence.baseRate.p` 是否逐行相同」。

- 口径（写死）：在**全表**（不限已结算）逐行取 `evidence_json` 中**第一个**带
  `baseRate.p ∈ ℝ` 的元素；无此元素者单列「无 baseRate」，**禁**当成相等、**禁**静默丢弃。
- 同时报三档一致性计数：**位级相等**（`|Δ| < 1e-12`）／**≤1e-3 相等**／**≤1e-2 相等**，外加 `max|Δ|`。
- ★**如实性要求**：核出来是什么就写什么。**「不是逐行相同」或「只有部分相同」都必须原样报**——
  它会改变整个项目的结论（若 p 并非基率的机械复写，则「系统能力 = 基率」这条论断的前提要重估）。
- F2 **不参与** C1／C2 的任何判定，**不因结果好看或难看而调整判据**。
