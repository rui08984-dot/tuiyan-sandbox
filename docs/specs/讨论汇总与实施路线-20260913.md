### D6 · ACR 二期实测（2026-09-13 完成，¥1.01）
**cutoff 口径三类全 PASS**：A 改票 0.0875 / B 假声称 0.0850 / C 时序 0.0422（阈值 0.15）
**关键发现（修正队长口径）**：漂移由**喂给 LLM 的事件窗**决定，不是投毒本身——
- cutoff 窗（投票前，无结算泄漏）：0.0875 ✅
- **full 窗（含计票/终局，≈生产 see-all 口径）：0.6485 ❌（7 倍）**
→ **「LLM 判词对投毒稳健」只在 cutoff 窗成立**；生产若用 see-all 口径，一条改票投毒即打偏 P_vote ~0.65。
**诚实边界**：n=6 < n≥30 → 方向性信号非结论级；cutoff 的 PASS 落在噪声带内（效应 0.04-0.09 vs 地板 0.09-0.11），full 的 FAIL 是噪声 7 倍（方向可靠）。
**对产品的含义**：参谋卡运行时点（cutoff vs see-all）是**产品设计决策**，不只是实验结论。
**两层互补**：一期机械层（能检出）vs 二期 LLM 层（是否被带偏）——A 类最脆（机械层 100% 检出，但 full 窗 LLM 反而信它）。
