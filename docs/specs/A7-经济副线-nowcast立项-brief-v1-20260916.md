## 1. 一句话

把「经济月度值公布前的空窗期」变成可结算题型：用**已发布的高频信息**给**未发布的月度值**出一个当期读数（nowcast），并用非劣判据验证它不比「等真值」更差——**不承诺跑赢，只承诺不恶化**，两窗无增益即封存。

## 2. 为什么是现在（可行性已实测）

- 数据源：广域普查（`p1b/sim/out/sources-wide-probe2.out`）实测 **FRED（fredgraph.csv 免 key）／ECB SDW／CoinGecko（走代理）** 可达；dbnomics 线已在账（L2 主力域）。
- 题型天然存在：账本现有多个月度 kind（`dbnomics_series_value` 123 行、`eurostat_*`、`noaa_*_monthly` 等），**发布滞后**产生空窗期＝天然 cutoff 结构。
- 与既有口径无冲突：nowcast 的读数走「披露层＋影子评分」，不碰主账本判据。

## 3. 形态（桥接式）

1. **空窗层**：月值 M 的发布日 ≈ 月末＋滞后 L 天（各源 L 不同，逐源登记）。
2. **桥接变量**：同域高频（日/周）指标（汇率、利差、能源价、货运量等）在 [月末, 发布日) 窗口内的已发布读数。
3. **nowcast 读数**：固定规则映射（先验＝该序列历史季节性均值；桥接变量作证据行），规则文本进 PREREG、sha 冻结。
4. **结算**：真值发布后按二元化（照既有 L2 口径的阈值/分位）或数值口径结算。

## 4. 判据三件套（照 18②，冻结时逐字复核）

| # | 判据 | 阈值/形态 |
|---|---|---|
| P1 | **非劣** | nowcast 臂 vs 基线臂（季节均值）ΔBrier 配对 CI 上界 ≤ **+0.005** |
| P2 | **空窗层专判据** | 只统计「真值尚未发布且桥接窗口非空」的题（空窗层），避免被非空窗题稀释；样本构成与覆盖率须披露 |
| P3 | **两窗连败封存** | 连续两个评估窗无增益（CI 含 0 或方向为正） ⇒ 该源线**封存**（写死重开条件：新桥接变量或新发布日历） |

多重比较：primary 仅 P1；其余只描述（照项目惯例）。

## 5. 成本与排期

- 逐源发布日历登记：≈0.5 人日／源（首版 3 源：dbnomics-eurostat、fred、ecb）。
