## 0. 结论先行

### 一句话

**「升级成智能体」是一个把四件事混成一句的复合命题。它的两个子命题已被项目自己证伪，一个是真升维但幅度被高估，第四个（市场）的方向是反的——而三份独立评估收敛到的正确形态，与创始人设想的正好相反。**

### 子命题逐条裁决

| # | 子命题 | 裁决 | 依据 |
|---|---|---|---|
| **S1** | 「本项目已经是半个 agent」 | 范畴错误 | 5,156 条判词 / 53.4 万 token 实测 = **固定流水线里调用 LLM**（extract → confirm → advise，llm.js 两处固定调用点）。agent 的定义是「模型决定下一步做什么」。**而且恰恰是这个非 agent 设计救了项目**——矛盾比对在 engine.js 纯代码里做，不在模型里做 |
| **S2** | 「让 AI 自主驱动研判 / 入账 / 结算」 | 自我否定，且已被项目自己证伪 | 负结果账本 **D4「LLM 多智能体辩论主持」已判负三次**（0916/17/20 三版），理由：「文献轮空＋同质性（WC2026 四前沿 agent 92% 相同首选；单底座 λ≈1 无信息差）」；**H1 多路自主判词 Δ=+0.00299，CI 含 0**；H2 归因「LLM 判词未充分利用可用信号」；**5156/5156 判词写于结算之后**（平均滞后 1.5465 天）；verdictsStore.js:10-12 铁律原文「项目两次负结果均死于 LLM 直接输出数字——temperature=0 也只是稳定地错同一个数」 |
| **S3** | 「把现有能力封装成工具供 AI 调用」 | 真升维，但幅度被高估约 10 倍 | 与 ADR-003 同向。**但升的是「可被调用性」，不是「预测能力」**——它不产生新知识，只把锁在进程内的 689 行 evidence 变成可寻址资产。14 个只读工具 / 0 个写工具 / 3–27 人日 |
| **S4** | 「agent 化会打开市场」 | 方向反了，窗口关得更死 | 三大厂 memory 已 default-on；ChatGPT Tasks 免费档每天 1 次循环任务；**OpenHuman 免费开源、32k stars、10 万+ 用户**；**Metaculus Radiant open beta 免费、无需信用卡、明示「Start on your own」**。agent 化把成本曲线打到零，**没动需求曲线**——而这个项目的病根是需求曲线是平的 |

### 三个岗位独立收敛到的同一个结论（这是本报告最重要的产出）

三份互不通信的评估，从技术、数据、市场三个方向出发，**收敛到同一个形态**：

- **CTO 席**：「agent 只能站在这条线的哪一侧？站代码那侧（只调只读工具，提案待人 ratify）→ 纪律延伸；站模型那侧 → 纪律被绕过。」**工具清单：14 个只读，0 个写。**
- **数据席**：「唯一能让这个系统产生真实证据的，不是换一个更聪明的 p 生成者，而是一个能持续产生真·事前·可结算新题目的吞吐源。」**支持形态 (b)：agent 出题、人给概率。**
- **市场席**：「创始人设想是把项目做成 agent 给用户用。真正能卖的是把项目做成可信层，给 agent 调用。」

**交集是同一个东西：一个只读的、可验证的、别人（agent / 人 / 组织）可以调用来问「这道题配不配、这个结论可不可信」的判定层。它不是 agent，它是 agent 的约束条件提供方。**

而这个形态的不可替代性有一个精确的技术根据：

> 【事实 · OpenAI 自己写明】「Saved memories are stored separately from chat history. **Deleting the original chat does not automatically delete a separate saved memory.**」
> 【推断】**assistant memory 是可变、可删、带损、非承诺的。** append-only + 机械抽取 + 不可改结算的账本，**在语义上无法构建在 assistant memory 之上**。这是唯一一块「免费替代品做不到」的地方——也是唯一可能收费的地方。

## 1. 第一性原理：剥掉「agent 化 = 升级」这个惯例假设

这个假设偷换了两个东西。

### 1.1 它假设 agent 化创造需求——它没有

agent 化改变的是**服务的边际成本**。把成本从 5 美元/月打到 0.05 美元/月，在一个「用户根本不来」的市场里，等于**把卖不出去的商品变得更便宜**。

上轮 GJ Open 的 70 个活跃预测者，是**需求**的测量值。agent 化只动供给侧的**成本**。**成本归零不创造需求，它只是让「没有收入」这个结果来得更快、更彻底。**

而且：一旦你的通用版本能被别人免费做，差异化版本就必须**比免费版更值钱**才能收费——而本项目对用户的可见体验（「agent 问你一个问题，然后告诉你你错了」）比 ChatGPT 做同一件事**体验更差**（冷、慢、不讨喜）。付费理由是负的。

### 1.2 它假设「本项目已有可被放大的智能」——没有

| 被假定的约束 | 分类 | 实测检验 | 结论 |
|---|---|---|---|
| 当前能力不足，所以要升级 | 惯例 | **当前能力实测为零**：p ≡ baseRate 配对差 +2.95e-5；真值与 Bernoulli(p) 不可区分（CI 含 0） | **没有可以升级的 0** |
| 当前有可被智能体放大的资产 | 惯例 | 450/1994 = 22.6% 绑死在自家模拟器；1,542 条是公开 API 序列的阈值问句 | **没有独占数据可放大** |
| 瓶颈在决策 | 惯例 | 瓶颈在时间：真前瞻 372 条、跨 4 个建题日、72 个事件日 | **智能体提高决策速度，约束是日历** |

### 1.3 剥完之后剩下的基本事实

- **F1** 系统的唯一功能：产出一对 (statement s, probability p)，稍后产出 truth y。
- **F2** 实测 p 是历史基率的机械复写（1308/1308 within 0.001，503 行位级相等），y 的分布被构造性地钉在 p 上 ⇒ E[Brier] = E[p(1-p)] = 0.2300，实测 0.2349，不显著。**因此系统的预测能力 = 0。实际资产 = 记账纪律 + 取数管道 + 拒收门 + 结算器。**
- **F4** 真瓶颈 = 真前瞻样本量。372 条，16 天。且只落在 4 个 created_at 日、72 个事件日、393/571 集中在 2026-09 ⇒ **有效自由度远小于 372**。
- **F5** 真风险 = 对 LLM 自由裁量的防御。11 条预注册假设全负，多条死于 LLM 路线。
- **F6** 出题速度过剩 30 倍（单秒实测 448 条），结算过剩 30 倍（daemon 每 60 分钟一轮）。**⇒ agent 化对前瞻样本量增速的直接贡献 ≈ 0。** 瓶颈是 lead time（日历）与域多样性，两者都不是 LLM 能压缩的。
- **F7** 16 小时数据层零推进，新增 4 份评审/口径文档 + 3 张空表。**⇒ 当前投入产出的边际在【文档与纪律】，不在【数据】。**

## 2. Steel-manning：反对 agent 化的最强论证

### 2.1 反方最强版本

> **反方论点（最强形式）**
>
> 这个项目的全部价值主张可以压缩成一句话：**它能在结果出来之前，把概率记下来，并事后诚实结算。** 这是预测科学里唯一不可被规模替代的东西。
>
> 现在它有 1,994 条题，但**其中 0 条来自真人在真实关心的事情上**。也就是说：**它证明了自己"能记账"，但从未证明"有人在用"。**
>
> 面对这个事实，只有三条路：① 继续写文档（本轮 16 小时的实际产出）② 等真人（analytics 三张表 0 行，埋点刚建，端点还没接）③ **用 agent 去产生"行为"**——让 agent 扮演提问者，去问那些真人不问的问题。
>
> 反方必须承认：第 ③ 条是唯一能在**没有真人**的情况下让这个系统产生"非自证数据"的路径。因为一旦有了外部 agent 作为提问者，**出题与给概率就分离了**——这正是形态 (b)。
>
> **反方最强的一击在这里**：本项目当前"零真人的 0 用户状态"不是 agent 化能解决的，但 agent 化至少能让"提问"这件事第一次发生。1,994 条题里没有一条是"有人想知道答案"生成的。

### 2.2 反方会在什么条件下赢

| 条件 | 检验方法 | 当前状态 |
|---|---|---|
| W1 agent 产物仍不来自任何外部需求 | 看 agent 题里有多少能被独立的"这个题有人关心吗"信号验证 | 无此类信号 |
| W2 agent 出题没引入新信息源，只是重排已有 44 个域 | 数 agent 题的 resolve.kind 与现有 52 个的重合率 | 【实测】现有只用 44 个 game_type / 52 个 resolve.kind |
| W3 agent 的概率仍等于基率（自主增量率 = 0） | M7a 指标 | 【实测】当前 100% 等于基率 |
| W4 若不加 G3 判词时序闸，agent 会重演 5156/5156 全部事后泄漏 | 查 verdicts.created_at ≤ resolved_at 比例 | 【实测】当前 0% 满足 |
| W5 若 intake_rejects 仍不落盘，拒收率永远测不出来 | 查表行数 | 【实测】0 行 |
| W6 90 天内真前瞻 n 仍 < 1000 且域 < 15 | 查 MDE | 当前有效 MDE 约 0.04 |

### 2.3 我的回答：反方赢的是「agent 化 = 升级」这个版本

**明确站队**：
- **反对**把 agent 化当作「能力升级」。它不是。没有可以升级的 0。
- **反对**形态 (a) agent 出题 + agent 给概率、以及形态 (c) 人出题 + agent 给概率。这会直接违反项目用两次负结果换来的铁律，且把自证幅度从 0.02~0.21 推到不可控。
- **有条件支持**形态 (b) agent 出题、人给概率，**且必须同时满足四道机械闸**（见 §4）。

**为什么这不是骑墙**：我反对的是命题的默认形态（a/c），支持的是一个具体且受限的形态（b + 四闸），并给出了可证伪的判定实验（SELF-CONF-3ARM）与数值判据（M7a = 0 则封存）。**「不做」和「照原样做」我都不选。**

## 3. 唯一真正的新能力：不可判定性地图

三个岗位收敛出的形态，落到具体能力上只有一件事值得做，而它恰好是项目六层分类里 L4（自反）/ L5（不可约）/ L6（对抗）**一直想做但没做成**的事：

**让 agent 持续尝试出题，把「出不来 / 出不来 / 还是出不来」这件事本身积累成资产。**

| 步骤 | 谁做 | 机械判据 |
|---|---|---|
| agent 提出题面 + 候选锚 | agent | kind.propose 工具；提案落不可变文件 + sha256 |
| 判定这道题配不配 | **代码**（anchor-gate + labBoundary + leak-scan） | Q0-1/2/3 三问；判据不依赖 LLM |
| 不可达则记为一条元数据 | 代码 | intake_rejects 必须落盘（当前 0 行） |
| 长期累计 | — | **「哪些事根本没法预判」的地图** |

**为什么这是唯一值得做的**：它把 agent 化从「提高预测能力」（已证伪）转成「**测绘不可预测性**」——而后者是企业决策咨询里最贵的报告（「这件事能不能预判」），也是六层分类体系的原始目的。

**但必须诚实**：市场席已判定，企业 AI 预算里**决策日志不是独立采购项**（McKinsey 2026：40% 大型组织已规模化 AI agents，但这笔钱流向客服/编码/销售/运维）。所以**不可判定性地图不能作为产品卖，只能作为咨询交付物嵌入。**

## 4. 目标架构：14 个只读工具，0 个写工具

### 4.1 切分原则（从项目自身推导，不是行业惯例）

1. **可判定性判据即权限判据**：能被代码唯一裁决的（gate / dueOf / Brier / cutoff / 泄漏）→ **工具在 agent 之外，代码是唯一裁判**。
2. **不可逆即禁入**：写入真值 / 概率 / 门状态的工具，**永不进 agent 工具集**——不是「加确认」，是「不可见」。
3. **可复算即必须确定性**：凡参与 PREREG 复算、anchor-gate 复算、Brier 口径的工具，必须纯函数、零 LLM、零网络。leak-scan.test.cjs:51-57 已有零写库锁，**这是现成范式，直接照抄**。

### 4.3 三道必上的机械闸

| 闸 | 位置 | 判据（不依赖 LLM） | 现状 |
|---|---|---|---|
| **闸 1 · 权限闸** | 进程边界 | agent **只能读 predictions_public 视图**（唯一有内核级强制的面）；**不得拿到 db 连接** | 项目已有 process_roles 表（4 行）但 **enforcement 一律 contract，作者自陈「禁把它读成内核隔离」**；且 process_roles 的消费方**只有测试**，无运行时组件执行它 |
| **闸 2 · 时序闸 G3** | 判词写路径 | verdicts.created_at ≤ predictions.resolved_at，硬拒绝 | **当前 0% 满足。** 加上它会一次性作废 5,156 条——**这是决定性分界线，没有第三条路** |
| **闸 3 · 确定性闸** | 注册表 | 可被冻结的工具 = 纯函数 + 确定性排序 + 零时间依赖；prereg-freeze 加「复算两次一致」自检 | 缺失。**agent 生成的产物若带时间戳/随机种子，PREREG 制度对该 run 失效**——这是唯一会摧毁本项目核心资产的失败模式 |

**闸 1 的具体威胁**（红队可打穿）：predictions_public 视图对「另一个进程」有效，对「同一进程内的另一个模块」**完全无效**。llm.js:268 把 rawText 裸拼进 user 消息、无分隔符标记；agent 形态下这段玩家原话会进入 conversation history，agent 可据其选工具。**若 ledger.resolve 在工具集内，等于真值可被对局参与者写入。**

**闸 1 的正确解法是进程级分离，不是注册表里加个 readonly 字段**——scripts-require-safety.test.cjs 的存在已经证明君子协定在这个项目被绕过了 121 次。

### 4.4 运行时选型

| 选项 | 裁决 | 依据 |
|---|---|---|
| **内部 function calling** | 采用 | **零新增依赖**：项目已在用 OpenAI 兼容的 /chat/completions，function calling 只是多一个 tools 字段。**唯一一个「用已有栈、不加一行新依赖」就能做的选项** |
| **自建 tool registry** | 采用（必做） | 它和「是否给 LLM」正交。真正干活的是这张表（谁可调/写不写库/失败模式），不是协议。约 150–200 行，**且它是「物理分离」红线的载体** |
| **MCP** | 推迟 | ① 要再起一个传输层，而项目已有 Fastify HTTP 面；② 需引 SDK，违反零新依赖铁律；③ **真正的收益是「让外部 agent 能调我们」——但这需要至少 1 个真实外部消费者才成立，而目前消费者数 = 0。** MCP 是分销决策，不是架构决策 |
| **Skill 文件** | 降级为文档 | **Skill 是 prompt，不是能力边界。** 它能「告诉」模型别做某事，不能「禁止」模型做。**任何纪律都必须是代码，不是 markdown** |

> MCP 是「我们要不要让别人来调我们」（商业，ADR-003），function calling 是「我们要不要自己调别人」（工程）。**前者等外部需求，后者现在就能做。混着谈会把一个 1 人日的工程决策拖成 3 个月的分销决策。**

## 5. 自证幅度：一个可以现在就量出来的数字

这是数据席贡献的最有价值的一条，因为它把「agent 化会不会自欺」从哲学问题变成了工程问题。

**用本项目自己的三组数，直接量出「评估器与预测者共享状态导致 Brier 低估多少」：**

| 评估器 | 是否共享真值侧状态 | 评估器 Brier | 虚低幅度 | 证据 |
|---|---|---|---|---|
| L1 proc_calc 引擎 | **完全共享**（读同一张 events 表） | 0.0000（引擎重放口径） | **−0.2115** | 对比账本 p 的 0.2115 |
| v1_evidence 判词臂 | **事后共享**（100% 晚于结算） | 0.1649（L6 单层） | **−0.105** | 对比 v2 0.2696 / v3 0.2554 |
| v2_skeptical / v3_baserate | 只看题面+基率 | 0.2696 / 0.2554 | — | 实测 |

**⇒ 本项目的实测自证幅度是 Brier 低估 0.02 到 0.21 点。全共享 = 0.21（完美预测），事后共享 = 约 0.10。**

**而这立刻给出一个免费、零等待、可证伪的判决实验：SELF-CONF-3ARM**

| 臂 | agent 可见输入 | 隔离机制 | 预期 |
|---|---|---|---|
| **A · 盲** | 只有 statement | 网络出口白名单为空 | Brier 约 0.26–0.27 |
| **B · 截止日** | statement + evidence_json[0] | 白名单只放 archive 源，不放 future 源 | 0.23–0.25 |
| **C · 全知** | A+B + events 全表 + truth_vault | 无 | 低于 0.16 |

**关键指标：Δ(C − A) 就是自证幅度。** 参照系已实测：0.105。数据源是现成的 1,700 条已结算题，**不需要等真值，0 天等待**。

**判据必须先冻结（照 PREREG 范式）：Δ(C−A) ≤ −0.05 ⇒ 该 agent 架构判不合格，其全部 Brier 读数永久封存。**

**这是本报告给出的唯一一个「跑完就能对 agent 化下判决」的实验，它的 ROI 高于任何架构改造。**

## 6. 成本与盈亏平衡

**实测（llm-usage.jsonl 逐行统计，534 条）**：prompt 304,498 + completion 777,194 + cached 21,696 = 1.08M tokens；**completion 是 prompt 的 2.55 倍**。

**⇒ 本项目的钱在输出不在输入。** 所以「agent 循环会不会因重发上下文而烧钱」这个担心**对本项目是次要的**，主要成本是 agent 自己的推理与工具输出。

**单次工具循环成本模型**（B = 基线上下文，N = 迭代轮数，C = 每轮新增）：

    无缓存：N·B + C·N(N+1)/2 + N·C_out    （随 N 二次增长）
    有缓存：N·B + N·C + N·C_out            （线性）

代入实测（B≈4,000，N=10，C≈300，C_out≈500）：**agent 循环单次成本约为现有管线的 25–30 倍，不是 100 倍**——因为本项目输出重、输入轻，恰好避开了最坏情况。

**盈亏平衡的正确提法不是「每天跑多少题」，而是「单个新 kind 要不要用 agent 起草」**：
新源接入人工成本 1.5–3 人日 = ¥600–2,400/kind。

| agent 迭代次数 / kind | 成本 | 需要的「无 review 失效率」回本点 |
|---|---|---|
| 1 run | ¥435 | 人工 review 省 18–82% 时间即回本，**划算** |
| 3 run | ¥1,305 | 需省 54–100% 时间，**临界** |
| 10 run | ¥4,350 | **不可能回本** |

**⇒ 盈亏平衡的唯一杠杆是「每个新 kind 的 agent 迭代次数」，不是题量。** 唯一该投的工程是「收敛迭代」（工具返回值限 2KB + 给模型看失败原因而不是让它试错），而不是「多做题」。

## 7. 市场：窗口不是打开，是关得更死

### 7.1 逐环拆解「agent 帮我记账 + 定期提问 + 自动结算 + 偏差画像」

| 环节 | 谁已免费覆盖 |

| 本地部署 + 长期记忆 + 多 agent 编排 | **OpenHuman：免费开源、32k stars、10 万+ 用户、1B token 记忆、118+ 集成** |
| 记忆基础设施 | Mem0（开源）、Zep（Flex $125/月、Flex Plus $375/月） |
| 概率预测本身 | Metaculus 免费；**Radiant**（多预测关系图谱，open beta 免费） |

**⇒ 五个环节全部有免费或低价在位者。agent 化把可竞争维度从 1 个变成 4 个，每个维度的价格都趋近零。**

### 7.2 最高威胁的新竞品：Metaculus Radiant

- **定位**：面向战略决策者的网络化预测工具，"a networked forecasting tool for strategic decision-makers"
- **价格**：**open beta 免费 credits，无需信用卡**
- **规模**：母体 434 万次预测 / 25,516 题；Metaculus 是 **Public Benefit Corporation**
- **它自己的话**："Start on your own, or bring us a real decision"——**明确开放给个人起步用户**
- **威胁**：**对本项目 B2B 方向的正面对撞，且对方免费、有真人超级预测者网络、有 20 万级历史校准数据、有品牌。本项目无任何一项对等资产。**

### 7.3 唯一的楔子，和它的定价逻辑

**能卖的不是「记得你」，是「你无法反悔，而且第三方能验证」。**

技术根据：assistant memory 是可变、可删、带损、非承诺的（OpenAI 自述 memory 独立于聊天记录存储、可单独删除）；append-only + 机械抽取 + 不可改结算的账本**在语义上无法构建在其上**。

**定价建议**：不要给「个人 agent」定价。若给「可验证账本」定价，锚点取 Zep Flex Plus 之下、Gong 之上，按 **$30–80/席位/月** 的 B2B 合规工具区间报，且**必须搭售**进已有企业预算（审计/合规/AI 治理），不能独立立项。

**决策规则（可执行）**：**在 Radiant 公布收费价目之前，不投入 B2B 销售。** 把 Radiant 价格页纳入季度监控。

### 7.4 kill test（最便宜的证伪检查）

**去 radiant.metaculus.com 注册，用它把自己的一个真实决策跑一遍，问自己：「如果 Radiant 明天收费，我付多少？用本项目的 agent 化版本，我能多出 Radiant 做不到的哪一条具体动作？」**
- 若答案里出现的是「我的数据不外传 / 我的预注册有哈希链可验证 / 我不需要登录别人的社区才能用」——**楔子存在**。
- 若答案是「我能问它更多问题」——**楔子不存在，立即停。**

### 7.5 时点红利是真的，位置红利是假的

【事实】The Economist（2026-09-16）：AI 首次赢得 Metaculus 季节 Cup。但**同季 FutureEval 人类 Pro 队仍以 1.25 分胜出（p=0.247，不显著），个人榜前十 9 席为 Pro**；而 2025 Q2 时 bots 还输 20.03 分。ForecastBench 官方外推 parity 时间为 2026 年 11 月。**Metaculus 自己的 11 篇分析综述警告：很多「bots == 最优人类」的说法用了已结算题目的回测，方法学存疑。**

**⇒ 「AI 赢杯」≠「AI 追平人类专家」。** 杯赛是混合榜，Pro 对战是精选人类专家队。**外部媒体正在大量传播前者——禁止在对外材料中单独引用。**

**同一个时点红利，被 Metaculus 用 Radiant 免费领走了。**

## 8. 合规增量：agent 化让红线更紧，不是更松

### 8.1 AI 生成合成内容标识办法（2025-09-01）——上轮结论需要修订

上轮判定「目前不适用」。**agent 化会直接触发它**，因为三个标志性能力全部落在射程内：自动生成题面 / 自动生成校准报告（周期性自动发布，频次更高）/ 生成建议理由。

**红线建议**：agent 生成的任何面向用户的文本，必须在**生成时即写入元数据隐式标识字段**并做可见角标。**不能「以后要发布再说」**——agent 输出自动流向用户，事后补标识技术上不可行（无法回溯生成时刻）。**这是 agent 化引入的全新工程义务，架构第一天就要定。**

官方说明对数字水印「不作强制要求」，改以**文本符号标识 + 文件元数据标识**落地——**这两条是硬要求**。

### 8.2 爬取与博彩：agent 化把「人做一次」变成「机器做一万次」

**这是 agent 化最被低估的风险。** 三个维度同时恶化：
1. **「避开或突破安全保护措施」成为默认行为**（刑事认定要件），因为 agent 要稳定抓取必然对抗反爬；
2. **主观故意难以主张**——用户可以说「我让 agent 去看看」，但日志显示的是系统在自动做；
3. **一旦涉及「投注建议/信号输出」**，从数据行为升级为经营行为。

**四条红线建议（写进代码，不写进提示词）**：
1. agent **只允许白名单数据源**，禁止任何绕过反爬的路径；SSRF 白名单化；
2. agent **永不输出投注建议、推荐、信号、必胜、「值得下注」等语义**。输出一律限定为「市场价格概率」这一事实性描述，UI 固定标注「市场共识，非投资/博彩建议」。**理由不只是合规：FT 2026-07 引用的结论本身就说明 AI 在博彩类预测上尚无 edge——给建议既无价值又有法律风险。**
3. agent **不得代替用户执行任何需要账号/资金的写操作**；
4. agent 生成的所有用户可见文本，**元数据隐式标识在生成时写入，不可延后**。

## 9. 顺序是硬约束，不可交换

## 最后

**技术席的一句话**：agent 化**是一次边界重画，不是一次能力升级**。本项目现在有两条边界——代码/LLM、人/脚本。agent 化会引入第三条。而这个项目全部的稀缺性都建立在同一条纪律上：**可判定的交给代码，不可判定的才交给模型，且模型的产物必须过机械门。** 所以 agent 化的真实内容只有一个问题：**agent 站在这条线的哪一侧？**

**数据席的一句话**：这个项目现在最缺的不是更聪明的预测者，是**真问题和真时间**。agent 能造出「像问题的东西」，造不出「真被问的问题」，也造不出「日历」。

**市场席的一句话**：agent 化让这个项目**更值得做**，但没有让它**更好卖**。时点红利是真的，位置红利是假的——Metaculus 用 Radiant 免费领走了同一时点的同一位置。**如果一定要 agent 化，应该 agent 化「别人」，不是「服务自己」**：让本项目的纪律成为 agent 可调用的可信层，卖给那些要向审计方证明「这个决定不是 AI 编的」的企业。

**我的裁决**：**不要以「升级成智能体」作为下一步。** 以「把可信层开放给 agent 调用」作为下一步——方向相反，成本只有它的三分之一，而且它是唯一有免费替代品做不到的语义。
