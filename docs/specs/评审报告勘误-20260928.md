## 一、必读的一段话

原报告的**结论我认同：不建议投，方向站得住**。它的技术部分已被独立核实为准确，
C 段（市场）与 D 段（技术）的事实密度、对「零来源就敢下断言」的克制、以及它自己
承认「我承认 0.2 分 / 我承认代码质量高于均值」的那种分角色、分歧点不强行统一的写法，
都是这份报告真正值钱的部分。

但**这份报告不能原样拿去跟投资人谈**，理由有两条，性质完全不同，必须分开处理：

**第一条：它的商业结论建立在零来源的外部证据上。**
报告全文 **0 个 URL**。而「不建议投」这个结论压在三根外部支柱上。我这次把三根都查了：
一根的**来源被写错了**（不是机构口径，是 2015 年一条匿名用户评论），一根的**核心数字
被反例推翻**（存在一个 117 star 的同构实现，不是「全部 0–2」），一根**依然没有找到
反例**（无可核实的个人订阅付费先例）。也就是说，结论虽然碰巧还站得住，但它现在**没有
举证能力**——任何一位认真的投资人都只要点开三个链接就能问倒它。这不是学术瑕疵，是
尽调事故。

**第二条：它自身有 36 处算术与口径矛盾。**
不是笔误级别的：I 表加权总分算错、C1 的 TAM 差一个数量级、SAM 与自己的公式差 2 倍、
E2 的回本周期三档全部推不出来、E1 的 LTV 有 12 倍量纲错（**错的方向是对它自己有利**，
修正后 LTV/CAC 从「看似 >1」变成 0.16–0.43）、E3 只有一档情景可复现。E1/E2 两节是
全报告商业论证的承重墙，这一节的数字经不起投资人当场拿计算器按一遍。

**但请注意：以上两条里，没有一条要求翻结论。** 见第四节——修正后加权分 2.425，
在最宽松的合理重赋权下也不超过 2.46，而报告自己那两项硬约束（市场 1.0、商业 0.5）
不但没被推翻，其中「市场」这一项反而**应该往上动一点**，因为支柱②被反例推翻了。
**报告把项目说小了，不是说大了。** 这正是它能拿去谈的前提。

**技术部分（D 段 + ADR）我一条没动**，按交接说明它已被独立核实为准确
（gate='scored' 0 行、0.0.0.0 + 反射 CORS + 零鉴权、scripts 绕过路由、
3 处 UPDATE 且 409 只护 resolve——四条逐字命中）。本勘误只查商业 / 市场 / 评分 / 算术。

这两项不只是不变，**它们是唯一真正卡住分数的东西**。
市场 + 商业合计只贡献 0.225 / 2.425 = **9.3%** 的分数，其余 2.2 分全部来自
技术 0.75 + 团队 0.50 + 护城河 0.30 + 时机 0.20 + 产品 0.375 + 融资 0.075。
**报告写得越好，这个结构越明显**——这也是为什么「不建议投」这个结论对算术修正免疫。

**对两项硬约束做压力测试**（每一项都是本勘误查出来的问题所允许的最宽松重赋权）：

| 情形 | 依据 | 加权总分 |
|---|---|---|
| 报告写的 | — | 2.50 |
| **仅算术修正**（采信值） | 第 1 条 | **2.425** |
| 商业 0.5 → **0.25** | 第 6/11/14 条：回本周期推不出、正确量纲下 LTV/CAC = 0.16–0.43 | 2.3875 |
| 市场 1.0 → **1.25** | 第 3 节支柱②：`Noisyxl/brier` 117 star 部分推翻「同构实现全部 0–2」 | 2.4625 |
| 商业 0.25 **且** 市场 1.25（同时放松两项） | 同上两项叠加 | **2.425** |
| 市场 1.0 → **1.5**（支柱②被推翻后给足） | — | 2.50 |
| **极端检验：只把「市场」给 10 分，其余七项不动** | 不现实，但用来测天花板 | **3.775** |

**读法**：无论采信哪一套合理重赋权，分数都落在 **2.39 – 2.46**（报告写 2.50），
距离任何 VC 门槛（通常 6.0 以上）都差一个数量级。
**即使把市场分从 1.0 一路加到 10.0，总分也只有 3.775。**
这就是为什么本勘误的 36 条修正**没有一条要求翻结论**。

**必须同时记下的两点**：

1. **方向**：本勘误查出的商业侧错误（#11 的 12 倍量纲错、#14 的 LTV/CAC）修正后
   **让项目更差**，不是更好。而市场侧的唯一反例（`Noisyxl/brier`）**让项目略好**。
   两者不同向，净效果是分数基本不动。**报告把项目说小了，不是说大了。**

2. **商业 0.5 这一项现在守不住了，但不该由我改**。E2 的回本周期三档推不出来、
   正确量纲下 LTV/CAC 是 0.16–0.43——这两条都指向「商业」项应当**下调**。
   但报告的 I 表「商业 0.5」是委员会的整体判断，**本勘误只指出其算术依据不成立，
   不代替委员会重打分**。同理，「市场 1.0」在本勘误给出的证据下有**上调**理由
   （支柱②被推翻），但支柱①来源是 2015 年匿名评论、支柱③我也没找到反例，
   **两项硬约束作为上限仍然有效**。**把这两项的重打分留给原委员会，本勘误不越权。**
