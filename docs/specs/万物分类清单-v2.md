# 万物分类清单 v2（checklist_hash=v2 · 冻结 2026-09-12）

> 万物可预测性审计器的判据核心（设计=docs/specs/2026-09-11-万物可预测性审计器-design.md §1）。打印即可人工使用：对每个候选题，先过拒收门，再按顺序过六层清单，首个全绿层=归属层。**修订规则**：本清单任何改动=新版本号（v3/v4…），不回填旧题；账本 checklist_hash 记录所用版本。
> **v2 修订点（对 v1 的增量，其余条目逐字沿用 v1）**：①拒收门增 Q0-3（恒定结果拒收，reason=tautology——S1 B3①裁定，堵「首夜平安」类重言题入库）；②L3 第 2 问二元化（衰减比 ≥1.5 倍或公开文献载明时界→是；无数据→未知降 L2——预注册阈值 1.5，可被首批数据校准）。v1 全文保留不动（docs/specs/万物分类清单-v1.md）。

## 第 0 步 · 拒收门（三问，任一「否」=拒收不入账本）
- Q0-1 resolve 时点是否存在**可机检或第三方可复核**的真值锚？（是/否；否→拒收 reason=no_anchor）
- Q0-2 判据冻结（cutoff）是否早于事件的决定性时点？（是/否；否→拒收 reason=leak）
- Q0-3 **结果是否随实例变化？恒定即拒收**（是=随实例变化/否=恒定；恒定→拒收 **reason=tautology**）——一夜狼「首夜平安（无人死亡）」类命题恒 false，属规则重言式而非可预测性问题，v1 期 30 条已按 tautology=1 标记隔离（predictions.tautology 列），v2 起源头拒收不再入库。

## 第 1 步 · 按序判定（L5→L6→L1→L3→L2→L4，首个全绿层即归属；混合题记 secondary_layer）

### L5 不可约随机（3 问全「是」）
1. 结果由认证随机源产生（认证 RNG/物理抽奖/量子源，机制可查）？
2. 不存在任何公开渠道的信息优势路径？
3. 题面无统计学偏倚可利用（有偏倚→归 L2）？

### L6 对抗（4 问全「是」）
1. 结果由利益相反的智慧主体的决策直接产生？
2. 对手能观测我方历史预测/策略模式并调整？
3. 策略空间开放（不可枚举全部打法，纯基率会因对手适应而失效）？
4. 存在「声称与真实意图可分离」的伪装结构？

### L1 决定论（4 问全「是」）
1. 状态空间有限且完全可枚举？
2. 转移规则完全已知且无隐藏随机源（同一状态必得同一后继）？
3. 任一观察者仅凭公开状态即可推演结果（信息完全）？
4. resolve=程序可复算（引擎跑一遍即真值，无裁判裁量）？

### L3 短窗混沌（4 问全「是」；第 2 问按 v2 二元化口径）
1. 存在已知或可近似的演化机制/模型？
2. **预测窗口显著短于该系统的可预测时界？（v2 二元化：历史同型方法命中率衰减比 ≥1.5 倍，或公开文献载明该系统时界→「是」；两者皆无数据→「未知」降 L2；本阈值为预注册阈值 1.5，可被首批数据校准）**
3. 有实时观测流可在窗口内同化？
4. resolve 落在窗口内？

### L2 系综（4 问全「是」）
1. 题面定义于稳定可重复的总体（同分布假设可写进判据）？
2. 存在 ≥30 条同类历史结果可查？
3. 单事件不可由现有信息决定性推出（但频率稳定）？
4. 存在外部统计源可作基率锚？

### L4 自反（3 问全「是」；叠加层语义：primary=按上文判定的底层，secondary=L4）
1. 结果由人类决策直接产生，且决策者可能接触本预测或同类预测？（同时记录本预测是否计划公开→public_exposure）
2. 存在反馈回路（预测→行为→结果→后续预测）的历史证据或机制描述？
3. 无法归入 L1-L3/L5？

## 走通示例（v2 冻结版口径）
题：「2026-09-12 上海最高气温 > 35°C 的概率？」
拒收门：Q0-1 真值锚=气象台官方日数据（是）；Q0-2 cutoff 冻结早于当天结束（是）；Q0-3 结果随实例变化（每日气温不同，是）→ 进判定。
L5：非认证随机源（否）→ L6：无对抗主体（否）→ L1：大气非有限枚举（否）→ L3：①数值天气模式存在（是）②v2 二元化口径：历史 24h 命中率相对 7 天命中率衰减比需查气候统计——公开文献载明数值天气确定性预报时界≈2 周、24h 窗口显著短于时界（是，文献口径）③地面站逐时观测流（是）④resolve 在窗口内（是）→ **归 L3**。
落库：layer=L3，engine=aci，gate=descriptive，checklist_hash=**v2**。
反例（v2 新增拒收示例）：「一夜狼本局首夜平安（无人死亡）」——Q0-3 一夜狼版型必有刀，命题恒 false，结果不随实例变化（否）→ **拒收 reason=tautology**，不入账本。

## 版本与修订
- v1（2026-09-11 冻结）：初版六层清单+拒收门（两问）。清单修订走 v2，不回填旧题。
- **v2 增补注记（2026-09-12，非判据改动，不升版本号）**：历史回填（backfill）题适用**同一套 Q0-1/Q0-2/Q0-3 拒收门**，无豁免。特别提示：
  · **Q0-2 对 backfill 题的判定口径**：cutoff 必须=**事件发生的**前一天（如问 2024-09-15 天气 → cutoff=2024-09-15 前），**禁止以「今天（落库日）」为 cutoff 去问历史事件**——该情形属 leak，拒收。
  · **Q0-3 对 backfill 题**：历史基率须落 (0.15, 0.85)，越界组合不产题（实测反例：上海 9 月 >35℃ 基率 0.01 → 拒收）。**禁止一套阈值跨十年/跨城市复用**，须逐组合标定（照 §6.4 阈值重标定纪律）。
  · **G2 口径见审计器 design §4.1 修订 R3**：backfill 题计入可判定率/判据争议率，**不计入「月 resolve ≥30 连续 2 个月」**达标判定（该指标测持续产出能力）。月报分列 realtime/backfill 两窗。
  · 本注记为**登记性说明**，未改动 v2 任何判据条目；若后续需调整判据本身，按修订规则升 **v3** 并冻结。

- **v2（2026-09-12 冻结）**：拒收门增 Q0-3（恒定结果拒收 reason=tautology）+L3 第 2 问二元化（衰减比阈值 1.5 预注册，可被首批数据校准）；依据=S1 B3①/B6 + 批次 2-M1 任务书。v1 全文保留不动。
