# 万物分类清单 v1（checklist_hash=v1 · 冻结 2026-09-11）

> 万物可预测性审计器的判据核心（设计=docs/specs/2026-09-11-万物可预测性审计器-design.md §1）。打印即可人工使用：对每个候选题，先过拒收门，再按顺序过六层清单，首个全绿层=归属层。**修订规则**：本清单任何改动=新版本号（v2/v3…），不回填旧题；账本 checklist_hash 记录所用版本。

## 第 0 步 · 拒收门（两问，任一「否」=拒收不入账本）
- Q0-1 resolve 时点是否存在**可机检或第三方可复核**的真值锚？（是/否；否→拒收 reason=no_anchor）
- Q0-2 判据冻结（cutoff）是否早于事件的决定性时点？（是/否；否→拒收 reason=leak）

## 第 1 步 · 按序判定（L5→L6→L1→L3→L2→L4，首个全绿层即归属；混合题记 secondary_layer）

### L5 不可约随机（3 问全「是」）
1. 结果由认证随机源产生（认证 RNG/物理抽奖/量子源，机制可查）？
2. 不存在任何公开渠道的信息优势路径？
3. 题面无统计学偏倚可利用（有偏倚→归 L2）？

### L6 对抗（4 问全「是」）
1. 结果由利益相反的智慧主体的决策直接产生？
2. 对手能观测我方历史预测/策略模式并调整？
3. 策略空间开放（不可枚举全部打法，纯基率会因对手适应而失效）？
4. 存在「声称与真实意图可分离」的伪装结构？

### L1 决定论（4 问全「是」）
1. 状态空间有限且完全可枚举？
2. 转移规则完全已知且无隐藏随机源（同一状态必得同一后继）？
3. 任一观察者仅凭公开状态即可推演结果（信息完全）？
4. resolve=程序可复算（引擎跑一遍即真值，无裁判裁量）？

### L3 短窗混沌（4 问全「是」；第 2 问答「未知」→ 降 L2）
1. 存在已知或可近似的演化机制/模型？
2. 预测窗口显著短于该系统的可预测时界（用历史同型方法命中率随窗口的衰减数据佐证）？
3. 有实时观测流可在窗口内同化？
4. resolve 落在窗口内？

### L2 系综（4 问全「是」）
1. 题面定义于稳定可重复的总体（同分布假设可写进判据）？
2. 存在 ≥30 条同类历史结果可查？
3. 单事件不可由现有信息决定性推出（但频率稳定）？
4. 存在外部统计源可作基率锚？

### L4 自反（3 问全「是」；叠加层语义：primary=按上文判定的底层，secondary=L4）
1. 结果由人类决策直接产生，且决策者可能接触本预测或同类预测？（同时记录本预测是否计划公开→public_exposure）
2. 存在反馈回路（预测→行为→结果→后续预测）的历史证据或机制描述？
3. 无法归入 L1-L3/L5？

## 走通示例（v1 冻结版口径）
题：「2026-09-12 上海最高气温 > 35°C 的概率？」
拒收门：真值锚=气象台官方日数据（是）；cutoff 冻结早于当天结束（是）→ 进判定。
L5：非认证随机源（否）→ L6：无对抗主体（否）→ L1：大气非有限枚举（否）→ L3：①数值天气模式存在（是）②历史 24h 命中率远高于 7 天（是，气候统计可查）③地面站逐时观测流（是）④resolve 在窗口内（是）→ **归 L3**。
落库：layer=L3，engine=aci，gate=descriptive，checklist_hash=v1。

## 引擎姿态速查（细则见设计文档 §2）
| 层 | 引擎 | LLM 角色 |
|---|---|---|
| L1 | 程序计算 | 仅代码生成（R-a 件），不出概率 |
| L2 | 统计基率 | 基率 |
| L3 | 基率+ACI×滚动窗 | 校准 |
| L4 | 私有多路（禁公开） | 聚合 |
| L5 | 认证源分布 | 无 |
| L6 | 结构推断（矛盾特征+多路） | 多路+校准 |
