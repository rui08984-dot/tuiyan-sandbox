# A6 · 校准报告发布纪律（v1 · 2026-09-16）

> 来源：蓝图 §2.1#9（限定语块＋发布面）；适用对象：`p1b/scripts/calibration-report.cjs` 产物与其前端页（`/calibration`）。
> 性质：**发布纪律文本**（不是判据）；纪律违反＝撤回发布面，不改数字。

## 1. 发布面（允许对外/对内的两个面）

| 面 | 形式 | 生成 | 备注 |
|---|---|---|---|
| 报告件 | `p1b/sim/out/calibration-report-YYYYMMDD.{json,md}` | `node p1b/scripts/calibration-report.cjs` | 只呈现既有读数件现成列，**零新算** |
| 页面 | 前端 `/calibration`（`CalibrationReportPage`） | `cd p1b/web && npx vite build` → 用户重启 bat＋强刷 | 数据源 `GET /api/disclosure/calibration` |

## 2. 恒挂限定语（三条，缺一条即不予发布）

1. **重放计分（读侧）**：数字来自引擎重放，账本 gate=descriptive 未计分；`baseline_brier` 列从未写入。
2. **过程能力门定性**：G2 门＝过程能力门，**不含质量读数**；对外表述一律挂限定语（不得表述为能力证明）。
3. **样本纪律**：n<30 的格只记方向、不出结论；格间**禁池化**。

（三条已内建在报告件的「限定语块」节——发布纪律与产物需逐条对得上。）

## 3. 禁词与用语

- 正文与页面**禁用**「预测」字样（铁律②）——落盘断言：脚本产物 md（测试锁）＋页面源码（测试锁）＋**构建产物 bundle（构建后扫描，值必须为 0）**。
- 「校准分/校准报告/分层账本/审计」为推荐用词；不得出现「更准/提升/超越」类比较宣称。

## 4. 口径边界（两个口径不可互搬）

- A｜账本口径：`/api/audit/summary` → `layer_calibration`（读 `predictions.assigned_prob`）。
- B｜引擎重放口径：本报告（读 stage4 读数件）。**报告只用 B**；引用 A 必须显式标注口径差异。

## 5. 发布流程（每次发布照做）

1. 跑 `node p1b/scripts/calibration-report.cjs`（零写库）；确认格数＝stage4 `by_domain` 格数。
2. 跑 `cd p1b && node --test`（含本报告测试与禁词断言）全绿。
3. 若需页面更新：`npx vite build` → 扫描 bundle 禁词（0 命中）→ 用户重启 bat＋强刷。
4. 发布后 24h 内登记：留痕索引一节＋（如对外）G2 限定语复核记录。

## 6. 变更纪律

- 本纪律文本与报告脚本同属**披露层**：改动＝版本递进（A6-v2），旧文本零改动保留；判据类文件（PREREG）不受本件影响。
- 若报告新增列（如 U8 加列）：新列默认**只披露不进门控**，须在报告内自带自我设限判据（例：KL 列与 ΔBrier 的跨层 Spearman CI 含 0 ⇒ 永久纯披露）。
