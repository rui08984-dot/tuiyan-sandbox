# P0 回放盲测协议 v1

> 日期：2026-09-07 ｜ 上游：docs/specs/2026-09-07-推演沙盘-design.md ｜ 目的：用带真值的公开对局，量化验证"账本+竞争假设研判循环"的信息增量（对应 P0 gate ①③）。注意：gate ②（录入成本≤30秒）本协议测不了，仍需真人局补测。

## 1. 假设

- H1（核心）：结构化切片+竞争假设 prompt 的研判，在"谁是坏人"排序上优于朴素基线（同一模型直接读原始战报自由发挥）。
- H2：研判依据链可追溯到具体事件（不是凭空断言）。
- H3：假设板发生 ≥1 次由新事件触发的有依据翻转（不是随机漂移）。

## 2. 材料与切片

- 输入：docs/sandbox/p0-replay/ 下的还原对局档案（子代理 B 产出）。
- **文件规范**：公开层与真相层物理分离——
  - `replay-<game>-<id>.md` = 公开信息流（盲测 AI 可读）
  - `replay-<game>-<id>.truth.md` = 真相层（队长专用，盲测代理不给）
  - 整合时由队长把 B 产出的单文件拆开。
- 切片规则：按昼夜/天数切成 day1..dayN，每片含"截至该日"的全部公开信息。第 d 轮研判只喂 day1..day d。

## 3. 双轨对照

| 轨 | 输入 | prompt |
|---|---|---|
| 实验轨 | 切片 + 账本结构（角色表/事件表/可见性） | 强制 ≥2 竞争假设 → 证据映射（结论须引用事件序号）→ 嫌疑 Top-2 排序 + 依据 |
| 基线轨 | 同一切片的原始战报文字 | "根据目前信息，你觉得谁最可能是坏人？给 Top-2 和理由" |

两轨同一模型、同一切片节奏，逐日推进。

## 4. 评分

每轨每日记录嫌疑 Top-2，对照真值计算：
- **命中率**：坏人进入 Top-2 的天数占比；
- **首次命中日**：越早越好；
- **翻转质量**：假设翻转是否与当日新事件强相关（人工判读，记录翻转入是否事后被证实）。

## 5. 判定

- H1 过 = 实验轨命中率 > 基线轨（且基线非零，防"闭眼蒙也能全对"的退化局）；
- H2 过 = 实验轨依据链抽查 ≥80% 能对应到真实事件序号；
- H3 过 = 出现 ≥1 次可归因翻转。
- **三过二 → P0 研判质量 gate 视为通过**（进 P1a）；不过 → 按 design doc 处置：杀引擎或回炉 prompt 再测一局，不换 UI 续命。

## 6. 局限（如实声明）

1. 切片由人工整理，信息已被一道人工过滤提纯——比真实边玩边录的条件乐观，H1 通过≠录入问题不存在；
2. 单局样本量极小，结论只当方向性信号；正式判定要连测 ≥3 局；
3. 还原档案含[推断]补全处，若推断恰好泄露真值，该切片作废（整合时队长逐条检查推断标注）。

## 6.5 v1.1 增补（第一性原理重建联动，2026-09-07）

- 实验轨 prompt 升级为两层研判：先输出**矛盾清单**（声称vs声称/声称vs行动，每条引用两个事件序号），再强制基于矛盾清单出竞争假设与嫌疑 Top-2。
- 新增指标 **H2'**：实验轨"有效矛盾发现数"——抽查矛盾对确属语义冲突的占比 ≥60% 且总数 >0，同时 > 基线轨随口点名数。与 H1/H2/H3 三过二判定并行计入。
- 评分表加一列：每日矛盾发现数（有效/总数）。

## 7. 执行编排（队长派单制）

- 档案整合/拆分：队长（轻量文本操作）；
- 盲测研判：每轮派一个全新子代理（无上下文污染，天然盲）；
- 评分：队长对照 truth 文件执行，记录进 `docs/sandbox/p0-replay/score-<game>.md`。
