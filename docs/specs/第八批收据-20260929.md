3. **为什么仍要放行**：这一层**本来就是读数实验**（拿合成真值的题跑判词管线），不是在线落注。
   ⇒ **闸要它做的不是「不许跑」，而是「跑出来的行必须自报是读数行」。**
4. **逐调用点显式传参，不是全局开关**：别的读数批漏了这一处就照样被拒。

★**第 3 条是这条豁免的正当性核心，我认可**：豁免的资格不来自「它方便」，而来自
**「放行之后那一行会被打上 `legacy_post_settlement` 标记、不进 clean 桶、并在返回值里 `excluded++` 披露」**——
即**放行≠免费**。C 道在 `:174,:209,:212-213` 逐条计数并在收尾打印，把这条落到了代码里而不是只写在注释里。
