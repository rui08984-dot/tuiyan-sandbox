## 二、pre-commit 钩子 · 建议：**启用（12.4 秒）**

实测总耗时 **12.4 秒**（后端 8.7 ＋ 构建 1.1 ＋ 前端 0.8 ＋ 类型 2.2），比我当初估的 20–30 秒快一半。
钩子不自动改任何文件，`git commit --no-verify` 可绕。

**我没有装**，因为它会改变你每次提交的手感，这件事该你定。
要装就一条：

```bash
cp p1b/gates/pre-commit.sh .git/hooks/pre-commit
```

> ⚠️ 本机是 NTFS，`chmod -x` 是**空操作**（实测 `chmod +x` → `chmod -x` → `stat` 仍是 755），
> 所以「装了但不启用」在 Windows 上做不到 —— 文件只要躺在那个路径上就是启用的。
> 要停就 `rm -f .git/hooks/pre-commit`。
>
> 注意：`.git/hooks/` **不进版本库**。钩子正文放在 `p1b/gates/pre-commit.sh`（可入库），
> 所以换机器不会丢，但你得重新执行上面那条命令。

## 三、43 个读侧是否切 `verdicts_clean` · 建议：**暂不切**
