## 一页版（3 分钟读完）

**一句话**：这是一台**给「会不会发生」记账的机器**——你把一个**事后能用公开事实核对**的问题交给它，
它记进一本不能改的账，自动结算，并长期告诉你「它自己算得准不准」。

它做三件事：

1. **记账**：每道题必须带**真值锚**（事后能查到的客观事实，比如"官方公告""某 API 的日值"）。没有锚的题，**当场拒收并留痕**。
2. **分类**：每道题自动落到**六层**里的一层（从"完全能算"到"纯运气/有人对抗"），决定用哪种算法处理。
3. **出读数**：能算的层给出**带误差带**的读数；并且每道题结算后**自动打分**——所以它不是一个"嘴硬的预测器"，是一本**自己能被打分的账**。

**怎么用**（现在就能用）：

- 打开工作台的**「接题页」**：写题面 → 按固定个数勾选六层问答 → 提交 → 立刻得到三种结果之一：
  **① 拒收**（说明理由，比如"没有真值锚""问得太模糊"）｜**② 只分类**（这层还没有算法，先记账）｜**③ 出读数**（归哪层 + 带区间的数）。
- **「审计页」**：整个账本按层的统计、已结算/待结算清单。
- 重度操作（批量结算等）走**命令行**，日常不需要碰。

**它的三个边界（它会主动告诉你）**：

1. **不能算的就说不能算**——拒收、或者"只分类不出数"，绝不给没根据的数字；
2. **有些层的读数天生"平凡"**——比如彩票层，它只会告诉你"这是随机的、别指望赢"（有层读数偏"平"，不是坏了）；
3. **它不承诺"什么都能算"**——承诺的是「**每件事都有归宿**」：合格的进账、不合格的进拒收日志、说不清的标"未知"。

## 详解版（想核对细节的人看这）

### 1 · 六层是什么（2026-09-14 的状态）

| 层 | 大白话 | 现在的状态 |
|---|---|---|
| **L1 决定论** | 规则内可以"算"出来的（一局游戏里谁出局这类） | ✅ 有引擎（程序复算）：**180 题，复算正确率 100%** |
| **L2 系综** | 有稳定历史分布的事（天气、汇率等） | ✅ 有引擎（历史基率+置信区间）：**可计分 278 题** |
| **L3 短窗混沌** | 短期能猜、长期没戏的（明天的气温） | ✅ 有引擎（基率+在线校准 ACI）：**可计分 481 题** |
| **L4 自反** | "预测本身会影响结果"的事（围观、传播） | 按设计**只做标注**，不出数（它是叠加在别的层上的标记） |
| **L5 不可约** | 认证过的纯随机（彩票开奖） | ✅ 有引擎（认证分布）：**可计分 30 题**（随开奖增长） |
| **L6 对抗** | 有对手在博弈的（狼人杀/血染钟楼复盘里的判断） | ✅ 有引擎（把已有判断按固定规则聚合）：**可计分 270 题** |

> 除了 L4（设计上不出数），**六层里五层都已有引擎、有读数**。

### 2 · 账本的四条铁律（为什么它的数字可信）

1. **没有真值锚，不入账**——"某公司会不会内部拍板"这种查不到客观事实的题，会被拒收（拒收不是丢人，是设计）；
2. **账本不可改**——写进去的事实不能回改（要改就是新记录 + 版本递进）；
3. **截止时间要干净**——每道题都记"什么时候问的"，问之前发生的事才算信息；
4. **改动判据=版本升级**——规则冻结后不偷偷改；改了要写新版本、说明为什么。

### 3 · 读数怎么读（三个概念）

- **Brier 分数**：给概率打分（越低越好，0.25 是"硬币水平"）。它比"准确率"更诚实：**说"八成会"最后没发生，要被重罚**。
- **区间**：每个读数带一个区间（比如"0.30～0.70"），不是单点装精确。
- **"平凡读数" vs "真读数"**：
  - **平凡**（L1/L3/L5 的部分读数）＝"这层本来就没打算赢"（基率层/复算层/认证随机层），**不要当本事读**；
  - **真读数**（如 L6 狼人杀判断聚合：Brier 0.183 对 0.25）＝真的有信息量——但也要看"更严的对照"，别急着庆祝。

### 4 · 现阶段能力快照（2026-09-14）

- 账本：**1935 题**（对局/sim 450 + 外部语料 1485），已结算 **1263+**；
- 接题闭环：**已上线**（拒收门 + 六层分类 + 分层路由 + 拒收日志）；
- 采信链：**已验收**（机器的自动检查 ＋ 代理逐题复核 ＋ **你本人抽验 10 题**三段齐全；这是审计器对外可信的底子）；
- 测试：**269 项全绿**；账本完整性检查通过；
- 在跑：命题 A 的补漏跑批（与"能不能把矛盾检测用在预测里"这个科研问题有关，**它不影响上面这些能力**）。

### 5 · 常用开关与口径（骨架，简化重构时补全）

- `P1B_LLM_REASONING_EFFORT=low`：让模型"少想一点、快点答"（跑批提速 ~4 倍；不设＝默认行为）；
- 所有跑批脚本：**默认只读/演练**，要真写库必须显式 `--confirm`；
- 数据路径参数（`--db`）一律显式传，不依赖默认值。

### 6 · 常见问题

- **"它到底能不能预测天气/彩票？"** —— 能"记账 + 给区间 + 自己打分"；彩票层它会明确说是随机，天气类是"短期有料、长期没戏"。
- **"为什么有的读数写了'不声称优于'？"** —— 因为那几层的职责是"诚实基线"，跟硬币比没有意义；真想提高，要引入新的信息来源（那是另一个立项）。
- **"能拿它下注/炒股吗？"** —— 不能。它是**审计与校准参考**，不是投资/下注建议；玄学那条线永远挂"娱乐参考"。
